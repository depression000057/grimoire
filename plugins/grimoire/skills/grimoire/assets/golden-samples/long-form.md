# お手本: 長文の地の文（note の本文を書く時）

- このファイルの役割: note の本文のような長い文章を書く直前に読む、講座運営者が実際に公開した長文の実物
- いつ読むか: モード2（note）で本文を通しで書く直前
- 目次: §0 使い方 §1 実物（公開する知識と、内部に蓄える知識） §2 この文から見るところ

## §0 使い方

- これは note ではなく、講座運営者が X に公開した長文投稿（2026-08-25 公開）。note の地の文のリズム・段落の渡し方・例えの入れ方の見本として使う
- 受講生本人の note や、講座で配られた note のお手本が `10_お手本/` にあれば、そちらを優先する
- 構成をそのまま型として写さない。1本の長文の中で、どう話を渡しているかを見る

## §1 実物（公開する知識と、内部に蓄える知識）

原文の句読点・改行はそのまま残している。ただし、書き手が自分用に書き留めた用語のメモ1行（「そうすると〜自社仕様になっていく。」の次の行）だけを省いた。

```text
意外とみんな意識低いけど、AI時代は公開する知識と、内部に蓄積する知識を分けないといけない 。

これまでは、自分の知識やノウハウを惜しみなく公開することが信用になり、その結果として仕事や顧客が集まる、という戦い方がかなり強かった。

もちろん、この構造自体は今後も残るんですが、AIが公開情報をほぼ無限に収集・整理・再構成できるようになると、話が少し変わってきます。

ネットに置いた瞬間、その知識は自分だけのものではなくなる。

競合も読めるし、AIも読めるし、数ヶ月後には似たような知識を誰でも数秒で取り出せるようになるので、「知っていること」そのものの希少性はかなり速い速度で落ちていく。

だからこれから必要になるのが、公開する知識と、内部で育てる知識をちゃんと分けることです。

たとえば私なら

◽️公開するのは、考え方や判断基準、再現できるノウハウ
◽️内部に残すのは、顧客との細かいやり取り、失敗履歴、改善ログ、判断の背景、独自に集めた一次情報

みたいに分けてます。

別にケチってノウハウを隠そうという話ではなく、むしろ公開情報はどんどん出した方がいい。思想や価値観まで含めて外に出すことで、「何を知っている人なのか」ではなく「どう考える人なのか」が伝わり、それ自体がブランドになるからね

ただし、その裏側には外からアクセスできない巨大な情報資産を作っておかないといけない。

表では思想を公開する。
裏では経験を蓄積する。

この二層構造がかなり重要になってくると思っています。

飲食店で考えると分かりやすくて、料理の思想や食材へのこだわりはどれだけ語ってもいいんだけど、毎日の微調整、仕入れ先との関係、火入れの感覚、何百回も失敗して作られた判断基準まで全部公開する必要はない。

そこまで公開したら秘伝のタレではなく、無料配布のめんつゆ、みたいな差分を作る。

そしてもう一段重要なのが、内部情報は「隠しておく」だけでも弱いということ。

社員の頭の中、過去のSlack、誰も見返さない議事録に散らばっている状態では、AIからすると存在していないのとほぼ同じだから

現場で経験する
↓
一次情報を記録する
↓
判断理由まで残す
↓
自社AIから参照できる状態にする
↓
また現場で結果が出てデータが増える

この循環を作る。

そうすると、汎用AIを使っているだけなのに、出てくる答えだけが徐々に自社仕様になっていく。

将来的には、モデル性能そのものではほとんど差がつかなくなるはずです。同じように賢いAIを誰でも使えるようになったとき、最後に差を作るのは「そのAIに何を見せられるか」になる。

公開情報だけを食わせたAIは、どれだけ賢くても平均点に収束する。

一方で、10年分の顧客理解、失敗、判断、現場の感覚を持っているAIは、同じモデルでも別物になる。

だからこれからは、発信することと同じくらい「何を公開せず、自分たちの中で複利運用するか」を考えないといけない。

AI時代の情報戦略は、隠すか公開するかではなくて信用を作る情報は公開し、競争優位を作る情報は蓄積する。

この線引きを持っている、いないでは数年後かなり大きな差になるだろうね。
```

## §2 この文から見るところ

| 見るところ | この文でのやり方 |
|---|---|
| 1行目 | 読者を少しだけ挑発する一言（意識低いけど）と結論を、同じ1文に入れている |
| 前の常識をいったん認める | 「これまでは〜かなり強かった」「もちろん〜今後も残るんですが」と、読者が信じてきたことを先に肯定してから、条件が変わった話に移っている |
| 自分の場合を出す | 「たとえば私なら」と、書き手自身の分け方を具体的に見せている |
| 反論を先回りする | 「別にケチってノウハウを隠そうという話ではなく」と、読者が思いそうな反論を先に言っている |
| 例え | 飲食店の料理と秘伝のタレ・めんつゆ。読者が毎日目にする物で、話を一段わかりやすくしている |
| 流れを見せる | 矢印の5段で、何をどの順番でやるかを1目で分かるようにしている |
| 締め | 最後は、読者が持ち帰る判断の基準（信用を作る情報は公開し、競争優位を作る情報は蓄積する）で終えている |

語尾は「〜です」「〜だから」「〜だろうね」と混ざっていて、これはこの書き手の声。受講生は自分の設定の声で書く。
