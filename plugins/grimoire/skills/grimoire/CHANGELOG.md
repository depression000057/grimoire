# 変更履歴

講座が新しい版を出すと、グリモワールは自動で新しくなる。受講生に「何が変わったの？」と聞かれた時に、ここを1〜3行で伝える。新しい版を上に書く。

## 2.14.0（2026-11-20）

- 複数アカウントでの運用や予約投稿を安全に続けるためのルールを Threads モードに追加しました（立ち上げ日数ごとの1日上限、予約時刻のランダムずらし、アカウント間・まとめ出し時の文面かぶり防止、1投稿目の外部URL直貼り回避）。機械チェックでも1投稿目のURL直貼りと投稿同士の文面かぶりを自動で検知します
- 振り返りモードに、閲覧や反応だけでなく「プロフィール移動・固定投稿・リスト登録・着座・成約」の数字を受け取って導線の詰まりを切り分ける手順と、リスト獲得につながった組み合わせをカードへ昇格させる流れを追加しました。使い方は今まで通りです

- 売れる文章の説得力と物語づくりを強化しました。書く前の8項目棚卸し・課題解決型と欲求喚起型の2つのロジック型・行動を止める6つの壁の先回り排除・実績ゼロからの4連ストーリー・信頼獲得5技法・煽らずに仲間意識を育てる3原則を追加しました

## 2.11.0（2026-11-19）

- 伸びた投稿の検索道具（バズレコ MCP）をつないでいる環境では、グリモワールが自動で連携するようになりました。手元に集めた投稿がまだ少ない時でも、あなたのジャンルでフォロワーの割に大きく伸びた手本や市場の言葉を自動で引いて手元に貯め、今日の切り口提案・全文とツリーの参照・1行目の句の一括カウント・書いた後のセルフ検品まで確認画面なしでそのまま使えます（つないでいない人の使い方は今まで通りです）

## 2.10.0（2026-11-18）

- 講師の最新の指示に合わせて、「全部のせ」の書き方と点検を新しくしました。話し言葉に整える時は、AI が言葉で口調を決めるのではなく、あなたのお手本・相手のコメント・参考にした伸びた投稿の原文をそのまま並べて、語尾や長さ・見出しの有無・温度感を合わせます。また、直しの途中で説明が増えて手本より長くならないよう、手本との12字以上の一致と字数のふくらみを機械チェックでも確かめます
- 複数本の Threads 投稿を作る時は、誰が読んでも反応しやすい集客用の入口の投稿（暦・行事・星座・誕生日・生まれ月など）を混ぜ、初期は1行目の7割以上を読者主語にします（キャラや身内の話は2行目以降の根拠か合う回だけに出します）。さらに、強い指摘で広く届ける「攻めの投稿（案内なし）」と、プラスの変化から案内へつなぐ「受けの投稿」を分け、最後の呼びかけ（フォロー・いいね・保存・コメント・プロフィール・無料鑑定や LINE や note・誘導なし）を4種類以上にばらします
- あなたの体験や具体的な場面が足りない時は、AI が勝手に作ったりぼかしたりせず、書く前に最大5問だけ質問してあなたの言葉をそのまま使います。1行目の10案も、集めた複数の伸びた投稿の原文からなぞって並べる形になりました。使い方は今まで通りです

## 2.9.1（2026-11-15）

- 第2回・第3回の勉強会の内容と食い違っていた手順を、勉強会の内容に合わせました。立ち上げたばかりのアカウントの相談では、投稿を始める前に自分のジャンルの言葉で検索して投稿を見ておすすめ欄をそのジャンルで染め、最初の1〜2週間はほとんど動かずに投稿だけにして、いいね周りやフォロー周りはしません（前はフォローして反応するとすすめていました）
- 無料鑑定の後の LINE は、有料の案内を無料鑑定と同じ日のうちに出し（前は7日後）、3通の順番を「見立て→変わったお客さんの声→有料の案内」にします。1通目の見立て（無料鑑定の手紙）は300〜500字にし（前は400〜700字）、見送った人には7日で3回以上連絡し、買った人にはラベルで目印を付けて買った商品の売り込みを見せないようにします
- Threads の投稿は、本文（ツリーの1つ目）を2〜3行・50〜100字にし（前は200字に満たない短文は作りませんでした）、ツリーに「1/3」のような番号は入れず、ツリーの時は本文（1つ目）で引きつけて理由の前で切り、答えはツリーに置きます。1行目は10案出してから選び、リンクはツリーの2投稿目・固定・プロフに置き、伸びた投稿の出し直しは9〜10日あけてそのまま出してよく（前は30日以上あけていました）、リサーチはまず20本集めてコメント欄も読み、投稿の採点の「長さ」の点は本文が100字以下でも満点にします（前は60〜99字は10点のうち4点でした）
- 変更履歴に抜けていた 2.8.1 の項を足しました。使い方は今まで通りです

## 2.9.0（2026-11-14）

- 講師の指示で、投稿・プロフ・note・告知を市場の言葉（集めた伸びている投稿に実際に出てくる言葉）で書く決まりが入りました。AIがふわっと言い換えた言葉や作った言葉を混ぜず、伸びている投稿の言葉をそのまま使い、中身だけあなたの話に変えます（1人の投稿の文をそのまま写すことは、今まで通りしません）
- 伸びている投稿の本文と数字をコピペして渡すと、原文のまま手元のフォルダに保存し、10本たまるとよく出る言い回し・1行目・文の終わり方を数えた表ができます。書いた投稿の1行目が集めた伸びた投稿に何本出てくる言い方かを数えて提出の時に本数つきで見せ、0本の言い方は市場の言葉に直します
- 見立てやおすすめは名乗りを付けて言い切り、読者にやってほしいことは「〜してください」の形ではっきり書きます（結果の約束・不安をあおる言い方・作った数字は今まで通り書きません）。また、「全部のせ」と送ると、書き方の決まりを1つずつ当てて、最後に確かめの一覧を出します
