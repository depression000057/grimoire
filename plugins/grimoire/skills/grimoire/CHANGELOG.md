# 変更履歴

講座が新しい版を出すと、グリモワールは自動で新しくなる。受講生に「何が変わったの？」と聞かれた時に、ここを1〜3行で伝える。新しい版を上に書く。

## 2.2.0（2026-09-26）

- セールスレター・LP・ステップメール・SNS の投稿・冒頭の一言を、売れる型に当てはめて組めるようになりました（型を選ぶ → 設計シートの枠を埋める → 書く → 点検）
- note の設計でも、無料部分と本編の型を選んでから書くようになりました
- 「この文章が売れない理由を見て」と頼むと、足りない教育や訴求を型に照らして見つけます

## 2.1.0（2026-09-26・最初の配布版）

- ティルナノーグ受講生のグリモワールの最初の版です。Claude デスクトップアプリの Code タブで、グリモワールのフォルダを開いて使います
- 文字起こしのファイルを添付したり、長い文を貼ったりするだけで、言われなくても覚えます。何十時間分でも区切りごとに少しずつ覚えて、会話が変わっても続きから進みます
- 講座が新しい版を出すと、自動で新しくなります。覚えたことと作った物は、そのまま残ります
- 最初に話しかけた時に、グリモワールがこのパソコンのこのフォルダに登録されます（次の会話からもそのまま使うため。1回だけ）
- 「グリモワール起動」と話しかけると、やりたいことと悩み（投稿が伸び悩む・有料記事が売れない・アカウントのコンセプトなど）のメニューが出て、選ぶだけで進められます
