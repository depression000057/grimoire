# 導線の設計（完全版）

無料鑑定から有料鑑定までの流れを、1枚の設計シートにして、各段の中身（投稿・返信・診断ページ・LINEの配信文）まで作る。

## 全体の流れ

```
コメントを誘う投稿（参加型の鑑定枠）
→ 届いたコメントに一言鑑定で返信。最後に「詳しくはプロフィールのリンクの診断から」
→ 診断ページ（質問8問・結果4タイプ）
→ 結果の続きを受け取るために公式LINEに登録
→ 結果のキーワード（例：「金運」）を送ると、詳しい鑑定結果（手紙版）が届く。この時にタイプが記録される
→ タイプ別のメッセージ（完全版は7通）
→ 有料鑑定（鑑定書）
```

LINEの手前に診断ページを1枚はさむのは、いきなり「LINEに登録して」と言うと身構える人でも、「自分の診断結果の続き」なら受け取りに来やすいから。キーワードでタイプが分かるので、LINEにつながった時点で「この人は金運の悩み」と分かり、タイプごとに違う案内を送れる。

## 手順

1. 利用者に聞く（1回にまとめる）: ①売りたい有料鑑定と価格 ②LINE公式アカウントの有無と配信ツール（UTAGE・Lステップ・LINE公式の管理画面など） ③タイプ分けの軸（例：金運・恋愛・人間関係・自分らしさ。リサーチの伸びているジャンルから4つ） ④無料で渡せるもの（一言鑑定・手紙版・特典の文書）
2. 設計シートを埋める（`.grimoire/assets/kantei/funnel-sheet-template.md`）
3. 各段の中身を作る

| 段 | 作る物 | 手順書 |
|---|---|---|
| 入口 | 参加型の投稿（週2〜3本）と、返信の型 | `threads-posts.md` 型1・15／`reply.md` |
| 診断ページ | 質問8問・結果4タイプ・キーワード・LINEボタンの HTML | `diagnosis-page.md` |
| LINE | キーワードの自動応答・タイプのラベル・7通の配信文・設置シート | `line-utage.md` |
| 有料 | 有料鑑定の案内文と、鑑定書の書式 | `kantei.md` |
| 測る | 週ごとの数字の表 | `weekly-review.md` |

4. 設計シートと作った物を `ティルナノーグ_制作物/鑑定/YYYY-MM-DD_導線/` に保存し、設計シートの要点を `ティルナノーグ_マイナレッジ/鑑定/導線.md` に書く（コメント返信の最後の一言に使う）

## 決めごと

- 無料の中身は「一言」「手紙」、有料は「鑑定書」のように、分量と深さで差をつける
- Threadsでは売らない。売り込みの投稿は全体の2割まで。有料の案内はLINEの中で
- 数字は利用者の実数だけを書く。無い所は空欄にして「測り方」だけ書く
- 作って終わりにしない。診断を始めた人・終えた人・LINEのボタンを押した人の3つは必ず測る（診断に人が来ているのに終えた人が0人なら、ボタンや送信先がつながっていないことが多い）
- 配信・公開・設置は利用者が行う。グリモワールは下書きと設置の手順まで
