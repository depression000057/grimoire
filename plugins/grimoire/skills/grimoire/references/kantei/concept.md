# コンセプトの設計（完全版：キャラ設計と3層の点検まで）

投稿をいくら作っても、「誰が・誰に・何を言う人か」が決まっていないと選ばれない。ここを最初に決める。

## 方程式

**キャラ記号 × 見立て × 救済の出口**

| 要素 | 意味 | 例（例なので、利用者の事実に差し替える） |
|---|---|---|
| キャラ記号 | 一目で覚えられる、その人だけの立場や経歴 | 元看護師の数秘術師／寺の近くで育ったタロット占い師／子育てを終えてから占いを学んだ人 |
| 見立て | 悩みをどう見るか。その人ならではの切り口 | 「恋が続かないのは、相性ではなく数字のリズムのずれ」 |
| 救済の出口 | 読んだ人が、今日できる小さな一歩 | 「今夜、寝る前に〇〇を1つ書き出して」 |

キャラ記号は作り話にしない。利用者の本当の経歴・体験から選ぶ。同じテンプレートを複数のアカウントで使い回すと、読者に見抜かれる（観察でも「同じ文言の占い師が3人並んでいた」という声が出ていた）。1アカウント1キャラで深く育てる。

## 進め方

1. 利用者に聞く（1回にまとめる）: ①占いを始めたきっかけ ②人に話すと驚かれる経歴や体験 ③いちばん多く相談される悩み ④有料で売りたい鑑定と価格（未定なら空欄でよい） ⑤顔を出すか（出す／出さない／イラスト）
2. リサーチ結果（`ティルナノーグ_マイナレッジ/鑑定/リサーチ.md`）があれば読み、伸びているジャンル・空いている席と重なる所を探す
3. 方程式の案を3つ出す。おすすめ1つに理由を付ける
4. 決まった案で、キャラを設計する（下の表）
5. 3つの層がつながっているか点検する（下の表）。つながらない所があれば、投稿を増やす前にここを直す
6. 決まったら、次を作って `ティルナノーグ_マイナレッジ/鑑定/設定.md` に書く
   - プロフィール文（150字以内・キャラ記号→誰の何を→どうなる、の順。数字や実績は本人の事実だけ）
   - 固定投稿の案（自己紹介＋無料鑑定の受け方）
   - 投稿テーマの柱3本（伸びているジャンルから）

## キャラ設計

| 項目 | 決めること |
|---|---|
| 呼び名 | 覚えやすい名前（本名でなくてよい） |
| 一人称と語尾 | 例：私／〜ですよ・〜ですね。方言を使うなら最初から最後まで通す |
| 口ぐせ | 1つだけ（多いと鼻につく） |
| 言わないこと | 安全ルールに加えて、このキャラが言わない言葉（例：強い命令形は使わない） |
| 見た目 | アイコンの方向（リサーチのアイコン傾向と合わせる） |
| 得意な型 | `threads-posts.md` の15型から、キャラに合う3〜5型 |
| 救済の出口の置き場 | 無料鑑定（一言）→ 有料鑑定（手紙）の順に深くなるように |

## 3層の点検

| 層 | 問い | つながらない時の直し方 |
|---|---|---|
| 集客（投稿のテーマ） | 伸びているジャンルの悩みを扱っているか | テーマの柱をリサーチの上位ジャンルに寄せる |
| アカウント（キャラ） | そのテーマを、この人が語る理由があるか | キャラ記号を、テーマに近い経歴に選び直す |
| 商品（有料鑑定） | 投稿で見せた見立ての「続き」を買える形になっているか | 有料鑑定の名前と中身を、見立ての言葉で言い直す（例：「数字のリズム診断つき恋愛鑑定」） |

点検の結果は「○／△／×」と理由1行で見せる。

## 出力の形

```
■ コンセプト案3つ（キャラ記号 × 見立て × 救済の出口）
■ おすすめ：案〇（理由）
■ キャラ設計：（表）
■ 3層の点検：集客○／アカウント△（理由）／商品○
■ プロフィール文（150字以内）
■ 固定投稿の案
■ テーマの柱3本
```
