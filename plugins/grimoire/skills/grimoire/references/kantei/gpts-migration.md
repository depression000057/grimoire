# 鑑定GPTsの引っ越し（完全版：何本でも・知識ファイル込み）

今使っている鑑定GPTsの中身を、グリモワールで同じように出せる「マイ鑑定レシピ」に移す。GPTsの仕様が変わっても、鑑定の中身は利用者のパソコンに残る。

## 利用者への案内（そのまま出す）

```
GPTsの引っ越しをします。1本ずつ、次の3つを用意してください。
1. GPTsの編集画面の「指示（Instructions）」の文章をすべてコピーして、ここに貼ってください
2. 知識ファイル（Knowledge）を入れている場合は、そのファイルを作業フォルダの「ティルナノーグ_マイナレッジ/鑑定/GPTs_元ファイル/」に置いてください（PDF・Word・テキストなど）
3. そのGPTsで実際に出した鑑定結果を1つ貼ってください（仕上がりを合わせるお手本になります）
```

## 移し方

1. 貼られた指示文を読み、次の6つに分けて書き出す
   - 占術と計算方法
   - 聞き取る項目（生年月日・名前・相談内容など）
   - 鑑定文の構成（見出しと順番）
   - 口調（一人称・語尾・呼び方）
   - 文字数や分量
   - 禁止していること
2. 知識ファイルがあれば読み、「計算の表・用語の意味・例文」に分けて、レシピの付録に要点を書き写す。他の人が書いた本や有料教材をそのまま写した物は、要点だけにして、出どころを1行残す（配布や販売には使わないよう利用者に伝える）
3. 占術ごとの扱い
   - 数秘術 → グリモワールの `numerology.py` で計算する
   - タロット → グリモワールの `tarot.py` で引く（利用者が実物で引いた時はその結果を使う）
   - それ以外（西洋占星術・四柱推命など） → 計算部分は「利用者が結果を入力する」形にする。構成・口調・分量はそのまま移す
4. `safety.md` とぶつかる指示（必ず叶う・不安をあおる等）があれば、移さずに利用者へ「この部分は安全のため外しました」と伝える
5. `ティルナノーグ_マイナレッジ/鑑定/マイ鑑定レシピ/<レシピ名>.md` に保存する（1本1ファイル）。先頭に「使う時の呼び名」を書く（例：「恋愛タロット」）
6. お手本の鑑定結果があれば、同じ相談でレシピを使って1回書き、お手本と並べて見せる。違う所を利用者に聞いて、レシピを直す（2回まで。合わない所が残ったら、その所をレシピに「未調整」と書いておく）

## 使う時

利用者が「〇〇（レシピの呼び名）で鑑定」「いつもの鑑定で」と言ったら、該当するレシピを読んで、その構成と口調で書く。レシピが複数あって分からない時は、番号で選んでもらう。`safety.md` はレシピより優先する。

## レシピの形

```
# マイ鑑定レシピ：<呼び名>
- 元のGPTs：<名前>（引っ越し日 YYYY-MM-DD）
- 占術と計算：
- 聞き取る項目：
- 構成（見出しの順番）：
- 口調：
- 分量：
- 禁止：（元の指示の禁止＋安全ルール）
- 安全のため外した指示：
- 付録（知識ファイルの要点）：
```
