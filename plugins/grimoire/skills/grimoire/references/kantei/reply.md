# コメント返信の下書き

送信は必ず利用者が自分で行う。グリモワールは下書きだけ作る。

## 手順

1. 設定（`ティルナノーグ_マイナレッジ/鑑定/設定.md`）の話し方と、導線の設計（`ティルナノーグ_マイナレッジ/鑑定/導線.md`）があれば読む
2. 貼られたコメントを1件ずつ読み、種類を分ける

| 種類 | 見分け方 | 返し方 |
|---|---|---|
| 鑑定の依頼 | 生年月日・数字（「5です」など）が書いてある | 一言鑑定（`kantei.md` の一言鑑定。150字以内）。最後に導線の一言（下の§導線の一言） |
| 感想・共感 | 「わかる」「泣いた」「私もです」など | 相手の言葉を1つ拾って返す（2文） |
| 質問 | 「？」がある・やり方を聞いている | 答えを1つ。長くなるなら「プロフィールのリンクから詳しくお伝えしています」 |
| 絵文字や一言だけ | 😊・🙏・「ありがとう」だけ | それにも短く返す（反応してくれた人を置いていかない） |
| 深刻な相談 | 体・お金・命・暴力の話 | 占わずに受け止め、専門の窓口を案内する（`safety.md`） |
| 荒らし・勧誘 | 攻撃・宣伝・外部リンク | 下書きを作らず「返信しない」とだけ書く |

3. 書き方
   - 相手のコメントの言葉を1つ入れる（全員に同じ文を返さない。同じ言い回しを続けない）
   - コメントに書かれていない事情を決めつけない。数字の自己申告（「私は5です」）を、こちらで計算し直して否定しない
   - 1往復で終わる返信にする（質問で終えて会話を引きのばさない）
   - 一言鑑定の中で未来を言い切らない（`safety.md`）

## 導線の一言（鑑定の依頼への返信の最後に付ける）

導線の設計があれば、その入口に合わせて1文だけ添える。毎回同じ文にしない。

- 診断ページがある時: 「もっと詳しく知りたい時は、プロフィールのリンクの診断もどうぞ」
- LINEだけの時: 「続きの読み方は、プロフィールのLINEでお届けしています」
- どちらも無い時: 付けない

## 出力の形

```
■ コメント1：「（コメント原文）」
種類：鑑定の依頼
返信の下書き：（本文）

■ コメント2：…
```

最後に「返信しない」にした件数と理由を1行。保存先は `ティルナノーグ_制作物/鑑定/YYYY-MM-DD_返信_下書き.md`。保存するファイルには、コメントの原文ではなく、生年月日・病名・名前などを「［省略］」にした要約を残す（画面に出す返事では原文を見せてよい）。
