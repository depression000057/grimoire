# タロットの読み（一般的な読みを自分の言葉で書いたもの）

鑑定文の材料。カードの言葉をそのまま並べず、相談者の生活の場面に置き換えて書く。逆位置は「悪い意味」ではなく「その力が出にくい・行き過ぎている・内側に向いている」状態として読む。どのカードでも未来を言い切らない（`safety.md`）。

## 小アルカナ（56枚）

小アルカナは「組（スート）」と「数・人物」の組み合わせで読む。

| 組 | 場面 | 正位置の方向 | 逆位置の方向 |
|---|---|---|---|
| ワンド | 情熱・仕事・やる気 | 動く・始める・燃える | 空回り・燃え尽き |
| カップ | 気持ち・恋愛・人間関係 | 満たされる・通い合う | すれ違い・気持ちを閉じる |
| ソード | 考え・言葉・決断 | はっきりさせる・切り分ける | 考えすぎ・言葉で傷つく |
| ペンタクル | お金・体・暮らし | 積み上げる・形になる | 不安定・後回し |

| 数・人物 | 読み |
|---|---|
| エース | その組の力の始まり・芽 |
| 2 | 2つの間で釣り合いをとる |
| 3 | 広がる・人と分け合う |
| 4 | 落ち着く・守る |
| 5 | ぶつかる・揺れる |
| 6 | 回復・行き来 |
| 7 | 立ち向かう・試される |
| 8 | 動きが速くなる・打ち込む |
| 9 | ほぼ満ちる・あと一歩 |
| 10 | 行き着く・ひと区切り |
| ペイジ | 知らせ・学び始め |
| ナイト | 行動・向かっていく |
| クイーン | 受け止める・育てる |
| キング | 導く・責任を持つ |

例：「カップの3（正位置）」＝気持ちの場面で、人と分け合って広がる → 「友達と会って話すと、気持ちが軽くなりやすい時です」

## 並べ方

| 枚数 | 位置 |
|---|---|
| 1枚 | 今のあなたへ |
| 3枚 | 過去・現在・これから／状況・壁・助言 |
| 5枚 | 今の状況・気持ちの奥・壁・助言・流れの向き |

3枚以上は、1枚ずつ読んだあとで、つながりを1段落にまとめる（「過去の〇〇が今の△△につながっていて、これからは□□しやすい」）。
