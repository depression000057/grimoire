# リサーチの整理（完全版）

伸びるアカウントを作る土台はリサーチ。利用者が集めた「伸びている投稿」から、伸びる型・伸びない言い方・伸びるジャンル・アイコンの傾向・空いている席・コンセプト案を取り出す。

## 受け取れる物

| 渡された物 | やること |
|---|---|
| 投稿の本文と数字のコピペ | そのまま下の「整理のしかた」へ |
| 画面収録の文字起こし（テキスト） | 投稿ごとに区切り直してから整理する。区切りが分からない所は「区切り不明」とする |
| 画面収録の動画ファイル | `python3 .grimoire/scripts/kantei/frames.py <動画> ティルナノーグ_制作物/鑑定/収録_静止画` で2秒ごとの静止画にし、1枚ずつ読んで本文・いいね・コメント数を書き起こす（同じ投稿が続く画像は1本として数える）。ffmpeg が無いと言われたら、スクリーンショットを渡してもらう |
| スクリーンショット | 1枚ずつ読んで書き起こす |

## 利用者への案内（投稿がまだ無い時にそのまま出す）

```
まず、伸びている投稿を集めましょう。
1. Threads の検索で、自分のジャンルの言葉を入れます（例：引き寄せ／金運／守護霊／数秘／タロット／縁切り）
2. いいね・コメントが多い投稿を選び、本文と数字（いいね・コメント数）をコピーしてここに貼ってください
3. 貼るのが大変なら、スマホで画面収録しながらゆっくりスクロールして、その動画を作業フォルダに置いてください。こちらで読み取ります
まずは10本からで大丈夫です。30本を超えると、型がはっきり見えてきます。
アイコンの雰囲気（顔出し／イラスト／風景など）もメモしてもらえると、アイコンの傾向も出せます。
```

## 整理のしかた

1. 投稿を1本ずつ表に入れる（数字が無い投稿は「数字なし」）

| # | 1行目（言い換え） | 型 | 字数の目安 | 主語（あなた／他の人／私） | 呼びかけ | いいね | コメント | アイコン |
|---|---|---|---|---|---|---|---|---|

2. 型の分類は `threads-posts.md` の15型を使う。当てはまらない物は「その他：〇〇型」と名前を付ける。使わない型（脅し・金額の予言・ぼかし）に当たる投稿は、伸びていても「真似しない型」として分けて数える
3. いいねの多い順に並べ、上位と下位を比べて違いを3つ書く（1行目の主語、具体的な場面や数字の有無、読者への呼びかけ、しぐさの身近さ、など）
4. 「伸びない言い方」を3つ書く（下位に共通する言い方）
5. 伸びているジャンル（恋愛・お金・仕事・人間関係・家族・自分・死生観）を多い順に並べる
6. アイコンの傾向（顔出し／イラスト／風景／文字）と、上位に多いもの
7. 空いている席を探す。上位のアカウントが「誰に・どんな立場で」話しているかを並べ、まだ少ない組み合わせ（例：同じ金運でも、家計の見直しの立場から話す人が少ない）を2つ挙げる
8. コンセプト案を3つ出す。形は `concept.md` の方程式「キャラ記号 × 見立て × 救済の出口」。3つは方向を変える（体験型／専門家型／寄り添い型など）。キャラ記号は利用者の設定にある経歴から作る。設定が無い時は「（あなたの経歴）」と空けて出す

## 出力の形

```
■ 集めた投稿：〇本（数字あり〇本）
■ 伸びる型トップ3：…（それぞれ、代表例の1行目を「言い換えて」1つ。原文は写さない）
■ 上位と下位の違い：…
■ 伸びない言い方：…
■ 伸びているジャンル：…
■ アイコンの傾向：…
■ 空いている席：…
■ 真似しない型（伸びていても安全ルールに当たる物）：〇本
■ コンセプト案3つ：…
■ おすすめ：案〇（理由1行）
```

- 他人の投稿の文面・アカウント名を出力に写さない。型と特徴だけ使う
- 10本未満の時は「傾向は仮です。あと〇本集めると確かになります」と添える
- 結果は `ティルナノーグ_マイナレッジ/鑑定/リサーチ.md` に日付つきで追記し、次回からコンセプトと投稿の材料にする。前回の結果があれば、変わった所を1行添える
