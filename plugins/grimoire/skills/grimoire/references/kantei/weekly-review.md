# 週次の振り返り（完全版）

週に1回、投稿と導線の数字を見て、来週の型と直す所を決める。数字は利用者の実数だけを使う。

## 手順

1. 利用者に、Threads のインサイトから1週間分の投稿の数字を写してもらう。`.grimoire/assets/kantei/weekly-posts-template.csv` を `ティルナノーグ_マイナレッジ/鑑定/投稿の数字.csv` に写し、1投稿1行で足していく（型は投稿を作った時の型の名前）
2. 導線の数字も聞く（分かる物だけ）: プロフィールを見た人・診断を始めた人・終えた人・LINEのボタンを押した人・LINEに登録した人・有料鑑定を申し込んだ人
3. 道具で表を作る

```
python3 .grimoire/scripts/kantei/weekly_report.py ティルナノーグ_マイナレッジ/鑑定/投稿の数字.csv --from 2026-09-22 --to 2026-09-28 --profile 1200 --diag-start 80 --diag-finish 52 --line-click 30 --line-add 24 --paid 2
```
（数字は例。分からない段は付けない）

4. 表を読んで、「来週やること」を3つ書く
   - 伸びた型：上位の投稿に共通する型・1行目の形。来週はこの型を増やす
   - やめる言い方：下位の投稿に共通する言い方
   - 導線で直す所：前の段から次の段へ進む割合が一番低い所を1つ（例：診断を終えた人は多いのに、LINEのボタンを押す人が少ない → 結果画面のキーワードの案内を上に出す）
5. `ティルナノーグ_制作物/鑑定/YYYY-MM-DD_週次.md` に保存し、伸びた型を `ティルナノーグ_マイナレッジ/鑑定/リサーチ.md` の「自分の伸びた型」に追記する

## 決めごと

- 1週で結論を出しすぎない。型の良し悪しは、同じ型を3本以上出してから判断する
- 数字が少ない週（閲覧が合計数百など）は「傾向は仮」と添える
- 伸びた投稿が安全ルールに近い言い方で伸びていたら、真似せずに言い方を直す
