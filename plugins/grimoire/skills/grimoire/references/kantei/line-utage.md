# LINE の配信（キーワードでタイプ分け＋7通・UTAGE の設置シート）

LINE の配信文と、配信ツールに設置するための一覧を作る。送信・設置は利用者が行う。利用者のパソコンの Claude Code が配信ツールにつながっていて、利用者がはっきり「設置して」と言った時だけ、何を設置するかの一覧を見せて了承をもらってから進める。

## 1. キーワードとタイプ

| タイプ | 診断の結果名 | キーワード | ラベル（タグ） | 自動で返す物 |
|---|---|---|---|---|
| A | | 金運 | 金運タイプ | 手紙版の鑑定（タイプAの内容） |
| B | | | | |
| C | | | | |
| D | | | | |

- キーワードは短く、タイプごとに違う言葉にする（診断ページの `keyword` と同じ）
- キーワードが送られたら、①そのタイプのラベルを付ける ②手紙版を自動で返す ③タイプ別の配信（2.）を始める、の3つが起きるように設置する
- キーワード以外の言葉が送られた時の返事も1つ作る（「診断の結果に出ていたキーワードを送ってください」）

## 2. 配信（7通）

| 通 | いつ | 中身 | 目的 |
|---|---|---|---|
| 0 | 登録直後 | あいさつ＋「診断のキーワードを送ってください」 | キーワードを送ってもらう |
| 1 | キーワード直後 | 手紙版の鑑定（`kantei.md` 手紙版） | 無料の「手紙」を体験してもらう |
| 2 | 翌日 | 見立て：そのタイプの悩みを、発信者はどう見ているか | 見立てに納得してもらう |
| 3 | 3日後 | よくあるつまずきと、今日できる一歩 | 役に立つ体験をしてもらう |
| 4 | 5日後 | 鑑定を受けたお客様の変化（本人の許可がある実例だけ。無ければ「（ここにあなたの実例）」と空ける） | 自分にも起きそうだと思ってもらう |
| 5 | 7日後 | 有料鑑定の案内（中身・分量・価格・申し込み方） | 有料鑑定を知ってもらう |
| 6 | 9日後 | よくある質問に答える（何が分かる／いつ届く／どんな人に向く・向かない） | 迷っている所をなくす |
| 7 | 12日後 | 最後の案内（受付の枠がある時は、本当の枠数だけを書く） | 決めてもらう |

- 1通は300〜600字。話し方は設定のキャラのまま
- 毎日は送らない（解除されやすい）。間隔は利用者の配信の実態に合わせて変えてよい
- 偽の締切・偽の残り枠・「今だけ」の値引きで急がせない。脅し・効果の保証をしない（`safety.md`）
- タイプ別に変えるのは、2〜4通目の見立て・つまずき・実例。0・1・5〜7通目は共通でよい

## 3. 設置シート（UTAGE の例）

UTAGE の LINE 配信には、登録後に順番に送る「シナリオ」、送られた言葉に返す「自動応答」、読者を分ける「ラベル」がある。画面の名前や場所は版によって違うことがあるので、利用者の画面に合わせて読み替える。

| # | 設置する所 | 中身 | 設置した |
|---|---|---|---|
| 1 | ラベル | 金運タイプ・恋愛タイプ…（タイプの数だけ） | □ |
| 2 | 自動応答（キーワード） | キーワードごとに「ラベルを付ける＋手紙版を返す＋タイプ別シナリオを始める」 | □ |
| 3 | 自動応答（それ以外） | キーワードを送ってもらう案内 | □ |
| 4 | シナリオ（共通） | 0通目（登録直後） | □ |
| 5 | シナリオ（タイプ別） | 2〜7通目。タイプの数だけ | □ |
| 6 | 有料鑑定の申し込み先 | 申し込みページ・決済（特定商取引法の表示を確認） | □ |
| 7 | テスト | 自分のLINEで登録→キーワード→手紙版→2通目まで届くか | □ |

Lステップ・LINE公式の管理画面など、別のツールでも同じ3つ（順番の配信・キーワードの自動応答・読者の分類）があれば、同じシートで設置できる。

## 出力

`ティルナノーグ_制作物/鑑定/YYYY-MM-DD_導線/LINE配信.md` に、1.の表・2.の7通の本文（タイプ別の分も）・3.の設置シートを1ファイルで保存する。
