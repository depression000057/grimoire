# LINE の配信（キーワードでタイプ分け＋無料鑑定と同じ日の3通・UTAGE の設置シート）

LINE の配信文と、配信ツールに設置するための一覧を作る。送信・設置は利用者が行う。利用者のパソコンの Claude Code が配信ツールにつながっていて、利用者がはっきり「設置して」と言った時だけ、何を設置するかの一覧を見せて了承をもらってから進める。

## 1. キーワードとタイプ

| タイプ | 診断の結果名 | キーワード | ラベル（タグ） | 自動で返す物 |
|---|---|---|---|---|
| A | | 金運 | 金運タイプ | 手紙版の鑑定（タイプAの内容） |
| B | | | | |
| C | | | | |
| D | | | | |

- キーワードは短く、タイプごとに違う言葉にする（診断ページの `keyword` と同じ）
- キーワードが送られたら、①そのタイプのラベルを付ける ②手紙版を自動で返す ③タイプ別の配信（2.）を始める、の3つが起きるように設置する
- キーワード以外の言葉が送られた時の返事も1つ作る（「診断の結果に出ていたキーワードを送ってください」）

## 2. 配信（無料鑑定と同じ日の3通と、見送った人への連絡）

| 通 | いつ | 中身 | 目的 |
|---|---|---|---|
| 0 | 登録直後 | あいさつ＋「診断のキーワードを送ってください」 | キーワードを送ってもらう |
| 1 | キーワード直後 | 見立て：手紙版の鑑定（`kantei.md` 手紙版）。最初の1通に一番力を入れる | 無料の「手紙」を体験して、見立てに納得してもらう |
| 2 | 1通目と同じ日 | 変わったお客さんの声（本人の許可がある実例だけ。無ければモニターの感想。どちらも無ければ「（ここにあなたの実例）」と空ける） | 自分にも起きそうだと思ってもらう |
| 3 | 無料鑑定と同じ日のうち | 有料鑑定の案内（中身・分量・価格・申し込み方） | 有料鑑定を知ってもらう |

有料の案内を見送った人には、7日で3回以上連絡する。

| 回 | 中身 |
|---|---|
| ① | 思い出してもらう |
| ② | 変わったお客さんの声 |
| ③ | 運気の時期で区切る |

- 1通に役目1つ・リンク1つ
- 有料の案内は、無料鑑定と同じ日のうちに送る。翌日に「昨日の続きですが」と送らない（すでに熱が冷めていて申し込まれないため。添削会で29人に無料案内して申込1件約3%だった原因）。目安は、無料鑑定を受けた人の1割が有料に申し込む
- 買った人には、ラベル（タグ）で目印を付け、すでに買った商品の売り込みを見せない
- 1通目（見立て＝手紙版）は300〜500字（講座の第3回）。1通目以外（2通目・3通目と、見送った人への連絡）は1通300〜600字。話し方は設定のキャラのまま
- 日をまたぐ配信（見送った人への連絡）は、毎日は送らない（解除されやすい）。間隔は利用者の配信の実態に合わせて変えてよい。無料鑑定の日の3通は、同じ日に送る
- 偽の締切・偽の残り枠・「今だけ」の値引きで急がせない。脅し・効果の保証をしない（`safety.md`）
- タイプ別に変えるのは、1通目の見立て（手紙版）と2通目の声。0通目と3通目は共通でよい

## 3. 設置シート（UTAGE の例）

UTAGE の LINE 配信には、登録後に順番に送る「シナリオ」、送られた言葉に返す「自動応答」、読者を分ける「ラベル」がある。画面の名前や場所は版によって違うことがあるので、利用者の画面に合わせて読み替える。

| # | 設置する所 | 中身 | 設置した |
|---|---|---|---|
| 1 | ラベル | 金運タイプ・恋愛タイプ…（タイプの数だけ）と、買った人の目印 | □ |
| 2 | 自動応答（キーワード） | キーワードごとに「ラベルを付ける＋手紙版を返す＋タイプ別シナリオを始める」 | □ |
| 3 | 自動応答（それ以外） | キーワードを送ってもらう案内 | □ |
| 4 | シナリオ（共通） | 0通目（登録直後） | □ |
| 5 | シナリオ（タイプ別） | 2・3通目（無料鑑定と同じ日）と、見送った人への連絡（7日で3回以上。買った人の目印が付いた人には送らない）。タイプの数だけ | □ |
| 6 | 有料鑑定の申し込み先 | 申し込みページ・決済（特定商取引法の表示を確認） | □ |
| 7 | テスト | 自分のLINEで登録→キーワード→手紙版→2・3通目まで、同じ日に届くか | □ |

Lステップ・LINE公式の管理画面など、別のツールでも同じ3つ（順番の配信・キーワードの自動応答・読者の分類）があれば、同じシートで設置できる。

## 出力

`ティルナノーグ_制作物/鑑定/YYYY-MM-DD_導線/LINE配信.md` に、1.の表・2.の配信の本文（同じ日の3通と見送った人への連絡。タイプ別の分も）・3.の設置シートを1ファイルで保存する。
