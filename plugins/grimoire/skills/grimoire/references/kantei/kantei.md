# 鑑定（完全版：数秘術＋タロット／一言・手紙・有料鑑定）

占術は数秘術とタロットの2つ。利用者が「マイ鑑定レシピ」（`gpts-migration.md`）を持っていて「いつもの鑑定で」と言われたら、そのレシピの構成と口調で書く。どの鑑定でも `safety.md` がレシピより優先する。

## 使い分け

| 依頼 | 出す物 | 分量 | 書式 |
|---|---|---|---|
| コメント・LINEの無料鑑定 | 一言鑑定 | 3〜4文・150字以内 | 本文のみ |
| LINE登録直後の無料鑑定・お試し | 手紙版 | 400〜700字 | `.grimoire/assets/kantei/kantei-letter-template.md` |
| 有料：基本の鑑定書 | 鑑定書 | 1,500〜2,500字 | `.grimoire/assets/kantei/kantei-sho-template.md` |
| 有料：1年の流れ | 年運の鑑定書 | 2,500〜4,000字 | `.grimoire/assets/kantei/kantei-year-template.md` |
| 有料：相性 | 相性の鑑定書 | 2,000〜3,000字 | `.grimoire/assets/kantei/kantei-aishou-template.md` |
| 有料：深掘り（相談1つを深く） | 鑑定書＋タロット | 2,000〜3,500字 | `.grimoire/assets/kantei/kantei-sho-template.md` の §4 を厚くし、タロットの節を足す |

無料は「一言」、有料は「手紙（鑑定書）」。分量と深さで差をつける。無料の鑑定でも、テンプレートの言葉だけを並べない。相談者が書いた言葉を1つは必ず拾う（テンプレートを流すだけの無料鑑定は読者に見抜かれる）。

## 数字を出す（数秘術）

必ず道具で計算する（手計算しない）。

```
python3 .grimoire/scripts/kantei/numerology.py 1990-05-15
python3 .grimoire/scripts/kantei/numerology.py 1990-05-15 --year 2027
python3 .grimoire/scripts/kantei/numerology.py 1990-05-15 --months 3
python3 .grimoire/scripts/kantei/numerology.py 1990-05-15 --months 12 --start 2027-01
python3 .grimoire/scripts/kantei/numerology.py 1990-05-15 --partner 1988-11-02
```

| 名前 | 意味 | 読み（`numerology-meanings.md`） |
|---|---|---|
| ライフパス | 生まれ持った性質と、人生で向かう方向 | 表1 |
| 誕生日数 | 人から見えやすい持ち味 | 表1 |
| 個人年 | その年のテーマ | 表2 |
| 個人月 | その月のテーマ | 表3 |
| 二人の数 | 二人でいる時に育ちやすいもの | 表4 |

Python が動かない時は、生年月日の数字を全部足し、2桁なら各桁をまた足して1桁にする（11・22・33 になったらそこで止める）。この時は「手計算です」と添える。

## カードを引く（タロット）

利用者が実物のカードを引いた時は、そのカードと向き（正位置・逆位置）を教えてもらう。引いていない時だけ道具で引く。

```
python3 .grimoire/scripts/kantei/tarot.py                  # 1枚
python3 .grimoire/scripts/kantei/tarot.py --spread 3       # 過去・現在・これから
python3 .grimoire/scripts/kantei/tarot.py --spread 3 --labels 状況,壁,助言
```

読みは `tarot-meanings.md`。カードの意味を並べるのではなく、相談の場面に置き換えて1枚ずつ書き、最後に3枚をつなげて1つの話にする。

## 一言鑑定（コメント返信・LINEの無料鑑定）

- 「あなたの数字 → 持ち味 → 今の時期 → 今日できること1つ」の順
- 相談内容があれば、持ち味を相談に結びつける
- 有料の案内は入れない（入れるのは導線の設計で決めた場所だけ）

例（ライフパス3・個人年3・相談なし）:

```
ライフパス3のあなたは、明るさと言葉で周りの空気を軽くできる人です。今年は「3」の年で、人に見せたり話したりするほど、つながりが広がりやすい時期です。今日、楽しかったことを1つだけ誰かに話してみてください。
```

## 有料鑑定の流れ（フルプロセス）

1. **聞き取り**（1回にまとめて聞く）: 呼び名（仮名でよい）・生年月日・相談内容（いつから・何が一番つらいか・どうなりたいか）・相性なら相手の生年月日と関係・希望の書式
2. **安全の確認**: 相談に命・体・お金・法律の深刻な話があれば、鑑定より先に専門の窓口を案内する（`safety.md`）。占えない相談（病気の結果・裁判の勝ち負けなど）は、占える形（気持ちの整え方・選び方の材料）に言い直して了承をもらう
3. **計算・カード**: 道具で数字を出す／カードを引く。出た値は鑑定書の表にそのまま写す
4. **構成**: 書式の見出しに沿って、各節で何を書くかを1行ずつ決める。相談者が書いた言葉を、どの節で拾うかも決める
5. **執筆**: 数字やカードの説明は、相談者の生活の場面（仕事・家族・恋愛・家事）に置き換えて書く。「これからの〇か月」は、個人月から月ごとに行動を1つずつ
6. **点検**: `safety.md` の点検、数字の写し間違いが無いか（道具の出力と照合）、相談者の言葉を拾えているか、分量
7. **保存と渡し方**: `ティルナノーグ_制作物/鑑定/YYYY-MM-DD_鑑定_A様.md` に保存（ファイル名に本名・生年月日を入れない）。PDFで渡したい時は、Markdownを読みやすい文書に書き出す方法を利用者の環境に合わせて1つ案内する

## 手紙版（無料のお試し・LINE登録直後）

- 400〜700字。「〇〇さんへ」で始まる手紙の形
- ライフパスの持ち味1つ → 今の時期 → 相談への一言 → 今週の一歩 → 「もっと詳しく見たい時は」の一行（導線で決めた有料鑑定の名前）
- 手紙版で全部を言い切らない。有料の鑑定書で深める所（つまずきやすい所の理由・月ごとの流れ）を残す

## 相性の読み方

- 二人のライフパスそれぞれの持ち味とつまずき（表1）を並べ、「ぶつかりやすい場面」と「助け合える場面」を具体的な生活の場面で書く
- 二人の数（表4）を、この関係で育てるとよいものとして書く
- 「相性が悪いから別れたほうがいい」「運命の相手」のような決めつけはしない。関係をどうするかは本人が選ぶ
