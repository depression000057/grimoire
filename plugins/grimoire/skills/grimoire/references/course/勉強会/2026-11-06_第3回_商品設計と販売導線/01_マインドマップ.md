    - ［画像予定］用語の地図：商品の段・クロス・アップ・ダウンの向き
    - 入口の商品（フロント）：最初に買ってもらう、手が出しやすい値段の商品（例：鑑定書・数千円の note）
    - ミドル：入口と本命の間の値段の商品（例：数万円の短期講座）
    - 本命の商品（バック）：一番届けたい・一番売りたい商品（例：サポート付き鑑定・講座）

    - クロスセル：買った人に、早く・楽に成果を出すための別の商品を足して勧めること（例：食事管理に糖質を抑えるサプリ）

    - ダウンセル：買わなかった人に、下の段の手が届く商品を勧めること

    - エバーグリーン：LINE の自動配信などでいつでも自動で売れ続ける仕組み（英語の evergreen＝一年中枯れない常緑の木）
    - 非属人：顔や名前を出さず、架空のキャラでアカウントを運用すること
    - 固定（固定の投稿）：プロフの一番上に固定しておく投稿（無料鑑定の受付などを置く）
    - 潜在層・顕在層：悩みにまだはっきり気づいていない人・悩みに気づいて解決策を探している人
    - グリモワール：この講座で配る AI（あなたの知識や考え方を覚えて育つ）
    - リスト：LINE などに登録してくれた人（連絡が取れる人の数）
    - 成約率：案内した人のうち、買ってくれた人の割合
    - オープンチャット：名前を出さずに入れる LINE のグループの部屋
    - CTA（最後の案内）：投稿の最後に置く「次にしてほしい行動」の一言
    - セールス動画（VSL）：商品を売るための説明の動画
    - Notion：ページを作れる無料の道具（LINE の手前の案内ページに使う）
    - LINE のタグ：登録した人に付ける目印（買った人・まだの人を分ける）
- 1. マインド：お金をいただいていい
  - 納品物に「ありがとう」と言われれば仕事になる
  - 未経験でも感謝される商品は作れる
    - 鑑定＝悩みへの答え＋行動のきっかけ
      - つまり：悩みに答えて動けるきっかけを渡す→「ありがとう」が返る・例）今夜レシートを分ける
  - 自信のなさは画面越しに伝わる
  - 自信のなさから安くするのはやめる
    - 意図ある低単価はOK：500円→5,000円→個別相談20万円
      - つまり：安い商品で人を集め次の商品につなぐ目的の低単価・500円→5,000円→20万円と段を上がる
    - 5件・10件こなしたら値上げする
      - なぜ：言ったとおりに上げると「早く買った方が得」が伝わる・値下げはしない
  - 値段＝責任の重さ・安売りで入口を広げない
    - なぜ：安すぎると本気度の低い人まで来る（講師の考え）
  - 悩みが深いほど払うハードルは下がる・金額＝「覚悟の金額」
    - つまり：深い悩みの人ほど「本気で変わりたい」→払う額がその覚悟の大きさ（講師の考え）
  - 「楽に稼ぎたい」は手放す・仕組み化しても最後は人の目
    - つまり：仕組み化＝自動の配信や AI で手間を減らすこと・最後は人の目＝送る前に自分で読んで確かめる
  - 完璧主義の対策：先に締切を決めて発信で宣言する
  - マインドの実例
    - 講師 さんの例
      - 1万円未満でも満足してもらえるか不安な状態
      - 2万9,800円で100部・0時ちょうど・300万円
        - つまり：2万9,800円の商品で、目標の100部に販売開始の夜0時ちょうどに届いた
      - 本人の言葉：「商品自体は変わってない」
    - オンライン秘書の受講生の例：本業まとめ note 9万円→2作目30万円
    - 副業 note の例：20冊売れるごとに2,000円値上げ・値下げなし
    - 更年期・ダイエットの例
      - 無料 note の次に1,000円弱の有料 note を用意
      - 払う人は本気・数百円だと本気度の低い人まで来る（講師の考え）
      - 払う意志の境目：「3桁か4桁か」
        - つまり：3桁＝100円台・4桁＝1,000円台の値段
    - 投資スクールの例：「数千円の節約を喜ぶ人が、数十万円を払うか」→買える層を集める
      - つまり：数千円の節約を喜ぶ人は数十万円の商品を買いにくい→最初から買える人に向けて発信する
    - 育児の例：産後うつの最中は自分への出費に罪悪感→売る時期を選ぶ
- 2. 商品とは何か
  - 情報ではなく変化を売る
    - 例）「数秘の読み方」（情報）より「月末に通帳を開くのが怖くなくなる」（変化）（〔サンプル〕）
    - ［画像予定］買う前と後：知る・できる・気持ち・行動・結果
    - 例）ふく江さんの5行：知る＝お金が残らない理由／できる＝自分で出口を見つける／気持ち＝月末が怖くない／行動＝毎晩レシートを分ける／結果＝月末にお金が残る
  - 手段より、その先の嬉しい未来を見せる
    - ヒーリングのやり方の説明は不要
    - 「受けた後どうなるか」を先に伝える
    - 「水道水でも10万円」（講師のたとえ）：言い切れる未来があれば手段は問わない
      - つまり：水道水でも「飲むとこうなる」と言い切れれば売れる・欲しいのは手段ではなくその先の変化（講師のたとえ）
  - 届け方と伝え方
    - 商品の届け方はほぼ被る
      - 占い：鑑定・ヒーリング
      - 稼ぐ系：note・Brain・Tips（コンテンツ販売サイト）・動画
        - つまり：note・Brain・Tips＝どれも文章のコンテンツを売り買いできるサイト
      - 高単価の売り方：セミナー・セールス動画・ウェビナー
    - 差がつくのは伝え方（ローンチコンセプト）
      - つまり：ローンチコンセプト＝同じ商品を「誰の・どんな悩みを・どんな未来に」と打ち出す切り口（講師の呼び方）
    - 伝え方の決め手：相手の現在地（悩みに気づいたばかりか・解決策を探しているか）
      - つまり：気づいたばかりの人（潜在層）には「なぜ必要か」から・探している人（顕在層）には「やり方」から
      - Threads 占いを始めたい人：「伸びる型」の話が届く
      - 副業を探し始めた人：「なぜ Threads 占いか」から伝える
      - AI 未経験の人：Claude Code の話は届かない
    - 年代で言葉を選ぶ：20〜30代は「HSP」・50代は「繊細さん」
      - つまり：HSP＝刺激に敏感で疲れやすい気質を表す言葉・若い世代には通じても50代には「繊細さん」の方が届く
    - 距離が合えば拙い文章でも刺さる
      - つまり：距離＝相手の今いる場所との近さ・文章の上手さより相手の言葉で話せているか
    - 伝え方の組み立て
      - ［画像予定］伝え方の組み立て（5つの順番）
      - 今ある悩み（毎日モヤモヤ・周りが幸せそうに見える）
      - 具体の場面（タイムセールの牛肉は買えず豚バラ肉を選ぶ）
      - あなたのせいではない・うまくいかない考え方のくせ
        - 例）頑張っても報われないと思い込むくせ（〔サンプル〕）
      - 悩みの原因
      - 解決の手段（ヒーリングなど）
    - 変化の物語（どんな状態からどうなれたか）は強い
    - ［画像予定］同じ商品・3つの伝え方（手段の名前→悩みの場面→なりたい未来）（サンプル）
      - 例）占い：金運鑑定 → 今月お金が出ていく日を先に知る鑑定 → 月末に通帳を開くのが怖くなくなる7日間
      - 例）育児：子育て講座 → イライラした日の声かけ集 → 子どもにイライラしなくて済む毎日
      - 例）ダイエット：ダイエット講座 → 食べすぎた翌日の戻し方 → もう一度自分を取り戻すセカンドライフ
      - 例）恋愛：恋愛相談 → 既読スルーされた時の返し方 → 愛されている自分に戻る1か月
      - 例）投資：投資の基本講座 → 年収400万円でも貯まる仕組み → お金の不安で眠れない夜を終わらせる
    - 呼び方を変える：「個別相談会」→「収入アップアクション作成会」（売り込み感を消す）
      - つまり：個別相談会＝話を聞いて商品を案内する場・呼び方を変えると売り込まれる不安が減る（在宅ワーク勉強会の設計）
  - ［画像予定］アカウント・発信・商品の三角形
    - ［画像予定］ずれた例と合った例：巫女キャラの商品
      - ずれた例：巫女キャラ→AI 講座（キャラと商品が合わない）
      - 例）合った例：巫女キャラ→お守りの言葉の鑑定（キャラの世界観のまま）（〔サンプル〕）
  - 1行で言えるか：「◯◯で悩む人向けの△△」
    - 例）お金がすぐ出ていく人向け・生年月日でお金の出口を見る占い師（10章のふく江さん）（サンプル）
    - 例）寝かしつけに疲れたママ向け・夜の流れを整える先輩ママ（サンプル）
    - 例）既読スルーに悩む30代向け・返信が来る送り方を教える恋愛相談員（サンプル）
  - 基準：30秒の説明で「ください」と言われるか
  - 期待の契約：投稿で作った期待を商品で返す
    - つまり：投稿で「これが分かる」と期待させたら、その中身を商品で返す約束・返せないと満足されない
    - ［画像予定］期待の契約：合っている例とずれている例
    - 例）一致：投稿「今月お金が出ていきやすい日」→商品「あなたの今月の出ていく日と対策」
    - 例）不一致：同じ投稿→商品が性格診断だけ
  - 個性がお客さんの良い変化につながらないと続けて買われない
    - つまり：キャラが面白くても、買った人の悩みが良くならなければ2回目は買われない
  - 商品が未定→プロフも投稿も軸がぶれる
  - ジャンル別の実例
    - ダイエットの例：普通の減量に100万円は払わない→「もう一度自分を取り戻す」がゴール・中身は自己啓発
    - 副業の例：「ウェブデザイン」という手段の訴求は伸びず、一つ上の「在宅ワーク」にする
    - 美容の例：成分名だけでなく「塗る順番＋具体的な商品名」まで示す
    - 投資の例：男性向けは「信用できる情報」・女性向けは「発信者への憧れ」
    - コーチングの例：「自己理解」では集まらない→「自分って何者？」の悩みから入る
    - 手法の名前だけでは売りにくい
      - 例）「個性心理学で見る60タイプ」→「自分の取扱説明書：疲れやすい場面と立て直し方」にする
- 3. 何を売るか
  - HARMの法則：売れる悩みを4つに分ける
    - ［画像予定］HARMの4つの悩みと売れている商品
    - H＝Health（健康）：体・見た目・年齢・睡眠の悩み
    - A＝Ambition（夢・仕事）：学び・資格・転職・自分を高めたい悩み
    - R＝Relation（人間関係）：恋愛・夫婦・家族・子育て・職場の悩み
    - M＝Money（お金）：収入・節約・貯金・お金の不安
    - つまり：本人が人に言いにくい悩みを4つに分けた物・自分の商品がどの悩みに答えるかを確かめる道具
    - 使い方：4つから1つに決める・2つ目は要る時だけ
    - 例）占いの相談を4つに分けると：恋愛・相性＝R／金運＝M／体調・心＝H／仕事・転職＝A
    - ［画像予定］ずれた例と合った例：悩みが見えない商品／悩みに答える商品
      - ×：「よく当たるタロット鑑定」→何の悩みが解けるか見えない
      - ○：「既読のまま返事が来ない理由が分かる相性鑑定」→R（恋愛）の悩みにそのまま答える
      - 違い：商品の名前に4つのどの悩みに答えるかが出ているか
    - HARMごとの売れている商品の例
      - H・ダイエットの例：無料 note から1,000円弱の有料 note（払う人かは3桁か4桁で決まる）
      - H・美容の例：投稿の柱→プロフ→LINE→動画→個別面談
      - H・運動の例：40〜75歳の女性向けフィットネスの月額コミュニティ（海外・月約37ドル）
      - H の注意：効き目を言い切らない（薬機法）
      - A・資格の例：資格の講座 39,800円（行政書士の民法・Tips）
      - A・オンライン秘書の例：自分の仕事の note→AI スライドの note・過去の note が毎月売れる
      - R・恋愛の例：note・LINE・相談・講座・恋愛の有料記事の中央値9,980円（Tips の上位60件中24件）
      - R・育児の例：note のメンバーシップ（月額）・note の急上昇でメンバーシップ1位が育児
      - R・夫婦の例：深い悩みは刺さるが共感だけで集めたリストは売れにくい
      - M・家計の例：ポイ活の note 100〜500円→2万9,800円の note
      - M・投資の例：口座の紹介＋教育 note・個別の銘柄は勧めない（金商法）
      - M・副業の例：1万円以下の note→買った人だけの LINE で2〜3か月の短期講座
  - ［画像予定］商品へ案内している人が多いジャンル（11/6・バズレコ）
    - つまり：伸びた投稿を集めた人のうち、投稿やプロフから商品・LINE へ案内している人の数・売上の数ではない
    - 多いジャンル：引き寄せ166人・ダイエット152人・自己啓発142人・星占い・タロット137人・金運117人・AIの使い方113人・恋愛112人
    - HARM別の割合：A 67%・M 66%・占いスピ 65%・H 61%・R 43%・暮らし・ペット・趣味 32%
    - Threads で伸びた投稿が多いジャンル：引き寄せ434本・金運426本・家事・住まい201本・ダイエット192本・人間関係186本・星占い・タロット157本
    - つまり：Threads は占いスピ・暮らし・人間関係が伸びやすい・X は占いスピ・自己啓発・ダイエットが多い
    - 狙い目の仮説：Threads で伸びているのに案内している人が少ない→人間関係37%・夫婦・家族34%・受験・不登校35%・家事・住まい28%
    - 本で買われているテーマ（Amazon の売れ筋の題名に多い言葉・11/6）：金運＝神社・開運／引き寄せ＝潜在意識・言霊・お金／ダイエット＝ヨガ・ピラティス・薬膳／夫婦＝離婚・財産／介護＝脳トレ・介護予防
    - 講座で学ぶ人が多いテーマ（Udemy の受講者数・世界・英語のページ）：AIの使い方 約562万人・SNSマーケ 約453万人・人前で話す 約400万人・瞑想 約192万人・タロット 約37万人
    - ジャンルの選び方：①Threads で伸びるか ②商品へ案内している人がいるか ③本や講座にお金が払われているか
  - 占い・スピの商品の種類
    - 鑑定書（文章で納品）
    - チャット・通話の鑑定
    - ヒーリング
    - note・読み物
    - 継続のサポート・講座
  - 目に見える物は伝わりやすい・見えない物はコンセプト次第
  - 占いは事前の商品作りが不要
    - 悩み・生年月日が最初から手元にある
    - 答えて文章で送るだけで商品になる
    - 最初の1本は鑑定が作りやすい
  - 占いの note は鑑定と分ける・王道は「自分の取扱説明書」（星座・誕生月・何日生まれ・血液型）
  - 有料鑑定の後に続く note は伸びにくい→別の鑑定か別商品にする
  - 恋愛に特化：母数は減るが悩みが深く単価を上げやすい
  - 手持ちのスキル×スピの意味づけ＝講座（ゼンタングル・マンダラ豆皿）
  - 占術ごとの役目：1枚引き（入口）→四柱推命で1年（本命の鑑定）・年末は1年の鑑定を出しやすい時期
    - つまり：1枚引き＝タロットを1枚だけ引く手軽な占い・四柱推命＝生年月日から1年の流れなどを見る占い
  - 占いを入口にして、後ろの自分の商品へつなぐ
  - ジャンル別の実例
    - 育児の例：有料 note より紹介（楽天・おもちゃのサブスク）が多い・無料のレビュー note→紹介リンク
    - 育児の例：「わが子の取説」→取説鑑定（松竹梅）→個別相談の案
    - 美容の例：楽天の紹介が中心・無料で信頼を作る→紹介商品を買ってもらう
    - 投資の例：口座開設の紹介＋教育 note・節約したい層は売れにくい・個別株に関心のある層（相談）
    - 恋愛の例：恋愛の次は夫婦関係（穴場）
    - 副業の例：1万円以下の note→購入者限定 LINE で2〜3か月の短期講座（初回はモニター価格）
  - 最初は商品を1つに絞る
    - よくある失敗：長文を一気に書き切る・複数を同時に作る
  - まず1対1で売る→型が見えたら商品化する
  - 作る前に需要を確かめる：投稿の反応・DM・無料 note の「興味あり」
- 4. 商品の並べ方と売り方
  - ［画像予定］商品の階段：無料→入口→ミドル→本命→その上
  - 階段の組み方：本命を決めてから入口を逆算（始めは鑑定1本でよい）
    - 例）先に本命（3万円のサポート付き鑑定）を決め、手前の入口（数千円の鑑定書）を決める
  - クロスセルとアップセルの違い（講師の考え）
    - アップセル：伴走・サポート
    - クロスセル：早く・楽に成果を出すオプション
    - ［画像予定］クロスセル・アップセル・ダウンセル
      - ダイエットの例：体質診断→食事管理（アップセル）→糖質を抑えるサプリ（クロスセル）
        - なぜ：食事管理＝伴走なので上の段（アップセル）・サプリ＝早く楽にする足し物なので横（クロスセル）
      - 美容の例：化粧水→導入美容液（クロスセル）
      - 占いの例：鑑定→サポート（アップセル）→パワーストーン・アロマ（クロスセル）
  - ［画像予定］売り方の5つの型
    - A 低単価だけで売る
    - B クロスセル
    - C アップセル
    - D 入口・ミドル・本命の3段
    - E 高単価を直接売る
  - A 低単価だけで売る
    - 中身：数千円以下の note・鑑定を本数で売る
    - 向く時：毎日の閲覧数が多い・悩みを細分化できる・サポートなしにしたい
    - 向かない時：大きく稼ぎたい（低単価だけで年商1億は基本無理）
      - つまり：年商＝1年間の売上の合計・安い商品だけだと、たくさん売り続けないと届かない
    - 導線：投稿→プロフ・固定→有料 note→本数を増やしてマガジン化
    - 夫婦関係 note の例：毎日10万表示・累計80万円（本人の申告）
    - 同じ発信者の例：全18本を有料化して売上3倍（本人の申告）
    - 講師 さんのポイ活 note の例：100〜500円で月10万円
    - よくある失敗：集客が止まると売上も止まる
  - B クロスセル
    - 中身：買った人に案内する、早く・楽に成果を出すための別の商品
    - 向く時：悩みが1つで終わらない（家族・恋愛・体質）
    - 導線：購入者限定 LINE（タグ分け）→購入前提の次の1本を案内
      - つまり：タグ分け＝LINE で買った人に目印を付け、買った人だけに次の案内を送る
    - 家族鑑定の例：本人→夫・子ども・親の分
    - 少額→少額の例：1本目を買った人に2本目・2本を買った人に3本目
    - マガジンの例：単体合計の6〜7割の価格でセット売り
    - 講師の例：メイン購入者に24時間限定で同価格帯の別商品を案内
    - よくある失敗：並べすぎ（3つ目から成約率低下）・売り込み連発による疲弊
      - つまり：成約率＝案内した人のうち買った人の割合・3つ目から下がる（外部記事の検証）・売り込みが続くと売る人も買う人も疲れる
  - C アップセル
    - 中身：満足した直後に上の段（続き・伴走）を案内
      - 入口で全部出さない：範囲・字数で線を引く
      - 鑑定書の最後に「次に深く見られるテーマ」を書いて橋にする
      - 案内は卒業の時か変化が出始めた頃・「続き」として案内する
      - ［画像予定］ずれた例と合った例：脅す案内／続きの案内
        - ×：「買わないと効果が出ません」
        - ○：変化を一緒に振り返り「ここから先の続きはこちら」
        - 違い：満足した直後に続きとして出すと押し売りにならない
    - 向く時：「やり方は分かったが一人では無理」な状態を作れている
    - 向かない時：入口で全部出し切る（1万円で完結すると本命が売れない）
    - 導線：無料鑑定→有料鑑定→最後に上の段を案内・購入者限定 LINE で案内
    - 講師の例：入口4,000円→1万円の上の段は売れない（差が小さい）・2〜3万円や5万円でも売れる
    - ちょい足しの例：ヒーリング＋1か月のチャットサポート
    - ダウンセル：見送った人へ下の段を案内
      - 例）占いのダウンセル：サポート付き鑑定を見送った人に単発の鑑定書
      - よくある失敗：見送った人に何も案内しない
    - よくある失敗：価格差が小さい・入口で出し切る・「買わないと効果が出ない」と脅す
  - D 入口・ミドル・本命の3段
    - ［画像予定］入口・ミドル・本命の3段
      - 入口の商品：数千円
      - ミドル：数万〜15万円
      - 本命の商品：30万円〜（講座・スクールの場合）
    - ミドルの役割：本命を売らない時期に年2〜3回売る・3段を同時には出さない
      - つまり：本命を売っていない時期の売上を作る役（講師が紹介した考え方）
    - 最初は本命1つ＋入口の商品1つで十分
    - 導線：入口で LINE 集客→ステップ配信でミドル・本命・全て組んでから発信開始
      - つまり：全て＝入口・ミドル・本命の商品と LINE の配信の流れ・先に組んでおくと集まった人をそのまま次の段へ案内できる
    - AI 講座の例：5,000円 note→3万円講座→2日間セミナー→30万円コンサル
    - 恋愛の例：note 3,000円→動画2万円→マンツーマン講習20万円（記事内の作例）
    - 恋愛占いの例：入口は復縁・本命は女磨き（つながれば何でも売れる）
    - 占い師向け講座の例：無料特典→竹39,800円→松98,000円
    - よくある失敗：価格の段差を空けすぎる
      - 講師の例：5万円の次が70万円ぐらい→引き上がらず間に1段追加
      - ［画像予定］ずれた例と合った例：段が離れすぎ／手が届く段
        - ×：5万円の次がいきなり70万円→上がる人が出ない
        - ○：間に1段置く→次の段が手の届く高さ
        - 違い：一段ずつなら上がれる
      - 目安：上の段は入口の2〜5倍が一般的・講師の例では4,000円の次に10倍の5万円でも売れた
    - よくある失敗：全商品を同時に案内する
  - E 高単価を直接売る
    - 中身：オープンチャット・セミナー・動画で教育→個別相談で数十万〜100万円
      - つまり：教育＝買う前に、なぜ必要か・どうすれば良くなるかを知ってもらうこと
    - 向く時：悩みが深い・伴走が必須（ダイエット・健康・育児・副業）・個別相談ができる
    - 鉄板の導線：Threads（複数アカウント）→Notion→オープンチャットで約1か月教育→セミナー→個別相談
      - つまり：複数のアカウントで人を集める→Notion の案内ページ→オープンチャットで1か月かけて信頼→セミナー→個別相談で申し込み
      - ［画像予定］高単価の鉄板の導線
      - いきなり個別相談の申込は怖がられる→説明の動画1本と担当の自己紹介を先に
    - ダイエットの例：数千人のオープンチャット→3日間のセミナー→100万円前後が数百件成約
      - 反省点：個別相談の作り込み不足・見送った人への別案内なし
    - オープンチャットの工夫：朝食の報告を投稿し合う・音声配信で仲間意識を作る
    - 副業の例：LINE→個別相談で30万円ぐらい
    - 営業代行スクールの例：「営業代行」と出さず「在宅で月数十万」と訴求
    - よくある失敗：個別相談の作り込み不足・ダウンセルなし
  - ローンチとエバーグリーンの組み合わせ
    - ［画像予定］ローンチ＝お祭り／エバーグリーン＝自動販売
    - 目安：ローンチの売上の2〜3割が毎月エバーグリーンで入る状態
      - 例）ローンチで100万円売れたら、毎月20万〜30万円が自動で入る状態（〔サンプル〕）
    - 講師の例：3日で1,300万円→仕組みで毎月300万円ぐらい→累計7,000万円以上
    - 講師の例：2〜3年前の note が今も売れ続けている
    - エバーグリーンで土台・2〜3か月に1回ローンチ
    - エバーグリーンで鑑定を売るなら LINE・ローンチならオープンチャット
      - なぜ：鑑定はいつでも1対1で受けられる→LINE の自動配信・ローンチは盛り上がりが要る→みんなが集まるオープンチャット
    - 同じオープンチャット・同じ構成に新ネタを1〜2割足して繰り返す・2回目3回目で買う人もいる
    - ローンチの目安：普通300万円・刺さって500万円・ぶっ刺さって1,000万円
    - 1,000万円売れたら商品を増やして取りこぼしを防ぐ→3,000万円へ
    - コンセプトの当たり外れは3回やると見える
    - 自動で売る仕組みは2週目まで売れて3週目から落ちる
      - つまり：自動配信での売上が3週目から落ちる→時々ローンチを打って補う（外部記事の考え）
    - 商品を出しただけの状態＝「リリース」
      - つまり：リリース＝予告や教育なしに出すだけ・ローンチ＝期間を決めて予告・教育してから売る
    - よくある失敗：サポートに追われてローンチが打てない・1回出して放置
    - エバーグリーンの組み方
      - 商品ごとに LINE のステップ配信を作る
      - ステップ7通＋定期のセールスを自動で送る
      - 3〜4回目の案内で買う人もいる
      - 期限は登録した日から一人ずつ・過ぎたら静かに元の値段・「二度と買えない」と言わない
  - 始め方：まず鑑定1本で反応を見る→売れ始めたら本命を決めて階段を作る
    - 分かれ目：高単価から始めてよい時＝恋愛・占いスピ・流行りのテーマ・リスト1,000人以上・コアなファンがいる・それ以外は低単価から
- 5. 値段の決め方
  - 値段の決め方は3つ：原価から／競合から／お客さんが得る価値から（一番大事）
    - ［画像予定］ずれた例と合った例：原価で決める／変化で決める
      - ×：「原価がかからないから安くする」
      - ○：「この人の何が変わるか」で決める
      - 違い：文章や鑑定は原価がほぼ0・値段の元は買った人に起きる変化
    - 価値は3つ：お金の価値・時間の価値・気持ちの価値
    - 例）お金の価値：毎月1万円の使いすぎが止まる×12か月＝12万円（ふく江さんの本命）
    - 例）時間の価値：3年かかる遠回りが3か月になる
    - 例）気持ちの価値：月末に通帳を開くのが怖くなくなる
    - 値段の目安：お客さんが得る価値の一部（例：価値120万円の4分の1で30万円）
  - 値段の帯は3つ
    - 3万円未満：多くの人に届ける・リストを集める
    - 3万〜30万円：本気の人にしっかり届ける
    - 30万円以上：少数の真剣な人に一番手厚く
  - 同じ月30万円でも：3,000円×100件／3万円×10人→必要な人数が10分の1
  - 時給で見る：例）鑑定書5,980円に3時間＝時給約2,000円・1か月の伴走3万円に月4時間＝時給7,500円
  - ［画像予定］目標からの逆算：3,000円×100件＝月30万円
    - つまり：3,000円＝鑑定1回の値段・100件＝1か月に売る件数→安いと数をこなす必要がある
  - 9,800円でも低単価・安すぎると価値まで低く見られる
    - つまり：初心者には高く見えても、3万〜5万円のサポート付き鑑定と比べると低い（講師の考え）
    - 例外：LINE 集客用の100円 note
  - 鑑定は3万〜5万円から・後ろに1〜6か月のサポートを付け期間で単価を上げる
  - 本命の商品の価格目安
    - 非属人（顔や名前を出さない架空キャラ運用）：10万〜20万円まで
    - 本命で売りやすい値段：14万8,000円
      - つまり：講師の経験で売りやすかった値段の目安
    - 動画教材だけで売れる上限：19万8,000円まで
    - 30万円以上：サポートが要る
  - 本命を期間で松竹梅にする例：1か月12万円・3か月14万8,000円・6か月30万円
  - 値段＝距離の近さ・見守る伴走ほど高単価
    - つまり：距離＝売り手とお客さんの関わりの近さ・伴走＝一定の期間、個別に相談に乗り進み具合を見ること
  - note だけだと月10万〜20万円で止まりやすい・月100万円の人は「6か月30万」の伴走あり
  - サポートの重さ：「稼ぐ」系は重い・整う／できるようになる系は軽い
  - Threads の特徴：初心者が多く、購買力がある
  - 最初の有料化は小さく始める：PayPay 送金リンクで5,000円など
    - つまり：PayPay の送金リンク＝リンクを送るだけで払ってもらえる・ネットショップを作らずに始められる
  - ジャンル別の価格例
    - 恋愛の例：講習やアプリのコンサルは数十万円も普通（相談）
    - スポーツ指導の例：1時間で数万円・半年で数十万円
    - 在宅ワークの例：半年で数十万円の伴走
    - AI 商品の例：中身が見えるスキル系は3万〜5万円
    - 協会ビジネスの例：認定講師の資格で25万円ぐらい
  - 迷った時の決め方4手順
    - 競合を3件調べる
    - 変化の大きさとサポートの重さで価格帯を決める
    - 初回は相場の1/3〜1/2で実績を作る
    - 実績がついたら値上げする
  - 商品の中身を決める順：誰向け→どこまで→期間→サポート→最後に料金
  - ［画像予定］占いの値段の階段
    - 入口の商品：鑑定書の梅2,980円・竹5,980円・松9,800円（グリモワールのおすすめ）
    - 本命の商品：サポート付き鑑定 3万〜5万円から
    - その上：長期サポート 19万8,000円まで
  - 見せる順番：本命の値段を先に見せてから入口を出すと安く感じる
    - ［画像予定］ずれた例と合った例：入口の値段だけ見せる／本命を先に見せる
      - ×：鑑定書5,980円だけを見せる→高いかどうか比べる物がない
      - ○：先に「1か月のサポート3万円」→次に「鑑定書5,980円」→手が届く値段に見える
      - 違い：人は値段を横に並んだ値段と比べて決める
    - 注意：本当には無い「通常価格」を作らない（不当表示のおそれ）
  - 値引きはしない・無料にするのはもっとダメ
    - なぜ：値引きが効くのは迷いの最後だけ・無料にしたら申込は少し増えても成約が半分に落ちた例
    - 使うなら：個別相談の後まで取っておき理由と一緒に出す
    - ［画像予定］ずれた例と合った例：値下げで売る／値段を守って背中を押す
      - ×：売れないから値下げする→前に買った人の信頼が落ちる
      - ○：値段は守る・特典と本当の期限で背中を押す
      - 違い：値段を守ると早く買った人が損をしない
  - 限定は本当の時だけ・「再販しない」と言ったら守る
  - 分割はクレジットカードの分割だけ・一括の方がお得と書く・銀行振込の分割は約束しない
  - 入口の商品の役目は3つ：自動で入る売上・高い商品を見送った人の受け皿・サポートを持たない商品
  - 入口の目安：500〜3,000円・読み切れる量
  - 世の中の相場（10/17 の講師の調べ）
    - 恋愛の有料記事：中央値9,980円（Tips）
    - note の有料記事：上位2割の平均 実用1,842円・読み物983円
    - ビジネスのノウハウ（Brain）：中央値 約3,500円
    - 電話占い：1分200〜500円（払う人の値段）
    - 資格の講座：39,800円の例（Tips）
    - 海外の月額コミュニティ：月29〜199ドルが多い（Skool）
- 6. 松竹梅
  - 松竹梅は全部買ってもらう物ではない・「買わない」を減らして真ん中を選んでもらう
    - なぜ：3つあると「買う・買わない」ではなく「どれにするか」で考えてもらえる
  - 2つだと迷いやすい→3つにする
  - 梅はあえて一番物足りなくする
    - なぜ：梅を物足りなくすると、竹・松を選んでもらいやすい
    - ［画像予定］ずれた例と合った例：豪華な梅／物足りない梅
      - ×：梅にも占術3つ・1年の見通し→竹・松を選ぶ理由が消える
      - ○：梅は相談1つ・今月だけ→もっと知りたい人が竹へ
      - 違い：梅の役目は竹と松を選びやすくすること
    - 削るのは：占術・相談の数と見通しの期間
  - プランごとに「こんな人向け」を書く
  - 上のプランは下を丸ごと含む・「通常◯円」は使わない
    - つまり：「通常◯円」＝元の値段を高く見せて、今の値段を安く見せる書き方
  - 差のつけ方：量・深さ・期間・その人専用か
    - 量：占術の数・相談の数・字数
