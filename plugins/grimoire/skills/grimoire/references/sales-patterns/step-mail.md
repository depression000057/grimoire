# step-mail — ステップメール・ローンチ配信の型

目次: 1 型の選び方／2 M1 7日16通の販売配信／3 そのほかの型（M2 4通の教育配信・M3 2〜4週間の販売企画の全体・M4 無料企画の7つの並び）／4 送る時刻と通数の原則／5 1通の組み立て

使い方: 登録してくれた人へ順番に送る配信を、型の日程と役割どおりに組む。1通ずつの役割を設計シートの「枠の表」に並べてから書く。メールでも LINE でも同じ型を使える（LINE は1通を短く分ける）。

## 1 型の選び方

| 条件 | 型 |
|---|---|
| 無料の動画や記事を数日かけて公開し、最後に商品を案内する | M1 |
| 通数を少なく、1通ずつ役割をはっきり分けたい・常設の配信 | M2 |
| 登録後の最初の数通だけ整えたい | §4 の原則だけ使う |
| 投稿・無料企画・配信を組み合わせて、2〜4週間かけて1つの商品を売る | M3（その中の配信に M1、無料企画に M4） |
| 無料の動画・音声・資料の中身の並びを決めたい | M4 |

## 2 M1 7日16通の販売配信

流れ: 1〜4日目は毎日1本ずつ無料の教材（動画など）を公開し、1本ごとに伝える教育を変える（`education.md`）。5日目は販売の準備、6日目に販売を始め、7日目で締める。

| 通 | 枠 | 送る時 | 公開するもの・目的 | 入れる要素 |
|---|---|---|---|---|
| 1 | 1日目1通目 | 登録直後 | 教材1（書き手を信じてもらう・目指す姿を見せる） | 目を止める件名、書き手の短い紹介（持っている事実だけ）、読者の今への共感、教材1で分かること、見てもらう誘導、追伸で次回の予告 |
| 2 | 1日目2通目 | 登録の半日後 |  | 教材1の要点の要約、見た人の感想（実際に届いた物だけ）、まだの人への再案内、次の教材の予告 |
| 3 | 2日目1通目 | 翌朝 | 教材2（うまくいかない原因に気づいてもらう） | 前向きな件名、教材1の最後の案内、教材2の公開、痛い所に触れる予告、追伸で次への布石 |
| 4 | 2日目2通目 | 夜 |  | 好奇心を突く件名、教材2の核心の一部、今と理想の差、実際の事例、質問の受付、次で解決策を出す予告 |
| 5 | 3日目1通目 | 朝 | 教材3（解決の手段を示す） | 解決を予感させる件名、教材2の復習、教材3の公開、うまくいった後の姿 |
| 6 | 3日目2通目 | 夜 |  | 教材3の中身を数字と事例で（実際にある物だけ）、個別の質問の案内 |
| 7 | 4日目1通目 | 朝 | 教材4（学びにお金と時間を使う意味を示す） | 教材3の再案内、教材4の公開、学びに投資する意味 |
| 8 | 4日目2通目 | 夜 |  | 教材4の要点、投資と返ってくるものの関係、翌日の案内の予告 |
| 9 | 5日目1通目 | 朝 | 販売の準備 | 4本の総まとめ、読者の未来の姿、翌日の案内への期待、質問と不安の受付 |
| 10 | 5日目2通目 | 夜 |  | 価値の総まとめ、案内の一部を先に見せる、翌日の時間割 |
| 11 | 6日目1通目 | 朝 | 販売開始 | 販売ページへの道、案内の中身と他との違い、実際の事例、期限（本当に決めている物だけ） |
| 12 | 6日目2通目 | 昼 |  | 内容・特典・保証の詳細、価格の理由、よくある質問、買った後の進め方 |
| 13 | 6日目3通目 | 夜 |  | 事例を別の角度から、行動しない場合に続く毎日（生活の場面で・脅さない）、翌日の締めの予告 |
| 14 | 7日目1通目 | 朝 | 最終日 | 最終日であること、特典の締め時刻、事例 |
| 15 | 7日目2通目 | 昼 |  | 締めまでの時間、迷っている人の不安を1つずつほどく、買った後の道のり |
| 16 | 7日目3通目 | 夜 |  | 最後の案内、価値のまとめ、質問への答え、感謝と次の案内（締めた後の案内がある時だけ） |

M1 を使う時の注意:
- 設計シートの枠の表は1通を1行にし、枠の名前は上の表の「枠」の列（〈日〉日目〈通〉通目・通は日ごとの番号）をそのまま使う。本文の見出しも同じ名前にする。入れなかった要素は、その行の「飛ばした理由」に要素の名前と理由を書く。§5 の1通の組み立ては全通に共通なので、枠の表には入れない。送る時と件名の種類は、その行の中身の列に書く
- 教材1〜4の役割（目指す姿・原因・手段・お金と時間を使う意味）は配信の設計なので、そのまま書いてよい。教材で話す具体（例に出すこと・手順・数字）が依頼に無い時は、予告と要約を役割の言い方にとどめ、具体は `【書き手が記入: 〜】` にする。役割を置いたことは出力④の「仮で置いた前提」に並べる
- 「痛い所に触れる予告」「好奇心を突く件名」は、教材の中身を言わずに、読者がすでに気にしていること（読者の今の状態）で書く。「教材3の中身を数字と事例で」は、依頼に数字と事例が無ければ記入欄にする
- 件名の種類は §5 の一覧から選ぶ（表の「目を止める件名」は驚きか好奇心、「前向きな件名」は解決の予感に当たる）
- 1通で読んでほしい行動は1つ（見る・申し込む など）。質問の受付や再案内は、行動ではなく案内として添えてよい
- 無料の教材と商品の関係（別物か、一部を公開した物か）が依頼に無い時は、記入欄で確かめてもらう
- 翌日の送る時刻（朝・昼・夜）は配信の設計なので本文に書いてよい。出力④の「仮で置いた前提」に並べる
- 7通版で送らない通の中身（価格の理由・質問と答え・特典や保証）は、販売ページに載せるよう出力④に書く
- 1通の長さは、依頼に無ければ、その通の要素を書き切れる長さを仮に置く。要素の大半が記入欄になる通（販売の日・最終日）は、記入欄に回る分を差し引いた長さで置く。見積もる時は、自分で書ける要素1つにつき1〜3文と数える。1通ごとの目標は、枠の表のその行の中身の列に書いてよい。「1本目でいちばんお伝えしたいのは」のような配信の案内の言い方は、書き手の気持ちの言い切りには当たらない。点検は `## 2日目1通目` の見出しごとに1通の字数を出す
- 有るか無いか分からない要素を条件つきの記入欄にした時は、その行の理由の列に書く（要素は入れて中身だけ記入欄にした物・書き手の紹介は、書かなくてよい）
- 事例のように、有るか分からず、無い時の置き換え（読者の状況ごとの場合分け）もある要素は、どの通でも同じ形にする: `【書き手が記入: 事例がある時だけ使う。無い時は、読者の状況ごとの使い方に書き換える】`
- 登録した時間によっては、2通が近い時刻に届くことがある。追伸では「今夜」「明日の朝」と時刻を決めつけず、「次のメールでは」と書いてよい
- 表の「教材1の最後の案内」は、教材1をまだ見ていない人への最後の呼びかけのこと。見られる期限がある時だけ、期限を記入欄で添える
- 理想の場面で商品の中身（扱う品目・作る物）に触れる所はぼかすか、出力④の差し替え候補に並べる
- メールでは設計シートの §6 を見出しごと消してよい（件名は §5 の種類から選ぶ）
- 全通の末尾の送り主・連絡先・配信停止は、各通に `【書き手が記入: 送り主の名前・連絡先・配信停止の方法（全通共通）】` と置き、出力④では1つの項目として書く
- 販売があることは、販売を始める前の通（2〜3日目のどこか）で一度知らせる。最後まで伏せて急に売らない（`guardrails.md` §5 の広告であることを隠さない）
- 「7日分」と頼まれたら、この型では16通になる（日数と通数は別）。依頼に通数が無ければ16通で組み、7通版の送り方を④に書く。7通にしたい時は各日の1通目だけを使い、販売の予告は2日目1通目に入れる。各日の1通目の追伸は同じ日の2通目を予告しているので、7通版では翌日の1通目の予告に書き換える所として④に並べる。その時も枠の表には16行を並べ、送らない通の「飛ばした理由」に「7通版のため各日の1通目だけ送る」と書く
- 期限・残数・値上げ・特典の締めは、**実際に決めて運用する物だけ**を書く（`guardrails.md` §1・§2）。締めが無い時、7日目は「メールでご案内する最終日」として書き（販売の締めの日ではない）、締め時刻は `【書き手が記入: 締めがある時だけ】` にする。「見逃すと損」の繰り返しで急がせない
- 用意がある時だけ入れる要素: 感想・事例・数字・特典・質問の受付・個別相談。用意が無いと依頼に書かれている時は、その要素を飛ばし、設計シートの「飛ばした理由」に書く。依頼に書かれていない（有るか無いか分からない）時は、飛ばさずに「ある時だけ使う・無ければ段落ごと消す」と書いた条件つきの記入欄にする
- 事例が無い時の置き換え: 読者の状況ごとの場合分け（「〇〇の人なら、こう使う」）か、書き手が実際に試したこと
- 自動で届く配信なので、「返信を読んで次の内容を考えます」のように、その場で読んで答える前提の書き方はしない。質問の受け付け方と答え方は `【書き手が記入】` にする
- 実際に集まった質問が無い時は「よくある質問」と名乗らず、「買う前に気になりそうなこと」と呼ぶ
- 送り主の名前と連絡先、配信を止める方法は、どの通にも入れる（`guardrails.md` §5）

## 3 そのほかの型

### M2 4通の教育配信

1通につき1つの問いに答える。順番は「なぜ→何→どうやって→今すぐ」。

| 通 | 答える問い | 中身 |
|---|---|---|
| 1 | なぜやるのか | やる理由、やる得、やらない場合に続くこと |
| 2 | 本当にそうなのか | 事実・根拠・書き手の実際の結果（画像などで一目で分かる形。無ければ仕組みの説明） |
| 3 | どうやるのか | 手順を3・5・7のどれかの段数で |
| 4 | まず何をするか | 今日やる最初の1つ |

4つを1通にまとめて入れてもよい。その時も「なぜ→何→どうやって→今すぐ」の順に並べる。

### M3 2〜4週間の販売企画の全体

1本の記事や動画で売り切るより、2〜4週間かけて少しずつ教育した方が、読者は「自分で決めた」と感じやすい。全体は3段。

| 時期 | やること | 投稿・配信の役割 |
|---|---|---|
| 3週間前〜 | 投稿で興味をひく | 目指す姿・原因への気づき（`education.md` 1・3）。興味をひく投稿は後の時期も続ける |
| 2週間前〜 | 解決の手段を示す | おすすめの手段、ほかの選択肢では届かない理由（事実で比べる）、再現できる例 |
| 1週間前〜 | 迷いをほどく・予告 | お金と時間を使う意味・今動く意味、発売・無料企画の予告、商品を作っている様子の実況 |
| 3〜5日前 | 無料企画（M4） | 無料の動画・音声・資料で必要性を一気に固め、受け取る人に配信へ登録してもらう |
| 当日〜 | 販売（M1 の6〜7日目の配信） | 登録者に先に案内し、その後に一般に案内する |

投稿の本数の目安（計45本前後）: 興味をひく10／原因5／手段とほかの選択肢5／再現できる例3／そのほかの教育7／予告7／準備の様子の実況7。実況以外は前もって書いておく。

準備の進め方: 2週間前に投稿の下書き → 1週間前に商品をほぼ完成 → 6〜8日前に無料企画と感想のお礼の品 → 直前に販売ページ・配信文・販売開始の投稿・誤字の確認。期限や値上げは、実際に運用する物だけを書く。

### M4 無料企画（動画・音声・資料）の7つの並び

| 順 | 枠 | 中身 |
|---|---|---|
| 1 | 入口 | 書き手の事実と目指す姿で興味をひく。この回で得られることと「最後に大事なお知らせがある」を予告 |
| 2 | 悩みの代弁 | 読者の悩みと願いを、事前に集めた読者自身の言い回しで言う |
| 3 | うまくいかない理由 | 読者本人を責めず、やり方や通説の側に原因を置く |
| 4 | 何を変えるか | 変えることを1つに絞って示す |
| 5 | 中身を少しだけ | 具体的な部分を1〜2割だけ見せる（「何をするか」まで無料で渡し、「どうやるか」は商品側に残す） |
| 6 | 理想の未来をもう一度 | 簡単さ・早さ・成果の大きさ・ほかの人の実例（実際の物だけ） |
| 7 | お知らせ | 商品の発売日時・学べること・先に買う得（本当にある物だけ）を知らせて締める |

## 4 送る時刻と通数の原則

- 登録直後は、お礼と軽い自己紹介だけ。いきなり売らない
- 何通かやり取りした3通目あたりから、具体的な提案を始める
- 1日に送る通数は、教育の日は朝と夜の2通、販売の日は朝・昼・夜の3通までを目安にする
- 締めが近い通だけ、期限の言葉を前に出す（期限が本当にある時だけ）
- 季節や行事に合わせる時は、話題の入り口だけにして、中身の教育は変えない
- 最初の1通は、書き手が誰かが分かる自己紹介の話にする（`persuasion.md` §8）。初めての読者に「誰が言っているか」が伝わると、後の配信が届く
- 序盤に、無料でも十分役立つ物を1つ渡す
- 大きな申し込みの前に、小さな行動（アンケートに答える・興味があるか返信する・低価格の物を試す）を積んでもらう。興味を示した人にだけ案内すると、配信の解除も減る
- 販売企画の時期以外は、配信の回数を落としてよい。中身の薄い配信を続けると読まれなくなる
- LINE の配信は短く。チェックマークを並べた定型の長文は読まれない
- 買ってくれた人には、本編の読み返しと実践を促す配信を用意する

## 5 1通の組み立て

どの通も、この順に組む。

1. 件名（その通の役割を一言で。種類の例: 驚き・重要・好奇心・解決の予感・残り時間・分かれ道・最後）
2. 前の通からのつなぎ（1〜2行）
3. その通の中身（役割の表の要素を上から）
4. 読んでほしい行動を1つだけ（見る・返信する・読む・申し込む）
5. 追伸で次の通への期待（次に何が分かるか）。最後の通は、次の案内がある時だけ追伸を書く
6. 送り主の名前・連絡先と、配信を止める方法
