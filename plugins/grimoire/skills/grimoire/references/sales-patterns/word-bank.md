# word-bank — 言葉の選び方と候補

目次: 1 言葉を選ぶ原則／2 言葉の候補（分類別）／3 講座・特典の名前の付け方

## 1 言葉を選ぶ原則

- **決まり文句を捨てる**: 誰もが使う定番の言い回しは「知っている情報」と見なされ、読み飛ばされる
- **有名な技法の名前を出さない**: 名前を出した瞬間に軽く見られる。中身で驚かせ、呼び名が要るなら自分で付け直す
- **ざっくりした言葉を場面に置き換える**: 「古い」「安い」「みんな」を、見える・聞こえる・触れる・数で測れる・似た経験を思い出せる言い方に変える
- **読者の言葉で書く**: 初心者には平易な言葉、詳しい人には専門語。読者が普段使っている言葉を、コメント欄や質問サイトなどで集めてから書く
- **話し言葉で書く**: 目の前の読者を思い浮かべ、相手の心の声に答えるように書く。1文ごとに「これを言ったら相手はどう思うか」を考えて次の1文を書く
- **本音を代わりに言う**: 人前では言いにくい読者の本音を言葉にすると刺さる。建前の欲では弱い
- **界隈の外から借りる**: 別の分野・日常の会話・読者が毎日手で触る物から言葉と例えを借りると、表現が新しくなる
- **大衆向けほど具体に**: 読者が詳しい時は、具体を省いて短くしてもよい
- **成果の言い方**: 成功の理由を「才能・運・根性」に置かず、「手順・型・知識」のような身につけられる物に置く（ただし必要な手間を隠さない。`guardrails.md` §2）
- **感想・評価を具体に**: 「すごかった」で終わらせず、何と比べてどのくらいかを言う

## 2 言葉の候補（分類別）

使う前に、その言葉が事実と合っているかを確かめる。強い言葉ほど、同じ文の中に理由が要る。

| 分類 | 候補の例 | 使いどころ |
|---|---|---|
| 簡単さ・手軽さ | 知識ゼロから／ひな形／ひと手間／〇分で | 始める壁を下げる（本当に簡単な時だけ） |
| 隠れていた物 | 公開／中身を明かす／原則／やり方の芯 | 新しい情報だと示す |
| 強さ | 圧倒的／劇的／本質的／根本から | 変化の大きさを言う（理由と一緒に） |
| 人 | 第一人者／先輩／案内役／先駆け | 誰が語るか・誰になれるかを言う |
| 珍しさ | 唯一／ここだけ／期間を区切った | 本当に珍しい時だけ |
| 新しさ | 次の／新しい見方／転換点 | 古い方法との違いを言う |
| 古くからの知恵 | 昔から伝わる／先人の知恵 | 新しさの逆で信頼を作る |
| 証拠 | 調べた結果／記録／実際の声／専門家の確認 | 本当にある証拠を示す |
| 数 | ずらり／ひと握り／指折りの | 量や珍しさを言う |
| 時間 | 短い期間で集中／締め切り／先着 | 本当の期限がある時だけ |

使わない分類: 恐怖（破産・病気・孤独などを並べる言葉）・性的な言葉・違法や反社会的な行為を連想させる言葉（`guardrails.md`）。

## 3 講座・特典の名前の付け方

- 形: 〈誰が・何で成果を出したかを示す短い前置き〉＋〈中身を表す名前〉。前置きの数字は書き手の実際の数字だけ
- 名前の語尾の候補: 完全ガイド／入門講座／ひな形集／早見表／〇選／手順書／チェックリスト／事例集
- 頭に付けるラベルの候補: 保存版／無料／書き換えて使える
- 名前だけで「何が手に入るか」が分かるようにする。色や番号だけの名前にしない
- 講座やコミュニティの呼び方の語尾の候補: 講座／ゼミ／ラボ／クラブ／アカデミー
