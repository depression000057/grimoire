# letter-structures — セールスレター・有料記事・LP の型

目次: 1 型の選び方／2 売る側の型（L0〜L6）と書く前の手順／3 本編の型（B1〜B3）／4 実績や証拠が無い時の置き換え／5 抜けやすい枠（どの型でも確かめる）

使い方: 売る側（無料部分・LP・セールスレター）の型を1つ、本編（有料部分・教材本体）の型を1つ選ぶ。選んだ型の枠を、表の順番どおり上から埋めて構成を作る。構成をゼロから考えない。枠を飛ばす時・型に無い章を足す時は、設計シートに理由を1行書く。

## 1 型の選び方

| 条件 | 売る側 | 本編 | 理由 |
|---|---|---|---|
| 書き手に実績も購入者の声も無い・生活の悩み（健康・家事・人間関係・お金の不安） | L2 か L0 | B1 | 読者の今の行動を言い当てる所から入れるので、証拠が少なくても組める。無料部分を3,000字以上とって、疑いへの先回り・正直に言うこと・よくある質問・価格の意味づけまで入れたい時は L0。無料部分を短くしたい時・特典がある時は L2 |
| 実績・証拠・購入者の声が揃っている・長いセールスレターにしたい | L1 | B1 | 実績と「今までの常識を壊す」流れで引っ張る。枠ごとの分量が多い |
| 「なぜ今までうまくいかなかったか」の原因の説明が売りになる | L3 | B1 か B3 | 原因と解決策が一本の線でつながることが軸 |
| 電子書籍のような大きな教材（合計2万字以上）・基礎から順に教える | L4 | B2 | 同じ設計の通し型。前半が売る側、後半が本編 |
| 読者の状況によって対処が分かれる悩み | L2 か L3 | B3 | 本編に「状況ごとの対処」の部がある |
| 短い LP・案内文（2,000字以内） | L3 | — | 6つの枠だけで一周できる |
| 登録ページ・ごく短い案内（800字以内） | L6 | — | 4段だけで一周できる |
| 投稿や無料配信を重ねた販売企画の最後に出す長いレター・初めての読者にも全部を伝え直したい | L5 | B1 | 欲しくさせてから中身を見せる順番が決まっている |

2つ以上の行に当てはまる時は、先に媒体と字数の行（短い LP・案内文→L3、登録ページ→L6、大きな教材→L4）で決める。本編の無い LP に、本編と組になった L0・L1・L2・L5 は使わない。実績や声が無いことは、選んだ型の中で §4 の置き換えを使う手がかりにする。

## 2 売る側の型

各表の列: 順／枠／中身／実績が無い時／飛ばしてよい条件。空欄は、そのまま使ってよいという意味。

### L0 15枠の実務型（実績ゼロの書き手が、そのまま使える並び）

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 見出し3行 | 1行目で「しなくてよくなる労力」、2行目で手に入る状態、3行目で読む理由。記事の題名とは別に、題名の下に置く。1行目は `hooks.md` の型に当てはめなくてよい（有料記事の「冒頭」はこの1行目を指す） | 証拠が少ない時は、保証でなく目指すこととして書く（「〜しなくて済むように組んだ」） | |
| 2 | 疑いを先に受ける1行 | 見出しを読んだ読者が抱く疑いを、こちらから先に言葉にして受け止める | | |
| 3 | 言い当て | 読者が実際にしている行動を、具体的な場面で3〜4つ言い当てる | | |
| 4 | 免罪 | うまくいかないのは読者の努力や才能のせいではない、と原因を読者の外に置く | | |
| 5 | 思い込みを外す | 読者が今信じている「こうすればいい」を1〜2つ、理由つきで外す | | |
| 6 | 行き先の提示 | 思い込みを外した直後に、どこへ向かえばいいかを示す | | |
| 7 | 核心は本編へ | 納得は無料部分で完成させ、手順そのものは本編にあると明かす（8〜15も無料部分。有料ラインは15の後に置く） | | |
| 8 | いちばん大きな「買わない理由」を外す | 「私には才能・資格・時間がない」を、才能ではなく手順の問題に言い換える | | |
| 9 | 未来の場面 | 実践した先の1日を、時刻・場所・動作のある場面で描く | | |
| 10 | 中身の紹介 | 章ごとに「手に入る変化」を1行＋要点3つ（要点が依頼に無い章は、要点を記入欄にする） | 変化は「〜が分かる」「〜を決められる」のように、読んで手に入る知識や手順で書く。体や収入の変化を言い切らない | |
| 11 | 正直に言うこと | 何ができないか、誰には要らないかを先に言う | | |
| 12 | よくある質問 | 買う直前に残る不安を3〜5つ、1つずつ答える | 実際に集まった質問が無い時は、見出しを「買う前に気になりそうなこと」などにする（枠の名前はそのまま） | |
| 13 | 価格の意味づけ | 価格を「出費」でなく、何と引き換えかで言い直す | | |
| 14 | 限定（事実だけ） | 本当に運用する限定（部数・期間）だけを書く | 限定が無ければ書かない | 実際の限定が無い |
| 15 | 追伸 | 見出しの約束に戻り、今日やる最小の一歩で閉じる | | |

L0 には書き手の紹介の枠が無い。書き手の事実（続けている期間・試したこと）は、6（行き先の提示）か 8（買わない理由を外す）の中で短く触れる。10 の「要点3つ」は、まとめの章には無理に付けなくてよい。

### L1 常識を壊す長文レター型

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 3段の見出し | 上段で「誰のための話か」、中段で「何が手に入るか」、下段で「どんな方法か」。案を10本ほど出して選ぶ | | |
| 2 | 実績と証拠 | 目を引く実績と、読者が追体験できる「変化の話」 | 書き手が実際に試した事実だけにする。無ければ飛ばして3から始める | 実績も試した事実も無い |
| 3 | 悩みの言い当て | 読者の悩みを5つ以内で言い当てる | | |
| 4 | これまでの常識 | 読者が試して挫折した方法→それがうまくいかない理由→「あなたのせいではない」を話として | 敵にするのは「方法」や「思い込み」。人や会社を名指ししない | |
| 5 | 語れる理由の予告 | これから出す方法の意外な切り口と、書き手がそれを語れる理由 | 語れる理由は、調べた資料と仕組み。資格や人数は書かない | |
| 6 | 常識を壊す | 4の方法と何が違うのか。なぜ普通は逆だと思われているのか | | |
| 7 | 解決策に名前をつけて出す | 中身を言い表す名前で、解決策を発表する | 造語にしない。説明より先に名前だけを使わない | |
| 8 | 証拠 | 第三者の声、仕組みの根拠 | 声は書かない。仕組みは「と言われています」のように留保をつけ、読者が自分で確かめる方法を添える | |
| 9 | 使い方はこんなに簡単 | 読者がすぐ使える手順・例と、うまくいかない可能性がある人 | 例の代わりに「今日やる1手」 | |
| 10 | 中身と道のり | 本編の中身を「期間」と「一段ずつ上がる段」で見せる | | |
| 11 | 締め | 特典・保証・署名・追伸 | 特典・保証は実際に用意できるものだけ | 特典・保証が無い |
| 12 | 自己紹介 | 書き手が変わってきた話 | 書き手の事実が無ければ、書き手が後で埋める枠として空けておく | 書き手の事実が無い |

### L2 行動の言い当てから入る型（証拠が少なくても組める）

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 必要な理由 | 読者がこの内容を必要とする理由 | | |
| 2 | 今の行動の言い当て | 「こんなこと、していませんか」と、読者が解決しようとして取っている行動を言い当てる。「悩みはありませんか」とは聞かない | | |
| 3 | 続けた先 | その行動を続けた先にある、読者が避けたい状態 | 病気・破産・孤独で脅さない。毎日の生活の場面で書く | |
| 4 | 解決策と根拠 | 解決策と、うまくいく根拠 | 根拠は仕組みと、読者が自分で確かめる方法 | |
| 5 | その先の理想 | 解決策を実行した先の状態 | 書き手の体験でなく、読者の生活の場面で書く（5 抜けやすい枠 5-1） | |
| 6 | 目次 | 本編で学べること | | |
| 7 | 特典 | 特典 | 実物があるものだけ | 特典が無い |
| 8 | 購入者の感想 | 感想と変化（SNS なら最後、広告なら4の直後） | 書かない | 感想が無い |
| 9 | 出発点と到達点 | どんな状態の人が、どんな状態になるための内容か | 5-4 の最低条件 | |
| 10 | 向く人・向かない人 | 向く人と、向かない人（健康の話なら、先に専門家に相談してほしい人もここ） | | |
| 11 | 章の流れ | 1章で何、2章で何 | | |
| 12 | 本編へ送り出す一言 | 本編へ送り出す。ここまでが無料部分 | 決めゼリフにせず、次にやる1手で送り出す | |

### L3 原因でつなぐ6枠型（短い LP にも使える）

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 今の問題 | 読者が困っていることを、今向き合う理由と一緒に | 「急がないと手遅れ」と煽らない。今向き合う理由は、毎日くり返す場面で書く（「片付けを後回しにするたびに、探し物の時間が増える」のように） | |
| 2 | 本当の原因 | その問題を起こしている原因 | | |
| 3 | 原因に合った解決策 | 2の原因と一本の線でつながる解決策 | | |
| 4 | 信じられる証拠 | 解決策がうまくいく証拠 | 仕組み（留保つき）と、読者が自分で測る方法。証拠を作らない | |
| 5 | その先の理想 | 解決した先の生活 | 5-1 の最低条件 | |
| 6 | 断りにくい申し出 | 価格・中身・受け取れるもの | 実際に渡せるものだけで組む | |

この6枠は順番を入れ替えない。短く言うと「問題を示す→このままの先を見せる→解決策」の3段にもなる。

LP・申し込みページに使う時は、1の前にページの見出し（誰に・何が手に入るか）を、6の後に申し込み方の案内を置く。申し込む前の質問と答えを置く時は、6と申し込み方の間に置く。どれも型の外の追加なので、設計シートに「追加（理由: LP の見出し／申し込む前の質問と答え／申し込み方）」と書く。

L3 には書き手の紹介の枠が無い。書き手の事実（経歴・資格・続けている期間）は、4 信じられる証拠の中に置く。

さらに短い場面（登録ページ・短い案内・800字以内）では、L6 の4段を使う。

LP で解決策の枠（3）を組む時: 解決策がサービスの中身そのものになる時は、依頼にある事実から直接言えること（家事代行なら「毎回同じ担当が伺う」、整体なら「予約は1日3人まで」のように、依頼に書かれた条件だけ）で考え方を示し、進め方・内容は記入欄にする。5-2 の呼び名は、この「解決策の考え方」に付ける（申し込みの名前とは別）。依頼に事実がほとんど無い時も、呼び名は依頼の言葉から仮に1つ決めて本文で通す（呼び名を記入欄にすると見出しまで読めなくなる）。仮に決めたことと、ほかの候補2〜3個を出力④に並べる。

### L6 4段の短い型（登録ページ・短い案内）

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 悩みか願いの言い当て | 読者がすでに気にしている悩み・願いから入る | | |
| 2 | うまくいかない本当の理由 | いちばん手間をかける所（ここが抜けると押しつけに聞こえる） | | |
| 3 | 理由を解く方法を1つ | 2の理由と一本の線でつながる方法 | 方法の中身が依頼に無ければ考え方だけ示し、中身は記入欄 | |
| 4 | 方法の先にある暮らし | 「直接の効果→その先の自由→毎日の暮らしの具体」の3層で描く | 効果は言い切らない | |

無料で渡す範囲の目安: 「何をすればいいか」までは無料で伝え、「どうやるか」を本編に残す。無料部分が役に立つと感じてもらえ、続きを求めてもらえる。

### L4 電子書籍型の前半（売る側）

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 0 | はじめに | この本の目的と読者／テーマの定義と今の状況／よくある思い込みとその限界 | 「今の状況」の数字は出典があるものだけ | |
| 1 | 必要と課題 | なぜ必要か／分からないままだと起きる悩み／よくある方法の問題点 | | |
| 2 | 理想の未来 | 得られること／この方法で出た結果／実践した先の暮らし | 結果は書かない。得られることは読者の生活の変化で | |
| 3 | 中身の説明 | 主な内容と特徴／ほかの方法との違い／特典 | 特典は実物だけ | |
| 4 | 使い方 | 読む順番と進め方／具体例／よくある質問 | | |
| 5 | 読んだ人の声 | 事例／購入を迷う人の質問と答え／評価 | 声・事例・評価は書かない。質問と答えだけ残す | 声が無い |
| 6 | 買い方と保証 | 価格と買い方／保証とサポート／対象範囲／どの段階の人が次の段階へ進むための本か／よくある質問／向く人・向かない人 | 保証とサポートは実際に用意できるものだけ | 保証が無い |
| 7 | 本編へ送り出す一言 | 背中を押す／約束する。ここまでが売る側 | 決めゼリフで閉じない | |

### L5 欲しくさせてから中身を見せる16枠（販売企画の締めのレター）

大きな流れは「気持ちを動かして欲しくさせる→必要な理由に納得させる→中身を見せる→迷っている人の背中を押す」。初めて読む人でも買えるように、それまでの投稿や配信で伝えたことを全部入れ直す。

| 順 | 枠 | 中身 | 実績が無い時 | 飛ばしてよい条件 |
|---|---|---|---|---|
| 1 | 入口 | 理想の未来か、悩みの言い当て | | |
| 2 | 最初の申し出 | 何が手に入るかを一言で | | |
| 3 | 書き手の紹介 | 書き手の事実 | 事実が無ければ短く、試した事実だけ | |
| 4 | 問いの立て方 | 読者が「そう、それが知りたい」となる問い | | |
| 5 | 問題 | 問題と、それが毎日の生活をどう圧迫しているか | 脅さない | |
| 6 | 原因 | 問題を起こしている原因（意外な原因ほど読まれる） | | |
| 7 | 解決策 | 原因と一本の線でつながる解決策 | | |
| 8 | 解決した後の姿 | 解決した後の生活 | 5-1 の最低条件 | |
| 9 | 共感を呼ぶ過去の話 | 読者と重なる過去の場面 | 書き手の話が無ければ、読者の今の場面で | |
| 10 | 解決策が妥当な根拠と得られること | 根拠と、得られること | 根拠は仕組み（留保つき） | |
| 11 | 理想の未来（もう一度） | 8より一段大きな未来 | | |
| 12 | 中身の箇条書き | 「〈得られること〉ができる〈やり方〉」の形で、中身と得られることを並べる | 中身を伏せすぎない | |
| 13 | 第三者の声 | 実際の声 | 書かない | 声が無い |
| 14 | 学びにお金を使う意味 | 価格と引き換えに何が手に入るか | | |
| 15 | 向く人・向かない人 | 向く人と向かない人（冒頭に短く置いてもよい） | | |
| 16 | 締め | 最初の理想に戻り、行動するかを読者自身に選んでもらう | 決めゼリフにしない | |

中身（12）には、読者が欲しくなるまで触れない。長いレターなら半分を過ぎてから、構成によっては最後の4分の1で初めて中身に入る。12まで来た時点で買う人は買っているので、13〜16は迷っている人に向けて書く。

### 書く前の手順（どの型でも）

1. 読者を調べる: 知識の段階（専門語が通じるか）／どこでつまずいているか／本人が思う失敗の原因／ほかに買った物と、使えるお金の感覚／制限が無ければ何が欲しいか／面倒に感じていること／いちばん避けたい事態／どんな情報に反応するか／この内容を探すことになった背景
2. 調べた結果で、商品の約束（誰の・何が・どうなる）を練り直す
3. 同じ分野でよく売れている文章を3〜5本読み、構成の流れと、自分に刺さった言い回しを書き出しておく（言い回しは、そのまま写さず自分の言葉に直して使う）
4. このファイルの型を1つ選び、枠を埋める（設計シート）
5. 型の順に書き、書き終えたら点検する

## 3 本編の型

### B1 抽象から具体へ進む型（ノウハウ・手順を渡す本編）

| 順 | 章の役割 | 中身 | 注意 |
|---|---|---|---|
| 1 | なぜ効くのか | 特徴／なぜ必要か／どんな場面で使うか／なぜこの方法でないとできないか／前提になる考え方の入れ替え／心構え | 効果は言い切らない |
| 2 | 全体像（抽象） | 「こういうイメージです」と全体を先に1回見せる。詳しくは次の章へ | |
| 3 | 手順（具体） | 2の全体像を、手順に落とす | 手順は3・5・7のどれかに収める |
| 4 | 場合ごとの実例と応用 | Aの場合／Bの場合／それを踏まえた応用 | 実例は読者の状況の場合分けで書く。架空の人物の成功談にしない |
| 5 | 質問と答え | 実践の途中で出る質問 | 5-3 の最低条件（本編の中に置く） |
| 6 | まとめ | 全体のまとめ | 要約で閉じず、今日やる1手で終える |

この型を使う時に守る4つ: ①最初に約束した価値と目的からずれない　②無料部分で誇張しない　③段を飛ばさず一段ずつ進む（低い段でも1段ずつ）　④本編は教科書、特典は学習を進める道具として、両方で完成すると伝える

### B2 電子書籍型の後半（本編）

| 順 | 章の役割 | 中身 |
|---|---|---|
| 8 | 自分を知り、目標を決める | 自分の特徴や大事にしていること／目的と目標（短期・長期・行動計画） |
| 9 | 前提になる知識 | 定義と種類／そのための心構え |
| 10 | 実践の手順 | 3段の手順／書き込み用のシートの使い方・例・自分用の手直し |
| 11 | 続けるための考え方と習慣 | なぜ続けるか／習慣にするやり方 |
| 12 | 使う場面と機会 | 機会の見分け方／始め方 |
| 13 | つまずきと対処 | 心の壁／続ける途中の困りごとへの対処 |
| 14 | おわりに | 最初の一歩と、学び続けること |

### B3 部・節・項の階層型（状況ごとに対処が分かれる悩み）

形: 部が4つ、それぞれに節が3つ、節の下に項が2つずつ。最後に短い終章。

| 部 | 役割 | 節の立て方 |
|---|---|---|
| 第1部 | 基礎と覚悟 | 現実を知る／自分を見直す／計画を立てて動く |
| 第2部 | 核心の手順 | この悩みでいちばん大事な手順を3つの節に分ける |
| 第3部 | 状況ごとの対処 | 読者がよく置かれる状況を3つ選び、1節に1状況 |
| 第4部 | 続けるための秘訣 | 続ける・深める・振り返る |
| 終章 | 送り出し | 最初の一歩 |

note や記事の見出しに合わせる時は、部を章（`##`）に、節を小見出し（`###`）に置く。

## 4 実績や証拠が無い時の置き換え

| 型が求める枠 | 置き換え | 理由 |
|---|---|---|
| 実績の数字・ビフォーアフター | 書き手が実際に試した事実（期間・何をしたか）。無ければ仕組みの説明（留保つき） | 実績を作ると、読者と法令の両方への裏切りになる |
| お客様の声・推薦・評価 | 書かない。代わりに「読者が自分で確かめる方法」 | 声は作れない |
| 資格・人数・メディア掲載 | 「なぜ語れるか」は、調べた資料と仕組みで | 持っていない権威は書かない |
| 自己紹介の話 | 書き手が後で埋める枠として空けておく | 人物像を作らない |
| 特典・保証・割引 | 実物・実際の設定があるものだけ | 無いものを約束しない |
| 続けた先の最悪の状態 | 毎日の生活の場面で書く | 恐怖で動かさない（guardrails.md） |

## 5 抜けやすい枠（どの型を選んでも確かめる）

型の枠があっても中身が弱くなりやすい所。書き終えたら4つとも確かめる。

| # | 枠 | 最低条件（満たさないと「弱い」） |
|---|---|---|
| 5-1 | 理想の未来 | 読者の生活で起きる変化を、時刻・場所・動作のある場面で書く。「〜しやすくなります」の1文だけで済ませない。効果は言い切らない |
| 5-2 | 解決策の呼び名 | 本編でやることの全体を、読者がひと言で呼べる名前を1つ決め、売る側と本編で同じ名前で呼ぶ。造語にせず、中身を言い表す普通の言葉で |
| 5-3 | 本編の質問と答え | 本編の中に、実践の途中で出る質問（できなかった日・家族や職場の事情・続け方）を3つ以上置く。購入前の質問だけで済ませない |
| 5-4 | 出発点と到達点 | 「今こういう状態の人が、読んで実践するとこういう状態になる」を、読者の状態で1組言う。数字の約束はしない |
