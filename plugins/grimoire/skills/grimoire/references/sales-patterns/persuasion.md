# persuasion — 訴求・論理・ストーリー・証拠・心理

目次: 1 文章の力はどこで決まるか／2 4つの訴求と2つの働き／3 ベネフィットと悩みの深さ／4 約束の一貫性／5 主張・理由・根拠／6 4つの問いの順番／7 証拠と信頼／8 売るためのストーリー／9 読み進めてもらう仕掛け／10 心理効果（学術用語）

## 1 文章の力はどこで決まるか

文章が人を動かす力は、書き手が誰か、中身が何か、書き方がどうか、の3つで決まる。効き目が大きいのは前の2つで、書き方はいちばん最後。書き方を磨く前に、次の2つを確かめる。

- **誰が**: 同じ言葉でも、言う人の行動と実績で重さが変わる。書き手の実際の行動と事実を、文章の前に積む
- **何を**: 書く前に目的（読者にどんな行動・気持ちを起こしたいか）を1つ決め、そこから逆算して書く
- **商品の試験**: 30秒で説明して「それが本当なら欲しい」と言われるか。ひと言で欲しいと思ってもらえない商品は、長く書いても買ってもらえない。文章の前に、商品と切り口を磨く
- 強い約束ほど、必要な証拠の量と具体さが増える。証拠がゼロなら、約束を弱めるか、読者が自分で確かめられる形に変える
- **書く前の商品分析（8つの問い）**: ①テーマを一言で ②誰のどんな悩み・欲を解くか ③どんな形の商品か ④ほかの解決手段は何か ⑤同じ分野の商品への不満は何か ⑥ほかと比べた強み ⑦作ったきっかけ ⑧読者をどこまで連れていくか。答えが出ると、何を原因に置き、何を強みとして押すかが決まる。同じ分野の商品を5つほど読み、良い点と不満を書き出しておく
- 強みが無い時は、商品に新しい意味づけ（どんな場面の・誰のための物か）を与えて強みを作る

## 2 4つの訴求と2つの働き

訴求は「読者の気持ちを動かす要素」。軸を1つ決め、ほかは脇に置く。

| 訴求 | 中身 | 注意 |
|---|---|---|
| 理想の未来 | 買った先に手に入る状態。いちばん強く効く | 読者が知っている理想に加えて、まだ気づいていない理想も示すと強まる。書き手の体験でなく読者の生活の場面で |
| 悩みの解決 | 読者の悩みを言葉にして「自分のことだ」と思わせる | 同じ「痩せたい」でも、年代や立場で悩みの中身が違う。読者1人の悩みで書く |
| 信頼と実績 | 本当に効くのかという疑いに答える | 実際にある物だけ（§7・`guardrails.md`） |
| 期限と数量 | 締めがあると人は動く | 本当に決めている期限・数量だけ |

働きは2つ。**気持ちを動かす**（理想・悩み・実績・ストーリー）と、**行動を後押しする**（期限・数量）。気持ちが動いていない読者に、後押しだけを重ねても動かない。

## 3 ベネフィットと悩みの深さ

- **ベネフィット**は、買った後に手に入る未来。特徴（メリット）とは別。「特徴→だから→結果こうなる」までつなげて書く（例の形:〈専用の手順がある〉→〈迷わず続けられる〉→〈〇〇の状態になる〉）
- **悩みの深さを上げる**: 「痩せたい」で止めず、いつまでに・どんなやり方なら続けられそうか・過去に何で失敗したか、まで掘ると、合う提案がはっきりする
- 1つの商品でも、解決できる悩みは複数ある。悩みごとに入口の言葉を変えて届け分ける
- 読者は、書き手が思うより2段手前でつまずいている。書き手の常識で悩みを設定しない。初心者の言葉で聞き直す
- 本音の欲を探る3つの問い: ①制限が無ければ何を望むか ②手間とリスクがゼロなら何を望むか ③どの欲が重なっているか（お金・時間・安心・特別感・認められたい・仲間に入りたい）

## 4 約束の一貫性

入口（見出し・広告・投稿）で約束した言葉と、相手の姿を、中身と最後の呼びかけまで変えない。途中で約束の言い方や相手が変わると、読者の気持ちの流れが切れる。例: 入口で「格好よくなる」と約束したなら、最後まで「格好よくなるために」で通す（途中で「きれいになる」に変えない）。

## 5 主張・理由・根拠

- **主張**（言いたいこと）、**理由**（なぜそう言えるか）、**根拠**（理由を支える事実）の3つがそろって、初めて筋が通る
- 理由は、主張と因果でつながっていないといけない。途中の段を飛ばすと切れる
  - 切れている形:「〈食べ物A〉を毎朝食べると痩せます。〈栄養素B〉が多いからです」（B が多いと、なぜ痩せるのかが無い）
  - つながった形:「〈食べ物A〉は〈栄養素B〉が多く、〈痩せる邪魔になる状態C〉を防ぐので、痩せる助けになります」
- 書き終えたら、主な主張ごとに理由と根拠があるかを設計シート §4 で確かめる

## 6 4つの問いの順番

読者は4つの問いを順に持つ。この4つがそろうと、行動につながる文になる（順番より、4つがそろうことが大事）。

| 問い | 答え方 |
|---|---|
| なぜやるのか | 理由・やる得・やらない場合に続くこと |
| 本当なのか | 事実・根拠・証拠。一目で分かる形（画像・表）で |
| どうやるのか | 手順。3・5・7のどれかの段数に収める（長い手順は読まれない） |
| まず何をするか | 今日やる最初の1つ |

メールなら1通に1つずつ答える組み方もある（`step-mail.md` M2）。

## 7 証拠と信頼

信頼を高める要素（効く順の目安）: 目の前で見せる／本人の生の声／台本なしで語る／ストーリーで語る／具体的な数字と中身／欠点を先に言う／仕組みを説明する／読者の疑問に先回りして答える／条件つきの保証／お客様の声。

- 数字や中身は具体的なほど本当らしく聞こえる。だからこそ、実際の数字だけを使う
- 欠点やできないことを先に言うと、後から言う良さが信じられやすくなる
- 仕組みの説明は必要だが、それだけでは「なぜこの人から買うのか」が生まれない。書き手の事実と組み合わせる
- 読者が抱く疑い（本当か、自分には無理では）には、聞かれる前に本文で答える
- お客様の声を使う時は、実際の声だけを、本人の許可を得て使う。対価を渡して集めた感想は、その旨を示す（`guardrails.md` §5）

## 8 売るためのストーリー

売る場面で使うストーリーは2種類。

| 種類 | 流れ |
|---|---|
| 商品が生まれた経緯 | 何に困っていた→何を試した→どう形になった |
| 書き手が変わってきた話 | うまくいかなかった過去→答えとの出会い→変わった転機→次はあなたの番 |

初めて読む人には、後者が効く。書き手の事実が無い時は、ストーリーを作らず、読者の今の場面を描く形に置き換える。

ストーリーの要点:
1. 読者との共通点: うまくいかなかった過去を、読者の今と重なる具体的な場面で書く
2. 気持ちを動かす: 起きたことに加えて、その時の心の声を地の文に入れる
3. 気づかせる: 結論を言い過ぎず、読者が自分で気づく材料を並べる。人は自分で気づいたことを高く評価する

組み立ての順: 出来事→気持ち→理屈→気づき。人は気持ちで決めて理屈で納得する。

共感してもらうには、出発点を読者と同じか少し下に置く。成功した話より、そこへ至るまでの試行錯誤を中心に語る。気持ちを動かす時は数字より一人の具体的な場面、理屈で納得してもらう時は数字を使う。

### 書き手の自己紹介の話（11段・書き手の事実がある時だけ）

大きな流れは「今→過去→今→これから」。過去から書き始めない（まず今の姿で興味をひく）。

| 順 | 段 | 中身 |
|---|---|---|
| 1 | 今の自己紹介 | 今の実績・暮らし・大事にしていること |
| 2 | うまくいかなかった過去 | お金・時間・人間関係の不自由さ（後半との対比になる） |
| 3 | 出会う前の背景 | もがいていた出来事。出来事には必ずその時の気持ちを添える |
| 4 | きっかけとの出会い | 最初は疑った・ためらった気持ちも書く |
| 5 | 小さな成功 | 初めてうまくいった時の気持ち |
| 6 | 成功が続く | 考え方がどう変わったか |
| 7 | 暮らしの変化 | 身近な変化（食事・時間・家族との過ごし方） |
| 8 | さらに学び続ける | 次の目標と、学び続けている姿 |
| 9 | 今の実績 | 事実だけ |
| 10 | このままだとどうなるか | 読者が選べる2つの道（脅さない） |
| 11 | 発信している理由 | なぜ発信しているか、と「次はあなたの番」 |

### 信頼を高める書き方

- 良い面と悪い面を両方示す（実際にある欠点を。実害の無い欠点だけを選んで公平に見せない）
- 読者がよく持つ反論に、先に答える（特別な人しか無理では／お金や時間が要るのでは／ほかの方法でよいのでは／今でなくてよいのでは／危なくないか）
- 第三者に語ってもらう（対談・実際の声）
- 選択肢は減らし、そのまま真似できる答えを1つ示す
- 小さな約束から大きな行動へ（無料の資料→アンケート→低価格の物→本命）
- 望む行動をした人を認め、前向きな呼び名で呼ぶ（決めつけて操るためには使わない）

## 9 読み進めてもらう仕掛け

- 1行目の役目は2行目を読ませること。序盤は「読ませる」ことを最優先にする
- 大きな疑問を1つ最後まで持たせつつ、小さな疑問→すぐ解決、をこまめに挟む。疑問が何も無い行が続くと読まれなくなる
- 答えを明かして疑問がゼロになった所が、いちばん読まれなくなる所。そこで次の疑問を立て直す
- 疑問を残す言い方: 対象をぼかす（「ある方法」）、後で出すと予告する（「このあと紹介する」）、気持ちだけ見せて中身を伏せる（「もっと早く知っていれば」）。伏せた物は必ず後で出す
- 1スクロールに1回くらい見出しを入れる。流し読みの人は見出しで止まる
- 難しい説明の直後に、ひと言の要約と身近な例え（読者が毎日手で触る物から）を添える
- 「〜しなさい」と命令せず、体験談や読者が得をする理由で、読者が自分でそうしたくなるようにする
- 書き上げたら声に出して読み、詰まる所を直す
- 商品の中身は、読者が欲しくなるまで出さない。中身の箇条書きまで来た時点で買う人は買っているので、そこから先は迷っている人に向けて、声・保証・不安への答えを重ねる（中身を隠したまま売らない。`guardrails.md` §2）

## 10 心理効果（学術用語・定義はこのスキルの言葉）

置く場所を決めて、1本の文章で3〜5個までにする。読者の判断をゆがめる目的では使わない（`guardrails.md`）。

| 名前 | この文章での使い方 |
|---|---|
| アンカリング効果 | 先に見せた数字が比べる基準になる。価格の前に、実際の比較対象を見せる |
| カリギュラ効果 | 伏せられると知りたくなる。伏せた物は必ず後で出す |
| 選択のパラドックス | 選択肢が多いと選べなくなる。選択肢は2〜3に絞る |
| バンドワゴン効果 | 多くの人がしていることに合わせたくなる。実際の人数がある時だけ |
| 所有効果 | 自分の物だと思うと価値が上がる。使っている場面を想像させる |
| ツァイガルニク効果 | 途中で止まった物が気になる。次の章・次の通への期待に使う |
| 権威の原理 | 信頼できる出どころの情報を信じやすい。本当の出典だけ |
| フレーミング効果 | 同じ中身でも見せ方で受け取り方が変わる。誤解させる見せ方はしない |
| 現状維持バイアス | 今のままでいたくなる。最初の一歩を小さくする |
| 同類性の原理 | 自分と似た人に好感を持つ。読者と同じ場面を描く |
| 損失回避 | 得るより失う方を強く嫌う。脅しにしない |
| 系列位置効果 | 並びの最初と最後が残る。いちばん大事な物を最初か最後に |
| スノッブ効果 | 珍しい物・特別な物を欲しくなる。本当に数が限られる時だけ |
| 社会的証明 | 他の人の行動を正しいと感じる。実際の声だけ |
| 返報性 | もらうと返したくなる。無料で先に役立つ物を渡す |
| アンダードッグ効果 | 不利な側を応援したくなる。書き手の実際の苦労がある時だけ |
| ハロー効果 | 目立つ一点が全体の印象を引き上げる |
| コミットメントと一貫性 | 小さく決めたことを続けたくなる。小さな行動から順に頼む |
| カクテルパーティ効果 | 自分に関係する言葉に気づく。読者の呼び方・状況を入れる |
| 確証バイアス | 信じたい情報を重く見る。読者の思い込みを利用して誤解させない |
| ピーク・エンド・ルール | 山場と終わり方で全体の印象が決まる。締めを大事にする |
| 希少性の原理 | 手に入りにくい物ほど価値を感じる。本当の希少性だけ |
