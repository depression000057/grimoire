# hooks — 冒頭で止める型

目次: 1 冒頭の型30（H01〜H30）／2 選び方と作り方／3 長文・記事の一文目／4 件名の種類

使い方: テーマと読者を決め、下の30の型から相性の良いものを分類をまたいで選び、テーマに当てはめた完成案を10〜20本出してから1つ選ぶ。型の名前をそのまま文にしない（「限定です」と書くのではなく、何が・いつまでかを書く）。

## 1 冒頭の型30

H14 と H25 は同じ「理由の問い」の形なので、1回の案出しで両方を使う時は言い方を変える。

数字・結果・体験の型を使う時の決まり:

- 入れる数字と事実は、書き手が実際に持っている物だけ（`guardrails.md`）。依頼の数字を同じ値のまま見える形に言い換えるのはよい（「500円」→「500円玉1枚」）。値や範囲が変わる言い換えはしない
- 一文の中で書き手の経験や結果を言う型（H17 失敗談・H28 やってみた、書き手の変化や数字を言う案）は、依頼に経験が書かれていればそのまま使ってよい。書かれていない時は、使わずに落とすか、使うなら案の上（表のセルの中では案の先頭）に `【書き手が記入: この経験が実際にある時だけ使う・期間など】` を置く
- 経験以外の条件が要る案（冒頭に完成品を映す・店の値段が前提 など）も、使うなら案の先頭に「使う条件」の記入欄を置く
- 採用した条件つきの案は、設計シート §6 の一文のセルにも、先頭に使う条件を書く
- 不採用にした案には印は要らない（〈 〉を埋める事実が無ければ、その所だけ記入欄で埋める）

型の役割についての決まり:

- 型の見本の〈 〉を埋めるのは置き換えではないので、設計シートの理由の列は空欄でよい
- 選んだ型の役割（一覧の型なら「一覧だと分かること」）を一文で果たせない時は、その型を選ばない
- 一覧やまとめの型は、品数が依頼に無ければ数を記入欄にしたうえで、「〜の一覧」「〜をまとめた」と言ってよい（数を言わなければ約束にはならない）

## 2 選び方と作り方

1. テーマと読者1人を決める
2. 30の型から、分類をまたいで10〜20個選ぶ（同じ分類に偏らせない。分類の数より多く選ぶ時は重なってよい）
3. 1つずつテーマに当てはめて完成した一文にする。〈 〉を残さない
4. 読者が「自分のことだ」と止まるか、続きを知りたくなるか、嘘や誇張が無いかで絞る
5. 採用した案の ID を設計シートに書く

案そのものが欲しい依頼（「最初の一言を8つ出して」など）は、求められた数の1.5倍ほどを出して求められた数に絞り、推奨を1つ付ける。落とした案と理由は設計シート §6 に書く。

冒頭の一言だけを作る時の設計シート: 枠の表は本ごとに1行（枠の名前は `本1-一言` のように）にし、中身に型の番号と一文を書く。使う条件つきの案（経験や本編の中身が要る案）は、その行の理由の列に「使う条件: 〜」と書く。案を出して選んだ過程と推奨の1つは §6 に書き、推奨は出力④にも書く。

冒頭で使える言葉の種類: 数字・否定・意外な組み合わせ・強い言い切り。2行目に、読者の属性だけが分かる「あるある」を置くと止まりやすい。

## 3 長文・記事の一文目

- 入れる要素: 数字／大きな損／常識と逆のこと／「Aしたいけど B なあなたへ」の呼びかけ／得られること
- 続きを読ませる作り方: 理由を1段飛ばす・大事な情報を1つ伏せる・常識と食い違うことを言う（あとで本文で必ず回収する。嘘にしない）
- 画像を添える時は、内容の要約でなく、目を止める一語を入れる

## 4 件名の種類（メール・LINE）

驚き／重要／好奇心／解決の予感／残り時間／分かれ道／最後。期限や残り時間の件名は、実際の期限がある時だけ使う。
