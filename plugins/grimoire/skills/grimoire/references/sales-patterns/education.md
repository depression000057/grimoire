# education — 買う前に伝える教育の要素と順番

目次: 1 教育とは／2 土台の6要素（この順で入れる）／3 効きを上げる要素／4 買うまでの気持ちの流れ／5 「やらない理由」を先に消す／6 教育の進め方の原則／7 点検のしかた

## 1 教育とは

教育とは、読者の見方を少しずつ整えて、商品が必要だと自分で分かる筋道を作ること。筋道だけ示しても、読者が「困っていない／原因が分からない／動くのが怖い／払うのが怖い」のどれかなら買わない。下の要素で、その4つを順にほどく。

教育は、読者の判断を奪うことではない。材料をそろえて、読者自身が決められる状態にすることが目的。

## 2 土台の6要素（この順で入れる）

| 順 | 要素 | 読者に分かってもらうこと | 材料 |
|---|---|---|---|
| 1 | 目指す姿 | 自分がなりたい姿を具体的に思い描き、そこへ向かいたくなる | 理想の状態（お金・時間・暮らし・人間関係・嫌なことから離れられた状態）、実際のビフォーアフター、実績。並べ方は、分野に直結する欲→暮らしに近い理想 |
| 2 | 信頼 | 「良さそうだけど本当か」という疑いが消え、話を聞く気になる | 「人として信用できるか」と「語る資格があるか」の2つ。書き手の事実、過去の話、当事者にしか分からない悩みの言い当て、発信している理由、無料で先に役立つ物 |
| 3 | 原因への気づき | 理想に届いていない原因に気づき、放っておけないと感じる | 本人が気づいていない原因（いちばん大事）、原因を読者のせいにしない、放置した場合に続く毎日（脅さない）。原因が分かった読者が自分から解決策を探す状態にしてから次へ |
| 4 | 解決の手段 | 解決策と、それで理想に行ける見通しが分かる。ほかの選択肢ではだめな理由も分かる | 解決策を1つに絞る、ほかより優れた点を読者の得まで言う、解決までの道のり、ほかの手段では届かない理由（事実で比べる）、再現できる例 |
| 5 | お金と時間を使う意味 | 学びや道具にお金と時間を使うと、遠回りが減ると分かる。払う直前の迷いがほどける | 知っているかどうかで差がつくこと、今の無駄な出費、遠回りで失っている時間、学びに使って助かった実例 |
| 6 | 今動く意味 | 今始めることの意味が分かり、最初の一歩を踏み出せる | 実際に動く人は少ないこと（出典が無ければ数や割合は書かない）、書き手自身の動き、動いた読者を認める言葉。行動してほしい場面の直前に毎回入れる。本当の期限が無い時は、読者が今日できる小さな一歩（予定に丸をつける・無料の体験に申し込む）で書く |

順番の意味: 1・2で「話を聞いてもらえる状態」を作る → 3・4で「自分に必要だ」という筋道を作る（原因→解決の順） → 5・6で迷いをほどき、決めてもらう。

## 3 効きを上げる要素

土台の6つの効きを上げる。必要な物だけ足す。

| 要素 | 中身 | 使い方の線 |
|---|---|---|
| 読んでもらう | 読みにくさで離れないようにする。冒頭で「なぜ大事か」「何が分かるか」「読んだ後どうなるか（一段先まで）」「後半に何があるか」を示す | 手順から書き始めない（難しく見える） |
| 繰り返し触れてもらう | 媒体・切り口・エピソードを変えて、同じ結論を何度も伝える | 同じ文の繰り返しでなく、根拠や経緯を変える |
| 変わる不安をほどく | 変わる時の不安は自然なことだと伝える | 家族や身近な人への相談を止めない。「反対されるものだ」と先回りして孤立させない |
| まず手順どおりに試す | 自己流の前に、学んだ手順で一度試す方が早いと伝える | 疑問を持つこと・質問することは否定しない |
| 学びを外に出す | 感想や学びを書くと、本人の記憶に残ると伝え、書き手自身もやる | 対価を渡して感想を集める時は、その旨が分かるようにする |
| 覚悟の話 | 書き手が弱みを乗り越えた実際の話で、迷いに寄り添う | 命の危険・極端な困窮を持ち出して、ためらう読者を恥じさせない |

使わない要素: 読者の「当たり前」の基準を、極端な作業時間・高額な出費・借金を当然に見せてずらすこと（`guardrails.md` §2・§3）。

## 4 買うまでの気持ちの流れ

読者の気持ちは、だいたいこの順に動く。今どこにいる読者に書いているかを決め、次の段へ進める要素を選ぶ。

1. 興味を持つ（→ 目指す姿）
2. 「良さそうだけど怪しい」と疑う（→ 信頼）
3. 背景を知って信じる
4. このままではまずいと気づく（→ 原因への気づき）
5. 原因が分かって解決策を探す（→ 解決の手段）
6. 自分にもできそうと感じる（→ 再現できる例・道のり）
7. 払う直前で怖くなる（→ お金と時間を使う意味）
8. 意味が分かって決める（→ 今動く意味）

## 5 「やらない理由」を先に消す

人が動くのは「動く理由がある」かつ「動かない理由が無い」時。良さをいくら足しても、買わない理由が1つ残っていれば動かない。本文の中で先に答えておく。

| やらない理由 | 答える方向 |
|---|---|
| お金・時間が無い | 無くてもできる範囲／作れる範囲を、事実で示す |
| 特別な条件が要りそう | 要らないことを、条件つきで示す |
| 怖い・危なそう | 実際の危険の大きさと、避け方を示す |
| 面倒そう | やらなくてよい所と、実際にかかる手間を示す |
| 書き手を信用できない | 書き手の事実・発信している理由・過去を示す |
| ほかにもっと良い方法がありそう | ほかの方法と事実で比べる |

## 6 教育の進め方の原則

- 情報は、読者が欲しがってから出す。問題を知らせる→「どうすれば？」となった時に解決策を出す、を繰り返す
- 「〜しなさい」と命令せず、体験談や読者の得で、読者が自分でそうしたくなるようにする
- 結論を言い過ぎず、読者が自分で気づく材料を並べる
- 複雑な仕組みを説明したら、直後にひと言でまとめ、身近な例えを添える
- 読者は書き手が思うより2段手前でつまずいている。その能力や成果が「なぜ嬉しいのか」から伝える
- 一度では定着しない。数日〜数週間に分けて伝える（`step-mail.md`）。時間を分けると「自分で決めた」と感じてもらえる
- 最後に決めるのは読者だと伝える。押しつけると、うまくいかない時に反発が大きくなる。伝える時は「決めるのはあなたです」のような独立した締めの一文にせず、確かめてほしい行動の中に含める（「申し込む前に、〜が自分に合うかを確かめてください」）
- 教育に気づかれないよう広告を記事に見せかける、はしない（`guardrails.md` §5）

|---|---|---|
| 目指す姿 | | |
| 信頼 | | |
| 原因への気づき | | |
| 解決の手段 | | |

抜けている要素が、売れない理由になっていることが多い。1本の投稿で全部を扱う必要はないが、配信や記事の全体では6つとも扱う。
