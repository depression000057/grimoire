# japanese-check — 読み直しで直す言い回しの例

使い方: 手順5の最初に本文を声に出すつもりで読み直す時、詰まった文をこの種類に当てはめて、文ごと作り直す。例は種類を見分けるための物で、例の文をそのまま使わない。

| 種類 | 直す前 | 直した後 | 見分け方 |
|---|---|---|---|
| 動作をそのまま名詞のように使う | 片付けては散らかすを続けてしまう | 片付けても、すぐに散らかってしまう | 「〜ては〜する」の後に「を」「が」が付いている |
| 2つの言い回しが混ざる | 気が向かわない日 | 気が乗らない日／足が向かない日 | 慣用の言い方を2つ思い浮かべ、どちらかに寄せる |
| 主語と述語が合わない | ダイエットがなかなか痩せない | ダイエットをしても、なかなか痩せない | 述語だけを取り出して「何が〜する」と言ってみる |
| 修飾が長くつながって、何にかかるか迷う | 店主が1人だけの、駅から遠い、小さな店の | 駅から少し遠い、店主が1人で開けている小さな店の | 「の」「、」で3つ以上つながったら、1つを文の外に出す |
| 設計シートの言葉が本文に混ざる | 毎日の目指す姿に近づく | 「こうなれたらいいな」と思っていた毎日に近づく | 型の枠や教育の要素の名前が本文に出ていないか探す |
| 何を指すか分からない指す言葉 | これを続けると、それが楽になる | 寝る前に5分だけ片付けると、朝の支度が楽になる | 「これ」「それ」「この」を、指している中身に置き換えられるか |
| 人が口にしない硬い言い方 | 購入の検討が可能です | 買うかどうか、ゆっくり考えてから決められます | 声に出して、目の前の人に言うか |
| 同じ語尾が続く | 〜です。〜です。〜です。 | 〜です。〜ですよね。〜でした。 | 文末を縦に並べて見る |
| 一文に言いたいことが3つ以上ある | 片付けが苦手で、時間も無く、家族も協力的でないので、なかなか進まない | 片付けが苦手で、時間も足りない。そのうえ家族の手も借りにくいので、なかなか進まない | 「、」でつないだ理由が3つ以上なら、2文に割る |
| 効果の言い方が強すぎる | これで毎日が変わります | 朝の支度で探し物をする時間が減ります | 変化を、読者の生活の具体的な場面で言い直せるか |

読み直しで直したら、もう一度頭から通して読む。1か所直すと前後のつながりが崩れることがある。
