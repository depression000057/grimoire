## §1 立ち上げ設計

### 1.1 市場と競合の見方（6手順）

1. キーワード検索で、その分野の大手アカウントを見つける
2. 関連アカウントやフォロー欄から、競合を芋づる式に拾う
3. 特に「**フォロワー数の割に反応が大きいアカウント**」を優先してメモする
4. 競合のよく伸びた投稿・長文記事・売っている商品の中身を見る
5. 競合が訴えている欲求・批判している古い常識・競合商品の不満点を書き出す
6. 大手が拾いきれていない隙間（テーマの絞り方・価格帯・サポートの形）を自分の立ち位置にする

### 1.2 狙う読者の4層

市場の読者は次の4層に分かれる。大きく伸ばす時は、母数が最も大きい**初心者・潜在層（約7割）**を取り込み、日々の投稿で引き上げるのが王道。潜在層に向ける時は、必ず「最初の一歩の壁」を扱う。

| 層 | 割合の目安 | 特徴 |
|---|---|---|
| トップ発信者層 | 約1% | すでに結果を出している層 |
| 実践プレイヤー層 | 約9% | 基礎は知っており、専門特化や高単価だけを選ぶ |
| 情報収集層 | 約20% | 今すぐ解決したい悩みがあり、購入意欲が高い |
| 初心者・潜在層 | 約70% | 母数が最大。悩みは漠然としているが、入口を合わせると大きく広がる |

### 1.3 コンセプト5要素とキャラ5類型

- **コンセプトの5要素**: ①誰が（強い実績、またはダメな今・過去とゴールとの大きな落差） ②誰を ③どれだけ（数値・手間・質・安定・速さのどれかで競合とずらす） ④なぜ（お金以外の発信理由を3〜5回深掘りする） ⑤どうやって（低単価・中単価・高単価サポートのどれで届けるか）
- **キャラクターの5類型**:
  1. **先導者タイプ**: 速さ・結果・熱量で背中を見せる
  2. **知識人タイプ**: 論理・分析・数字の分かりやすさで信頼される
  3. **仙人タイプ**: 自由・調和・長期目線で惹きつける
  4. **アイドルタイプ**: 親しみやすさ・仲間づくり・楽しさで集める
  5. **情報まとめタイプ**: 非属人で拡散しやすいが、高い商品を売るには向かない

### 1.4 プロフィールの組み立て（2つの型）

10の丁寧な説明より、1つの強い興味づけを優先する。ヘッダー・アイコン・名前・プロフ文のどこか1か所以上で「何の人か・なぜ見る価値があるか」が一瞬で伝わるようにする。

- **実績がある時**: 現在の実績（事実だけ） → 昔うまくいかなかった過去との差 → 発信している内容 → フォローする得 → 行き先（固定投稿やLINE・note）
- **これから実績を作る時**: 今の正直な状況 → 目指す大きな目標 → 挑戦の記録として発信する内容 → フォローする得 → 行き先
- **検索とおすすめ対策**: 届けたいジャンルの大事な言葉を **2〜3個**、プロフ文に自然に入れる（詰め込みすぎると機械っぽくなるため2〜3個まで）。

## §2 フェーズ別の動き方と投稿比率

投稿の役割は大きく3つに分ける。

1. **興味づけ（4型）**: 理想の暮らしや変化／古い常識への違和感／常識のひっくり返し／昔と今の落差
2. **ファン化・教育（7型）**: 行動している様子／学びに投資している様子／失敗からの立て直し／挑戦宣言／目標のくり返し／第三者の変化事例／過去や理念の開示
3. **価値提供（3型）**: 手順や箇条書きのまとめ／やり方＋気づいていない原因の指摘／やり方＋具体的な場面や比較

### 2.1 立ち上げ初期（フォロワー0〜数千人・開始1〜3か月）

- **最優先**: 知ってもらうことと、興味を持ってもらうこと。まだ誰か分からない時期に丁寧なまとめばかり出しても読まれにくい。
- **投稿比率の目安**: **興味づけ投稿を5割以上**（慣れてきても3割は残す）。
- **初速をつける4つの動き方**:
  1. **古い常識のひっくり返し**: 業界で当たり前とされているやり方に対し、根拠つきで別の見方を示す
  2. **理想の未来のテスト→一点突破**: 変化・手軽さ・暮らしなど複数の切り口を試し、反応が跳ねた切り口を深掘りしてくり返す
  3. **間接的なテーマへの問題提起**: 読者が陥りやすい別のやり方の落とし穴を論じる（特定個人の批判は絶対にしない）
  4. **上位発信者の実践報告ポジション**: 同ジャンルで伸びている人の学びを即実践し、リアルな感想と変化を丁寧に発信する（相手が自分では言いにくい良さを第三者として伝えることで引用されやすくなる）

### 2.2 育成・ファン化期（フォロワーが定着してきてから）

- **絶対に止めないこと**: フォロワーが増えても**興味づけ投稿（3割目安）を止めない**。新規の入口が止まると、アカウント全体の勢いが落ちるため。
- **日々の6アクション**: ①興味づけの継続 ②行動・学び・挑戦を「背中で語る」（実際の作業風景や画面を添えて報告） ③過去・失敗・理念を語る長文ポストの定期投下 ④ノウハウ＋原因・具体例の投稿で保存とフォロー理由を補強 ⑤小さな反応の積み上げ（いいね→返信・引用→企画や音声ライブ参加→LINE・メルマガ登録） ⑥外部の連絡先（LINE・メルマガ）への継続案内。

## §3 アルゴリズム攻略と「表示パワー」の守り方

### 3.1 フォロワー数より「表示パワー」と複数層のローテーション

- X は「フォロワー数＝届く数」ではなく、**読者の関心度合い（表示パワー）**で表示回数が決まる。放置すると時間とともに落ちる。
- フォロワーの中には「初心者」「中級者」「特定の悩みを持つ人」など複数の層が混ざっている。一部の層だけに刺さる投稿ばかり続けると、他の層への表示パワーが消える。
- **対策**: いくつかの風船を順番にふくらませるように、**投稿ごとに狙う層を順番に回して**全員を温め続ける。

### 3.2 伸ばすための5つの運用ルール

| ルール | 具体的なやり方 | 理由 |
|---|---|---|
| 1行目でタップを止める | 読者1人（N1）の口ぐせ・具体的な数字・続きが気になる言い回しを1行目に置く | タイムラインで指が止まらなければ本文も長文も評価されないため |
| ジャンルの一貫性を守る | **発信アカウントで関係のないジャンルを見ない・検索しない・いいねしない**（見る専用アカウントを分ける）。無関係なニュースやゴシップに便乗しない。日常を出す時は「日常×学び」にする | 関係のない人に届くと反応率が落ち、アカウント全体の評価が下がるため |
| プロフと投稿の言葉をそろえる | プロフに入れた2〜3個の軸の言葉と、普段の投稿テーマを一致させる | システムが「この人は何の専門家か」を正しく判断しやすくなるため |
| 初動30分の「反応率」を意識する | 末尾に答えやすい問い・診断・保存の理由を自然に置く。来た返信には丁寧に返し、自分の補足リプで滞在時間を伸ばす（露骨な相互拡散や無理なリプ強要は制限の原因になるため避ける） | 数の多さより「見た人のうち何割が反応したか」が拡散の引き金になるため |
| 数日後の再表示を前提に書く | 伏線や続きの投稿でも、**初見の人がその1本だけを読んで100%意味が通じる形**にする | 最近は投稿直後だけでなく、滞在時間や保存が高い投稿が数日〜1週間後に再表示されるため |

## §4 日常ポスト作成の5手順

書く前に毎回この5段を通すと、伸びない空振りを大きく減らせる。

1. **手順0（伝えたいことを1行に絞る）**: この1本で持ち帰ってもらう核を1つだけ決める
2. **手順1（誰に向けるか決める）**: フォロワーの中の具体的な1人（N1）を思い浮かべる
3. **手順2（1行目を最低1分磨く）**: その人が普段こぼす一言・数字・常識のひっくり返しで1行目を作る
4. **手順3（末尾の出口を置く）**: 問いかけ・当てはまるかチェック・保存の理由など、反応しやすい終わり方にする
5. **手順4（初見チェック）**: **自分のことをまったく知らない人**の目で読み直し、前後の文脈がなくても意味が通り、興味が湧くかを確かめる
