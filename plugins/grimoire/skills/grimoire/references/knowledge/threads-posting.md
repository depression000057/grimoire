# Threads 投稿の作り方

- 役割: Threads の投稿1本を「1行目 → 本文 → CTA → ツリー」の順に組み立てる判断基準と、投稿前に当てるチェックをまとめたもの
- いつ読むか: Threads の投稿を作る時・直す時（`references/modes/1_threads.md` §2 の4番目）。1行目で迷ったら §1 と §9、型で迷ったら §3、何本かまとめて作る時は §4 と §6
- 目次: §1 1行目／§2 本文の組み立て／§3 型カタログ／§4 ボリュームの4分類とツリー／§5 CTA／§6 企画の混ぜ方／§7 NG パターン／§8 投稿前チェックリスト／§9 1行目の候補を複数出して選ぶ手順

このファイルの読み方:

- マイナレッジや講座ナレッジに同じ工程のカードがある時は、カードを先に使う。ただし `references/quality/absolute-rules.md` の決まりは、どのカードでも上書きしない
- 「運営者の実例」と書いた文は、講座の運営者本人のアカウントで、運営者が合格を出した文。受講生とはジャンルが違うので、形だけ借りて言葉は写さない
- 〇〇・△△・□□・［ ］は、受講生のジャンルの言葉を入れる場所
- 各ルールの「理由:」は、ルール同士がぶつかった時や、ここに書いていない場面で迷った時の判断材料にする

| 言葉 | 意味 |
|---|---|
| 1行目 | タイムラインで最初に目に入る行。ここで手が止まらなければ、本文は読まれない |
| ツリー | 1本目の投稿に続きの投稿をつなげて、1つの話を複数の投稿に分ける形。つながった1本1本を「パート」と呼ぶ |
| CTA | 読み終わった人にしてほしい行動（コメント・保存・プロフィールを見る・LINE 登録・note を読む）を促す一言 |
| 読者1人（N1） | `00_わたしの設定.md` に書いた、この人に届けば十分という具体的な1人 |
| 固定投稿 | プロフィールの一番上に固定しておく投稿。LINE や note への入口にする |

---

## §1 1行目

流し見している人は、1行目だけを見て読むか飛ばすかを決める。本文がどれだけ良くても、1行目を越えた人にしか届かない。

### 1-1 主張で始める

- 1行目には、その投稿で一番言いたい結論を書く。悩みの説明・状況の説明・「今日は〜について話します」から始めない。理由: 説明から入ると、何を言う投稿なのか分からないまま指が次へ進む
- 本当の主張が本文の最後にあるなら、1行目へ移す。理由: 書き手は結論を最後に置きたくなるが、読者はそこまで読む前に離れる
- 行動か判断が分かる形にする。理由: 読者が「自分は今それをしているか」をその場で照らし合わせられる

```
〇〇はやめてください
〇〇したいなら△△してください
〇〇を選ばないでください
断言しますが、〇〇は△△です
何度も言いますが、〇〇していいです
お願いです、〇〇しないでください
```

- 言い切りの強さ（「〇〇するな」か「〇〇はやめてください」か）は、設定の「声」に合わせる。理由: 強い言葉でも、普段の口調とずれると本人の投稿に見えない
- 「見直すべき」「原因は〇〇です」「〇〇に注意」「タイプが違います」で止めない。何をどうすればいいかまで書く。理由: 何を見直すのかが書いていないと、読者は動きようがない
- 1行目の主張は1つにし、対象を並べない（✕「〇〇、△△、□□のストックが多い家は全部［容器］に収めて」→ ○「ストックは［容器］N個までにしてください」）。理由: 並べると、どれの話なのかがぼやける

### 1-2 具体語を入れる

- 1行目に次のどれかを1つ以上入れる: 商品名・食材名・サービス名／数字・年齢・回数・金額／場所・時間帯／行動・対象物／誰が言っているか（経験年数・立場）。理由: 抽象的な言葉だけでは読者の頭に場面が浮かばず、自分の話かどうかを判断できない
- 抽象語は具体語に置き換える（✕「［行動］やめて」→ ○「［体の悩み］で困る人は［具体的な食材］を食べてください」）。理由: 「やめて」だけでは、何をやめればいいのかが分からない
- 「誰が・何を・どの場面で」を省かない。理由: 省いた部分を読者が1通りに補えないと、意味が広がりすぎて刺さらない

運営者の実例（目的語を足した直し）:

```
✕ 身だしなみや持ち物にこだわる人を雑に扱うと一気に心が閉じる
○ 身だしなみや持ち物に妙にこだわる人。その人のこだわりを雑に扱うと、一気に心を閉じること、ありませんか🙈
```

✕ は「何を」雑に扱うのかが抜けていた。○ は「こだわりを」を足して、場面が1通りに決まるようにした。

### 1-3 主語は読者か、誰にでも起きる現象にする

- 1行目の主語は、読者本人か、誰にでも起きる現象にする。「私は」「〇歳のとき、私は」から始めない。理由: 流し見している人にとって、知らない人の昔話は手を止める理由にならない。自分にも覚えがある現象なら、読んだ瞬間に「私かも」が起きる
- 自分の体験は、2行目以降に「証拠」として1〜2文で置く。自分の話を厚くするのは、プロフィールと LINE の中にする。理由: 自分の話は、1行目に置くと早すぎる。プロフィールを見に来た人や LINE に登録した人は、もう話を聞く準備ができているので、そこで話せば読んでもらえる
- 例外: 体験そのものが、誰もが知りたい謎である時（めったにない出来事の中身など）は、自分主語でも止まる。理由: 読者は発信者のことを知らなくても、その謎の中身を知りたくて手を止めるから
- 「〜な人は、」で始めてよいのは、次の2つがそろう時だけ。①主語が誰にでもある現象で、条件を重ねていない ②同じ文の中で、読者の思い込みを否定するところまで言い切っている。「〜な人は聞いて」「〜したいあなたへ」は主張がないので使わない。理由: 呼びかけだけでは、何を言う投稿なのかが1行目で伝わらない
- ジャンルに分類がある時（肌のタイプ・骨格のタイプ・性格のタイプなど）、分類名は1行目の主語に使ってよい。理由: 読者は「自分のタイプかも」と思って止まる。運営者のアカウントでは、分類名を出さない一般論の1行目の方が反応が弱かった。1行目から外すのは、発信者の「私は」の方
- 絞りすぎない。そのジャンルの読者の半分以上、できれば8割くらいが「自分かも」と思える言葉にする。条件を重ねない。ターゲットを二度書かない。理由: 条件を重ねるほど当てはまる人が減り、当てはまらない人は1行目で離れる。読者1人（N1）の細かさは頭の中で持ち、1行目の言葉では広く開く
- ターゲットを書かなくても伝わるなら書かない（✕「〇〇を普通に払っている人」→ ○「〇〇は払わないでください」）。理由: 誰向けかを説明する言葉が、主張の場所を奪う

### 1-4 長さは40字前後

- 1行目は40字前後を目安にし、長くなったら後半を2行目へ回す。理由: 1行目が長いと、スクロール中に一目で読み切れず、主張が届く前に指が進む。機械チェック（`scripts/tn_check.py`）も、40字を超えた1行目を目視候補に出す

### 1-5 2段の形: ショート一撃 → 空行 → ロング結論

基本形は次の2段。

```
［ショート一撃］中身を伏せた短い一言（打ち明ける・言い切る）

［ロング結論］そこで初めて答えや原因を明かす1〜2文
［本文］
```

- ショート一撃は、打ち明ける言い方（「正直に言うと」「ここだけの話」「これあんまり言われないんですが」）か、言い切る言い方（「断言します」「はっきり言いますが」「結論から言うと」）で作る。理由: 長い結論文1本で始めると冒頭が重く、短い一言だけでは何の話か分からない。役割を分けると、手を止める一言と、自分の話だと思わせる一文を両方置ける
- 短くするために言葉を端折らない。理由: 端折って作った造語は不自然で、かえって引きが弱くなる。強さは、距離の近さ・本音らしさ・言い切る自信で出す
- ショートとロングで、同じ語・同じ主張を二度言わない（同義反復の禁止）。ショートは中身を伏せた合図にし、ロングで初めて中身を出す。理由: 同じ語が二度出ると、1文で済む話を2回聞かされる違和感が出て、ショートの「引き」が働かなくなる

運営者の実例（同義反復の直し）:

```
✕ 毎日ゼロから、もう卒業しましょう。
  毎日ゼロから投稿をひねり出してる人……（「毎日ゼロから」が二度出る）
○ 同じ時間でも、差がつきます。
  毎日ゼロから投稿をひねり出してる人、その消耗、一生終わりません
```

- 2段は基本形だが、同じショート一撃を3本続けて使わない。理由: 同じ出だしが並ぶと、読者に型が透けて見える

### 1-6 運営者の実例: 合格した冒頭と、直した冒頭

冒頭の入り方は5つに分けられる。まとめて作る時は、この5つを回す。

| 入り方 | 運営者の実例 |
|---|---|
| 言い切り | 「はっきり言いますが、優柔不断は欠点じゃないです」／「断言しますが、続かないのは意志の弱さじゃないです」 |
| 打ち明け | 「これあんまり言われないんですが、〜」。言わない場所を具体的にすると強い（「有料の〇〇でしか言わないんですが」）。ただし本当にそこでしか言っていない話に限る |
| 打ち明け＋気づき | 「正直に言うと、長く人を見てきて、相性で一番大事なのは性格じゃないと気づきました」 |
| 場面の言い当て | 「初対面はうまく話せないのに、心を許した相手にはびっくりするほど甘えてしまう」 |
| 寄り添い・問い直し | 「まだ大丈夫、まだいける。そう言い聞かせて無理を重ねていく。頑張り屋さんほど休んでいい合図を見落とします」 |

運営者の実例（弱い冒頭を直したもの）:

| 直す前 | 足りなかったもの | 直した後 |
|---|---|---|
| 人に頼るのが苦手な自分を責めてきたあなたへ | 言い切りがなく、本人の気持ちも言い当てていない | 人に頼れないのは、頑固だからでも可愛げがないからでもないです。「迷惑かも」って頼む前に全部想像しちゃう人ほど、抱え込みます |
| ルールでガチガチに縛られると急に何も思いつかなくなる人 | 説明から入っていて、言い切りがない | 正直に言うと、自由を奪われた瞬間に力が出なくなる人がいます。ルールで縛られると、急に何も思いつかなくなる |
| 人といたあとに、なぜかどっと疲れる | 本人がまだ言葉にしていない核に届いていない | 人といたあとに、なぜかどっと疲れる。これ、結構多くの人に当てはまるんですけど、体力の問題じゃないんです |

直した後の例は2〜3文あるが、1行目はそのうち最初の1文。2文目以降は2行目・3行目として改行して置く。

## §2 本文の組み立て

### 2-1 流れ

基本は次の流れにする。

```
主張 → 理由 → 具体例 → コメントを誘う一言
```

言いたいことに合わせて、次の2つに変えてもよい。

```
主張 → 読者が損していること → 解決の一部 → 続きはツリーへ
主張 → 理由 → 具体例 → もう一度主張（言い方を変えて締める）
```

理由: 1行目で止まった人は「本当に？ なぜ？」と思っている。すぐに理由を渡すと読み進め、具体例で自分の生活に当てはめられると、保存やコメントにつながる。

| 段 | 書くこと | 気をつけること |
|---|---|---|
| 主張 | 1行目の言い切り（§1） | 1投稿に1つ |
| 理由 | なぜそうなるのかの仕組みを1〜2文 | 「A だから B」の間を飛ばさない。A から B へ何が起きるのかを書く |
| 具体例 | 誰が・何を・どの場面で。読者の生活の一場面 | 読者1人（N1）が実際に口にする言葉・毎日触る物で書く |
| 締め・誘い | コメント・保存・次の行動（§5） | 投稿の中で答えが完結していること |

### 2-2 守ること

- 1投稿1テーマ。理由: 2つ入れると、読者はどちらを持ち帰ればいいか分からず、コメントも割れる
- 同じことを言うなら短い方を選び、コメントを誘うところまで早く進む。削るのは、前置き・長い状況説明・言い訳・同じことの言い直し・なくても伝わるターゲットの説明・抽象的な補足。ロングやヘビー（§4）は中身が多いから長くなるもので、前置きや言い直しで長くしない。理由: 中身の増えない文が多いほど、最後の誘いまで読む人が減る
- ただし、主語・理由・文と文のつなぎは削らない。意味が完全に通る文を先に作り、そのあとで短くする。理由: 短くするために意味を壊すと、読者は途中で読み返すことになり、そこで離れる
- 本文の中で答えを1つは渡す。全部の手順や詳しい理由をツリーや note に回すのはよいが、本文を答えのない予告だけにしない。理由: 何も持ち帰れない投稿は「で？」と思われ、次から読まれなくなる
- 感情が動く話を先に、理屈を後に置く。理由: 先に理屈を並べると、読者は自分の話だと感じる前に離れる
- 例え話は、読者1人が毎日手で触る物から作る。理由: 例えとして筋が通っていても、読者が触らない道具の話では場面が浮かばない

運営者の実例（50代女性に向けた動画台本の例え話の直し）:

```
✕ スマホの充電が残り10%で、アプリを50個開きっぱなし
○ お財布に一万円しかないのに、五十人分の手土産
```

- 箇条書きは1項目20字前後にし、スマホで1行に収める。形は「導入1〜2行 → 箇条書き → 誘い」で、1投稿に1回まで。本文 → 箇条書き → 本文 のはさみ込みはしない。理由: 折り返した箇条書きは読みにくく、本文の途中に挟むと話の流れが切れる
- かぎかっこの中は短く、実際に言われる言葉にする（✕「『［基準］を着た方が〇〇になるよ』ってよく言われるけど」→ ○「『［基準］を着ろ』ってよく言われるけど」）。理由: かぎかっこは「よく聞くあの一言」を思い出させる道具なので、長いと実際の声に聞こえない
- 絵文字は本文の途中に挟まない。使うなら文末か、強調したい1か所。量は設定の「声」に合わせる。理由: 主張やノウハウの途中の絵文字は、読む流れを止める
- 実績・体験・数字・相談の話は、設定に書いてある事実だけを使う。理由: 作った実績は、ばれた時に発信者への信頼を全部失う（`references/quality/absolute-rules.md`）

## §3 型カタログ

型は3つの層に分かれる。1本の投稿は、3つの層から1つずつ選んで組み合わせる。企画表（`references/modes/1_threads.md` §3）の「型」の欄には、3-3 の形の名前を書く。

- 3-1 狙う反応で選ぶ4タイプ（投稿全体の向き）
- 3-2 1行目の材料7つ（何を書き出しに使うか）
- 3-3 中身の組み立て12の形（本文の組み立て方。読者が参加する形を含む）

### 3-1 狙う反応で選ぶ4タイプ

| タイプ | 形 | 狙う反応 | いつ使う | 1行目の作り方 |
|---|---|---|---|---|
| 共感型 | あるある場面 → 読者の気持ちを代わりに言う → 余白を残す問いかけ | コメント | 読者1人の生活が細かく書けている時。「〇〇な人いますよね」程度のあるあるしか出ないなら使わない | 読者が実際に口にする言葉か、その場面の一瞬を切り取る |
| 有益型 | 気づき・ノウハウ → 理由 → 具体的な手順 → 保存かツリーへ | 保存 | 発信を始めたばかりで、何のジャンルの人かを覚えてもらう時期の中心 | やめるべき行動・結果・数字を言い切る |
| 物語型 | 体験を時間の順に → 学びは言い切らず余白を残す | フォロー | 発信者への興味を育てたい時。体験は事実だけ | 読者に起きる現象を主語にし、体験は2行目から（§1-3） |
| 意見型 | 強い主張 → 根拠 → よくある反論への答え → 問いかけ | 拡散・議論 | ジャンルの常識に、言いたいことがある時 | 常識を1行で否定する |

- フォロワーが少ない時期は、有益型と意見型を中心にする。理由: 誰でも保存したくなる情報や、はっきりした主張の方が、まだ知らない人にも読まれて、何のジャンルの人かが伝わる
- この配分は目安で、固定しない。理由: 反応が取れる配分はジャンルごとに違い、振り返りで数字が出るたびに見直す必要がある

### 3-2 1行目は、何を材料にするかで決める

1行目は、書き出しに使う材料で7つに分ける。どれも、設定・カード・実績にある本人の材料から作る（材料が無い物は使わない。材料を作るのは作り話になるため）。

| 材料 | 1行目の例 | 2行目からの流れ | 使う時 |
|---|---|---|---|
| 読者の場面 | 18時半、冷蔵庫を開けたまま5分止まっていませんか | その場面で起きていること → なぜそうなるか → 変える所を1つ | 設定の読者1人の1日が、時刻や物まで書けている時 |
| 読者の口ぐせ | 「なんでもいい」が、一番困るんですよね | その一言の裏にある本当の困りごと → 本人のやり方 | 設定に読者の口ぐせや、DM・コメントの実際の言葉がある時 |
| 読者の思い込み・習慣 | 献立は、毎日考えるものじゃないです／日曜の作り置き、今週はやめてみてください | そう思われている・続けてしまう理由 → 実際にはどうか → 最初の一歩 | 本人が、ジャンルの当たり前と違うやり方で結果を出している時 |
| 本人の数字 | 平日の晩ごはんが、1日20分で終わるようになりました | 前はどうだったか → 何を変えたか → 読者が真似できる所 | 実績カードに本当の数字がある時だけ |
| 本人のつまずき | 作り置きを3か月続けて、やめました | 何がうまくいかなかったか → 気づいたこと → 今のやり方 | 本人の失敗が設定かカードにある時 |
| 読者からの質問 | 「下味には何を使ってるの？」と聞かれました | 答え → 本人のやり方 → 気をつける所 | 実際に聞かれた質問がある時（作った質問は使わない） |
| このアカウントの行き先 | 平日の晩ごはんで毎日迷う人は、このアカウントを見ておいてください | ここで何を書いているか → 読むと何が変わるか | 集客の投稿（§6）。1週間に1〜2本まで |

まとめて作る時は、5本の中で3つ以上の材料を使い、同じ材料を3本続けない。理由: 同じ書き出しが並ぶと、読者に作り方が透けて見え、「またこの話」と思われる。

### 3-3 中身の組み立て（12の形）

ボリュームの名前（ミディアム・ロング・ヘビー）は §4。

| # | 形 | 組み立て | 長さの目安 | 1行目の材料（3-2） |
|---|---|---|---|---|
| 1 | 手順 | やることを順番に3〜5つ → つまずきやすい所 → 今日やる1つ目 | ロング | 読者の思い込み・習慣／本人の数字 |
| 2 | 比べる | 2つのやり方か2種類の人を並べ、違いの正体を1つに絞る | ミディアム | 読者の思い込み・習慣 |
| 3 | 当てはまるか確かめる | 読者の場面を5〜7つ並べ、いくつ当てはまったかで今の状態に気づいてもらう | ロング | 読者の場面 |
| 4 | つまずきから | 本人がつまずいた事実 → 原因 → 今どうしているか | ロング | 本人のつまずき |
| 5 | 記録 | 本人の1週間・1か月の実際（何をして、どうなったか） | ロング〜ヘビー | 本人の数字 |
| 6 | 質問に答える | 実際に聞かれた質問 → 答え → 本人のやり方 | ミディアム〜ロング | 読者からの質問 |
| 7 | 思い込みを解く | よくある思い込み → なぜそう思われるか → 実際はどうか | ミディアム | 読者の思い込み・習慣 |
| 8 | 使っている物 | 本人が毎日使っている物・道具 → なぜそれを使うか → 使い方 | ミディアム | 読者の場面 |
| 9 | 言い切り | 一番言いたいことを1文で言い切る → 理由と補足を1段落 | ミディアム | 読者の思い込み・習慣／本人の数字 |
| 10 | 変わる前と後 | 前の状態 → 変えたこと1つ → 今の状態（本人の事実だけ） | ロング | 本人の数字 |
| 11 | 選んでもらう | 読者の今の状態を2〜4つの選択肢で聞く → 選択肢ごとに一言 | ミディアム | 読者の場面・読者の口ぐせ |
| 12 | まとめて渡す | 1つのテーマで知っておくことを、ツリーで全部渡す | ヘビー | 本人の数字・このアカウントの行き先 |

11 は、読者が参加する形。理由: 読者の目を自分自身に向けさせるので、読むだけの人がコメントする人に変わる。

- 選択肢は、読者の「今の状態・気持ち」を選ばせる。最後に「どれでもない」を置く。理由: 「今夜ためす人は1」のような未来の行動を選ばせると、一読で何を答えればいいか分からない。逃げ道がないと、当てはまらない人が答えられない
- 答えを後に回す時は、答えを必ずツリーの2本目以降で出す。理由: 伏せたまま終わると、読者はだまされたと感じる

## §4 ボリュームの4分類とツリー

### 4-1 4分類

| 分類 | 長さの目安 | 形 | まとめて作る時の割合 |
|---|---|---|---|
| ミディアム | 300〜500字 | 1パートで完結 | 3割 |
| ロング | 合計650〜1000字 | 2〜3パートのツリー | 3.5割 |
| ヘビー | 合計900〜1500字（深い話なら上限なし） | 3パート以上のツリー | 2割 |
| ツリー | 字数より、続きを開いてもらうことが目的 | 1本目は短い引きで、答えや項目を2本目以降に1つずつ置く | 1.5割 |

- 200字に満たない短文だけの投稿は、4分類に入れない。言い切りの形（3-3 の9）も、補足を足してミディアムの長さにする。理由: 短文だけの投稿は中身が薄くなりやすく、並べた時に量産しているように見える
- 何本かまとめて作る時は、先に本数を決め、次に各投稿のボリュームを割り振ってから、テーマを当てる。理由: テーマから書き始めると、AI は無難な1つの長さに寄っていく。運営者が大量に作った投稿を測った時、ほぼ全部が200〜300字台に固まっていて、タイムラインで目立たなかった

| 本数 | 割り振りの例 |
|---|---|
| 3本 | ミディアム1・ロング1・ヘビーかツリー1 |
| 5本 | ミディアム1〜2・ロング2・ヘビー1・ツリー0〜1 |
| 10本 | ミディアム3・ロング3〜4・ヘビー2・ツリー1〜2 |

### 4-2 1パート500字以内

確かめ先: Meta の Threads 開発者向け資料「Text posts are limited to 500 characters.」 https://developers.facebook.com/docs/threads/posts （2026-09-26 に確認。同じ資料に、絵文字は1文字ではなく複数文字として数えられることがあると書かれている。絵文字を多く使う時は、490字くらいを上限の目安にする）

- Threads の1投稿は500字まで。1パートを500字以内にし、超える話はツリーに分ける。理由: 500字を超えると投稿できない
- ツリー全体の字数に上限はない。理由: パートをつなげば、深い話でも必要なだけ書ける

### 4-3 ツリーにする時・しない時

| ツリーにする | 1パートで出す |
|---|---|
| 500字を超える | 300〜500字で言い切れる |
| 手順やノウハウを順番に見せたい | 共感や主張を1つだけ届けたい |
| 答えを伏せて、続きを開いてもらいたい | 答えを伏せる必要がない |
| note・LINE・プロフィールへの案内を、最後に置きたい | 案内を入れない |

- ツリーばかりにせず、1パートで完結する投稿も混ぜる。理由: 毎回ツリーだと、続きを開く新鮮さがなくなる

### 4-4 ツリーの分け方

- 1本目は、それだけ読んでも意味が通るように書く。前置きで終わらせず、主張と、続きを読みたくなる引きを置く。理由: 1本目で離れる人が一番多いので、その人にも1つ持ち帰ってもらう
- 2本目からは、1パートに1つの役割を持たせる（理由／具体例／手順の1段／答え／案内）。理由: 1パートに役割を詰め込むと、どこで区切っても話のつながりが悪くなる
- 最後のパート以外は、次のパートで何が分かるかを予告する一文で切る。理由: 次を開く理由がないと、読者はそこで止まる
- パートに番号（1/3・2/3・3/3）を入れる。理由: 読者が全体の長さを見て、最後まで読むかを決めやすくなる
- note・LINE・プロフィールへの案内は、最後のパートに置く。理由: 本文を読み切って納得した人にだけ案内が届き、売り込みの印象が薄くなる
- 2パートで足りなければ、3〜4パートに伸ばしてよい。深い話なら5〜7パートでもよい。理由: 短く切ることより、話を十分に展開することが大事
- 1パートの字数に下限はない。代わりに「1パートに新しい情報を1つ以上入れる」を下限の目安にする。400字で言い切れる話を2つに割って、薄いパートを作らない。理由: 続きを開いて中身が薄いと、次からツリーを開いてもらえなくなる
- 書く時は、パートの区切りに `### ツリー2` のような見出しを置く（`references/modes/1_threads.md` §6）

## §5 CTA

### 5-1 行き先と、そこまでの道

CTA の行き先は2種類ある。

| 種類 | 行き先 | 使う場面 |
|---|---|---|
| 軽い反応 | コメント（絵文字ひとつ・番号ひとつ）・保存・フォロー | 普段の投稿 |
| 導線 | プロフィール → 固定投稿 → LINE 登録・note | 集客・教育・販売の投稿 |

- 投稿の本文に URL を貼らない。LINE の URL は特に貼らない。note と LINE の URL はプロフィールと固定投稿に置き、投稿からは「プロフィールの固定投稿」へ案内する。note の URL をどうしても投稿に置くなら、ツリーの最後のパートにする。理由: 運営者は、LINE の URL を本文に直接貼るとアカウントの制限につながる恐れがあり、外へ出るリンクが本文にあると読まれにくくなると判断して運用している
- 案内する前に、プロフィールと固定投稿を整えておく（`references/knowledge/threads-account-ops.md`）。理由: 投稿で興味を持った人がプロフィールに来ても、入口がなければそこで終わる
- 案内には「どこから・何をすると・何が手に入るか」のうち2つ以上を書く（例の形: 「プロフィールの固定投稿から、［入れるもの］を入れるだけで［手に入るもの］が出ます」）。理由: 「詳しくは調べてみて」のように手段が分からない誘いでは、読者は動けない
- 販売期間の投稿の組み方は `references/knowledge/sales-launch-evergreen.md` に従う

### 5-2 note・LINE へ架ける橋（7段）

「キーワードを送ってください → 特典を渡します」だけの案内にしない。次の7段を順に置く。

1. 本文の気づき
2. 読者に「これは自分のことだ」と言い当てる
3. 「あなたのせいではない」と安心させる
4. なぜその特典（note・LINE の中身）が必要なのか
5. 特典の中身と価値
6. どこから受け取るか（なぜ今それを見るとよいか）
7. 受け取った直後に、読者に起きること

理由: 本文から案内までの間に橋がないと、読者には唐突な売り込みに見え、自分が動く理由が分からない。

形（ツリーの最後のパートに置く時の例）:

> ［本文の気づき］
> 〇〇で手が止まっている人は、△△が足りないわけじゃありません。□□の順番を知らないだけです。
> その順番を、［note／LINE の特典の名前］にまとめました。［何が・いくつ入っているか］。
> プロフィールの固定投稿から読めます。
> 読んだその日から、［具体的な行動］の1つ目を迷わずに始められます。

### 5-3 ハードルは低く

- 普段の投稿の CTA は、心の中で完結する低いハードルにする。理由: 普段の投稿で行動を求めると、反応する人が一気に減る

| ハードル | 形 |
|---|---|
| なし（余韻） | CTA を置かず、読み終わって残るものだけで終える |
| 絵文字ひとつ | 「〇〇だった人は、コメントに［絵文字］をひとつ」 |
| 番号ひとつ | 読者の今の状態を①〜③で選ばせ、④に「どれでもない」を置く |
| 保存 | 「あとで見返したい人は、保存しておいてください」 |

- 購入・登録・期限つきの行動・書かせる・電話させる、といった高いハードルは、販売の投稿だけで使う。理由: 本気の人を絞り込む販売の場面以外で使うと、気軽にコメントや保存をしてくれていた人まで何もしなくなる
- 本名・生年月日・詳しい状況・相手とのやりとりは、コメントに書かせない。受け取るなら DM で受ける。理由: コメント欄は誰でも読めるので、読者の個人情報がさらされる

### 5-4 文末は投稿の中で完結させる

締めに置くのは、読者が持ち帰れる具体的な答えか、次の行動にする。読み終わった人の頭に「なるほど、そうだったのか」が浮かぶかで判断する。締めの形は次の4つを毎回変えて使う。

| 締めの形 | 形の例 |
|---|---|
| 分類ごとのおすすめ | ［タイプA］には［やり方］、［タイプB］には［別のやり方］を |
| 具体的な一言・動作 | 明日の［場面］で、［相手］に「［実際に言う一言］」と聞いてみてください |
| 数字で見える変化 | ［行動］を［期間］続けると、［回数・量］が［どう変わるか］（数字は実際に測ったものだけ） |
| 目に見える行動の変化 | ［相手／自分］が自分から［具体的な行動］をする日が出てきます |

締めに置かないもの:

- 「空気が変わります」「人生が変わります」「視野が広がります」「気持ちがラクになります」。理由: 何がどう変わるのかが見えず、読者は何も持ち帰れない
- 「ちょっと試してみて」「意識してみて」「取り入れてみて」。理由: 何をすればいいのかが書いていない
- 「詳しくは調べてみて」。理由: 答えを読者に丸投げしている

### 5-5 CTA を入れる割合と並べ方

- 導線の CTA（プロフィール・LINE・note への案内）は、全体の3割前後にする（3本なら1本、10本なら3本）。理由: 毎回入れると売り込みに見えてフォローを外され、1本もないと LINE の登録も note の売上も育たない
- 1投稿に CTA は1つ。理由: 2つ並ぶと、読者はどちらをすればいいか迷って、どちらもしない
- 導線の CTA を入れた投稿を2本続けない。その前後の投稿は、CTA なしか軽い反応だけにする。理由: 続くと、アカウント全体が販促の印象になる
- 軽い反応の一言（絵文字・保存）は、導線の CTA がない投稿の締めに使ってよい。ただし同じ言い回しを続けない。理由: 同じ誘い文句が並ぶと、機械が作った投稿に見える

## §6 企画の混ぜ方

### 6-1 4つの軸を混ぜる

| 軸 | 目的 | 形の例 |
|---|---|---|
| 有益 | 役に立つ情報で保存してもらい、何のジャンルの人かを覚えてもらう | ノウハウ・手順・NG集・チェックリスト |
| 興味付け | 「この人の話をもっと聞きたい」と思ってもらう | 常識への異論・発信者の見立て・意外な視点 |
| 集客 | フォローする理由・プロフィールを見る理由を作る | 1行目の材料「このアカウントの行き先」（3-2）・「この悩みがある人はこのアカウントを追っておいて」 |
| 教育 | 読者の考え方を変え、note が必要な理由の土台を作る | 「今のやり方でうまくいかない理由」「この悩みはこう考える」 |

- 有益だけで埋めない。週単位で4つとも入るようにする。理由: 役に立つだけの投稿は、その場で満足されて終わり、発信者への興味も note への関心も育たない
- 教育と販売の投稿は、すぐに数字が伸びなくて正常。共感や有益を狙った投稿が伸びなかった時だけ直す。理由: 教育と販売の投稿は届けたい読者が狭いので、閲覧が伸びにくい。閲覧の数字だけを見て直すと、狙いの違う投稿まで共感や有益の投稿と同じ形に直してしまう

### 6-2 型と見せ方を回す

- 中身の形（3-3）は、3本なら3種、5本以上なら5種以上を使う（5本なら5本とも別の型）。同じ型は1セットに2本まで、3本続けない。理由: 同じ型の繰り返しは、読者から見ると機械が作った投稿に見える
- 1行目の材料（3-2）は、5本で3つ以上。同じショート一撃を3本続けない
- ボリューム（§4）も散らす。型だけ変えて、全部同じ長さにしない
- 見せ方も散らす。1パートの投稿・ツリー・会話（相談者とのやりとりを再現する）・ひとり語り・Q&A・リスト・告知を混ぜる。理由: 型を変えても、全部が「1行目 → 本文 → 締め」の同じ見せ方だと、タイムラインでは同じ投稿に見える
- 締めの形（5-4）と語尾も散らす。同じ語尾で終わる投稿を3本続けない
- 伸びた投稿の1行目の型・言い回しは使い回してよい（「何度も言いますが」「お願いです」「断言しますが」など）。ただし、使い回す時は対象・場面・数字を変え、同じネタの言い換えを続けて出さない。理由: 運営者のアカウントでは、伸びた型を同じ構造・同じネタの言い換えで続けた時期に、反応がはっきり落ちた

### 6-3 入り方の手札

3本以上まとめて作る時は、話の入り方を次の手札から3種以上選び、同じ手札を3本続けない。

| 手札 | 入り方の形 |
|---|---|
| A 今のやり方から | 「今は〇〇している」「やっているのは〇〇だけ」 |
| B 過去の経験から | 「最初は自分も〇〇だった」「〇〇で失敗した」 |
| C 結論から | 「正解は〇〇。これだけ」「結論から言うと〇〇」 |
| D 例え・比べから | 「〇〇って、△△と同じ」「これを△△に置き換えると」 |
| E 人から言われたことから | 「〇〇と言われた」「こんな相談が来た」 |
| F 課題から仕組みへ | 「〇〇できない原因は、△△じゃない」 |
| G 質問と答え | 「〇〇って何？ → △△のこと」 |

- A と B は自分の話から入る手札なので、1行目は §1-3 どおり読者側の主張にし、手札は2行目から使う。理由: 読者が手を止めるかどうかは1行目の主語で決まるので、入り方の手札より主語のルールを優先する
- 「最初は自分も〜」「ある日、〜してみた」「直したのは〇〇だけ」「これだけで〇〇になった」は、1セットに1回まで。理由: 1本ずつなら問題ないが、全部の投稿が同じ骨組みだと、箇条書きを並べたようなテンプレート感が出る

### 6-4 読者1人に直接向ける投稿は1〜2割

- 読者1人（N1）の具体的な生活に直接向けて書く投稿（共感型）は、全体の1〜2割にする。残りは、誰が読んでも役に立つ有益型・意見型で組む。理由: 毎回同じ1人に向けるとくどくなり、有益・意見の投稿が減って、何のジャンルの人かが伝わりにくくなる

## §7 NG パターン

### 1行目

| NG | なぜダメか |
|---|---|
| 説明・状況描写・「今日は〜について」から始める | 何を言う投稿か分からないまま、指が次へ進む |
| 「〇〇な人は聞いて」「〇〇したいあなたへ」で始める | 呼びかけだけで主張がない。1セットに何度も出ると、アカウント全体に弱い投稿の印象が残る |
| 「見直すべき」「原因は〇〇です」「〇〇に注意」「〇〇を疑って」で止める | 読者は何をすればいいか分からないまま終わる |
| 条件を重ねたターゲット指定・ターゲットの二重書き | 当てはまる人が減り、当てはまらない人は1行目で離れる |
| 1行目に対象を並べる | どれの話か分からず、主張がぼやける |
| 自分の昔話から始める（自分主語） | 知らない人の話に、流し見している人が止まる理由がない |
| ショートとロングで同じ語・同じ主張を二度言う | 1文で済む話を2回聞かされる違和感が出て、引きが消える |
| 短くするために言葉を端折った造語 | 不自然な日本語はかえって引きが弱い |

### 本文

| NG | なぜダメか |
|---|---|
| 1投稿に2テーマ | 読者がどちらを持ち帰ればいいか分からない |
| 前置き・状況説明が長い | 主張に着く前に読者が離れる |
| 抽象的な言葉だけ（「夢を諦めないで」「努力は裏切らない」） | 誰に向けた話か見えず、読者の生活に結びつかない |
| 「A だから B」だけで、間の仕組みを飛ばす | 読者が納得できず、主張が押しつけに聞こえる |
| 「これ」「それ」「こんなこと」が何を指すのかぼやけている | 読者が前を読み返すことになり、そこで離れる |
| 普通の日本語では組み合わせない名詞と動詞（［抽象的な名詞］が［整う／動き出す／軽くなる］） | 雰囲気はあっても、何が起きたのかが浮かばない |
| 解説者ぶった第三者目線（「〜は事故になります」「〜気質です」） | 読者を上から評価しているように聞こえ、自分の話として受け取れない |
| きれいごとで締める（「大切にしたいですね」「〜と信じています」） | 誰でも言える一般論で、読者の手元に何も残らない |
| 締めの決めゼリフ（短い言い切りで余韻を作る）・場面を「夜」「未来」「景色」のような大きな言葉に置き換えた予言 | 目の前の相手に声では言わない言葉で、作り物に聞こえる |
| 本文 → 箇条書き → 本文 のはさみ込み、スマホで折り返す長い箇条書き | 話の流れが切れ、読みにくい |
| 本文の途中の絵文字 | 主張やノウハウを読む流れを止める |
| 読者が毎日触らない物での例え | 筋は通っていても場面が浮かばない |
| 同じ語尾が3文続く | 文のリズムが単調になり、機械が書いた文に見える |
| 実績・数字・相談事例の作り話 | ばれた時に、発信者への信頼を全部失う |
| 収益や効果を約束する言い方（誰でも・必ず・100% など） | 読者を傷つけ、規約や法律に触れる恐れがある（`references/quality/absolute-rules.md`） |

### CTA

| NG | なぜダメか |
|---|---|
| 「詳しくは調べてみて」（手段が分からない誘い） | 読者は動き方が分からない |
| 「空気が変わります」（抽象的な結論） | 何も持ち帰れない |
| 「意識してみて」（何をするか分からない指示） | 読者は何をすればいいか分からない |
| 普段の投稿で「今日中に〇〇して」「ノートに書いて」 | ハードルが高く、気軽に反応してくれていた人まで何もしなくなる |
| 個人情報をコメントに書かせる | 誰でも読める場所で、読者の情報がさらされる |
| 本文に URL を貼る | 運営者の運用では、アカウントの制限や読まれにくさにつながると判断している |
| 1投稿に CTA を2つ以上・毎回 CTA を入れる | 迷って誰も動かず、アカウント全体が売り込みに見える |

### アカウント全体

| NG | なぜダメか |
|---|---|
| 1投稿に何人もメンションを付ける | 宣伝目的の投稿に見える |
| 同じ型・同じ入り方・同じ長さが続く | タイムラインで同じ投稿が並んでいるように見える |
| 「今夜」「朝」など時間の言葉と、投稿する時刻がずれている | 朝に「今夜」と書いた投稿が届くと、読者は置いていかれ、予約投稿だと透けて見える |

## §9 1行目の候補を複数出して選ぶ手順

最初に思いついた1案で決めない。1行目で読まれるかどうかが決まるので、候補を並べて比べてから選ぶ。

### 9-1 案の数

- 1本だけ作る時・1行目を磨き直す時は、10案出す
- 何本かまとめて作る時は、`references/modes/1_threads.md` §4 の案数（1本ごとに5案、10本以上なら3案）にしてよい。手順は同じ

### 9-2 手順

1. **本文の本当の主張を1文で書く**。本文の中身が決まってから1行目を作る。理由: 何を言い切る投稿かが決まっていないと、候補が雰囲気の違う言い換えになるだけで、比べる意味がなくなる
2. **材料を3種類出す**。①主語の候補（読者／誰にでも起きる現象／ジャンルの分類名）②具体語の候補（物の名前・数字・場面）③否定したい常識（読者が思い込んでいそうなこと）。理由: 材料が少ないと、10案がどれも似た形になる
3. **10案を作る**。3-2 の7つの材料と §1-6 の5つの入り方から5種類以上を使い、同じ型は2案まで。2段の形（ショート一撃 → ロング結論）の案を3案以上入れる。マイナレッジに `threads-hook` のカードがあれば、候補の半分以上をそのカードに沿わせる。理由: 型を散らすと、思いつかなかった切り口が候補に入る
4. **足切りをする**。次のどれかに当たる案は落とす: 主張がない／具体語がない／自分主語で始まる（§1-3 の例外を除く）／条件を重ねた呼びかけ／ショートとロングの同義反復／誇大な表現／§8「日本語」の5問に落ちる。理由: 点数をつける前に、出してはいけない案を先に外す
5. **残った案を3本柱で採点する**（10点満点）。7点以上の案だけを残す。理由: 3本がそろうと強い冒頭になり、1本でも欠けると弱く見える

| 柱 | 見ること | 点数 |
|---|---|---|
| 言い切り（0〜4） | 1行目の先頭で、短く言い切っているか | 先頭で言い切る＝4／強い言葉が後ろにある＝2／説明から入る＝1／言い切りがない＝0 |
| 場面（0〜3） | 誰が・何を・どの場面で、が補わなくても浮かぶか | 補わずに浮かぶ＝3／少しあいまい＝2／目的語が抜けている＝1 |
| わかってくれてる感（0〜3） | 読者が薄々感じているのに、まだ言葉にしていないことを言い当てているか | 言い当てている＝3／共感で止まっている＝2／一般論＝1 |

6. **点数が並んだ時の比べ方**: 40字前後に収まっているか／読者の半分以上が「自分かも」と思えるか／ショート一撃を同じセットの他の投稿と使い回していないか、の順で比べる
7. **上位3案を、本文の2行目以降とつなげて読む**。1行目から2行目へ理由がつながり、本文で1行目の約束を果たせる案を選ぶ。理由: 1行目だけ強くても、本文が約束を果たさないと、読者はだまされたと感じて次から読まなくなる
8. **記録を残す**。提出メモに、採用した案・使った型・点数と、次点の2案を書く。理由: 受講生が次点に差し替えられ、振り返りの時に、どの型の1行目で閲覧やコメントが増えたかを突き合わせられる

候補を並べる時の表:

| # | 候補 | 型・入り方 | 言い切り | 場面 | わかってくれてる感 | 計 |
|---|---|---|---|---|---|---|

### 9-3 7点以上の案が1つもない時

- 手順2に戻って、材料（具体語・否定したい常識）を足してから作り直す。言い回しだけを変えて作り直さない。理由: 点が低い原因の多くは材料不足で、言い回しをいじっても点は上がらない
- 2回作り直しても7点に届かない時は、テーマを見直す。読者が本当に知りたいことか、発信者が言いたいだけのことかを確かめる。理由: 読者が求めていないテーマは、どの1行目を付けても止まってもらえない
