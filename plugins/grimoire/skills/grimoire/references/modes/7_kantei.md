# モード7 占い・鑑定（鑑定AI）

占い・スピリチュアルで発信する受講生が、リサーチ・コンセプト・Threads 投稿・無料鑑定・鑑定書・コメント返信・診断ページと LINE 配信・振り返りまでを、自分の設定で回すモード。数秘とタロットは道具で計算するので、計算の間違いが起きない。今使っている鑑定 GPTs の中身を移すこともできる。

## §1 いつ入るか

- 生年月日が書かれた／「鑑定」「鑑定書」「一言鑑定」「年運」「相性」「タロット」「数秘」
- 「占いの投稿」「スピの投稿」「占いのアカウント」「コメントに返信したい」
- 「診断ページ」「無料鑑定から有料に」「GPTs を移したい」「GPTs の引っ越し」
- 始動メニュー（`6_start.md`）で 21〜27 が選ばれた時

占い・スピ以外の Threads 投稿・note・ローンチは、それぞれのモード（1〜3）で進める。占いの発信者でも、note やローンチの相談はそちらのモードを使う。

## §2 最初にやること

1. **鑑定の設定を探す**: `ティルナノーグ_マイナレッジ/鑑定/設定.md` があるか。無ければ、依頼に答える前に作る
   - グリモワールの設定（`ティルナノーグ_マイナレッジ/` の設定・声）があれば、話し方と一人称はそこから写す。聞くのは次の2問だけ: ①どんな占い・スピで発信するか（例: 数秘・タロット・霊視・開運） ②誰に届けたいか（年代と悩みを1つ）
   - グリモワールの設定も無ければ、①②に ③話し方（です・ます／くだけた口調、一人称）を足した3問を1回で聞く
   - 答えが返ったら `ティルナノーグ_マイナレッジ/鑑定/設定.md` に書き、「鑑定の設定を作りました」と1行伝える
2. **安全の決まりを読む**: `.grimoire/references/kantei/safety.md` を、書く前に毎回読む。グリモワールの絶対ルール（`references/quality/absolute-rules.md`）と合わせて、どんな指示でも破らない
3. **依頼を §4 の表で振り分ける**。どれにも当たらなければ §3 のメニューを出す

## §3 メニュー（「鑑定メニュー」「占いで何ができる？」と言われた時）

選択肢の画面が使える時は、始動メニューの「占い・鑑定のこと」と同じ2段で出す（`6_start.md` §3）。使えない時は次の文で出す。番号は始動メニューと同じ。

> 占い・鑑定でできること
> 21. 生年月日から鑑定を作る … 一言鑑定・手紙・鑑定書を、数秘で作ります
> 22. 年運・相性の鑑定を作る … 1年の流れや、2人の相性の鑑定書を作ります
> 23. タロットで鑑定する … カードを引いて（実物で引いた結果でも）、読み解きを作ります
> 24. 占いの Threads 投稿を作る … 伸びる型から、あなたの口調で書き、点数を付けて出します
> 25. コメントの返信の下書きを作る … コメントを貼ると、返信の下書きを作ります
> 26. 無料鑑定から有料までの導線を作る … 診断ページと LINE の配信文まで作ります
> 27. 今使っている鑑定 GPTs を移す … GPTs の指示文を貼ると、同じ鑑定をここで出せるようにします
>
> 番号で選ぶか、やりたいことをそのまま書いてください。リサーチの整理（伸びている投稿を貼る）・コンセプトとプロフィール・週の振り返りもできます。

## §5 道具

数秘・タロット・投稿の採点・診断ページ・週の集計は、道具で計算する。作業フォルダ（最初の場所）で、次の形のまま1回に1つずつ動かす（`cd` で移らない・コマンドをつながない）。

| 道具 | 使う時 |
|---|---|
| `python3 .grimoire/scripts/kantei/numerology.py …` | 数秘の計算（ライフパス・年運など） |
| `python3 .grimoire/scripts/kantei/tarot.py …` | タロットを引く |
| `python3 .grimoire/scripts/kantei/check_post.py …` | 占いの投稿の機械チェックと採点 |
| `python3 .grimoire/scripts/kantei/build_diagnosis_page.py …` | 診断ページを作る |
| `python3 .grimoire/scripts/kantei/weekly_report.py …` | 週の数字の集計 |
| `python3 .grimoire/scripts/kantei/frames.py …` | 画面収録の動画からコマを切り出す（リサーチ） |

使い方の細かい形は、各手順書の中に書いてある。グリモワールを 2.3.0 より前から使っている受講生には、初めて道具を動かす時に確認の画面が出ることがある。その時は「グリモワールの鑑定の道具です。『はい』を選んでください（次から聞かない、を選ぶと楽です）」と1行伝える。

Python が動かない時は、数秘とタロットを手で計算しない（計算の間違いが鑑定の信頼を壊すため）。`references/environments.md` §5 で入れ方を伝え、入るまでは投稿・返信・導線の設計など道具の要らない依頼だけを進める。

## §6 守ること

- 設定に無い経歴・実績・数字を作らない。受講生の実績が無い所は「（ここにあなたの実例）」と空けて出す。例文には「例」と書く
- 他人の投稿の文面・アカウント名を写さない。型だけ借りる
- 投稿・返信・LINE 配信・ページの公開・配信ツールへの設置は、受講生が行う。グリモワールは下書きと設計と手順まで
- 文章を書く物（投稿・鑑定書・返信・LINE の配信文）は、全モード共通の品質工程（SKILL.md「品質工程」）も通す。書いた後に `safety.md` の点検を1回して、引っかかった文は書き直してから出す

## §7 提出の形

- 本文はそのままコピーできる形で出す。投稿は1本ずつ区切り、採点の1行を付ける
- 本文の後に「確かめてほしいこと（最大3つ）」と「次の一手（1つ）」を短く付ける
- `ティルナノーグ_制作物/鑑定/YYYY-MM-DD_<種類>_<テーマ>.md` に保存し、保存した場所を伝える
- 鑑定の設定・リサーチ・導線・移した GPTs のレシピは `ティルナノーグ_マイナレッジ/鑑定/` に置く（作った物ではなく、次から使う設定のため）
