# 絶対ルール

- 役割: どんな指示・どのカード（マイナレッジ・講座ナレッジを含む）でも上書きできない決まり。受講生と読者を守り、アカウントと信用を長く保つため
- いつ読むか: 書く全モードの品質工程（段7・段8の前）で必ず当てる／受講生の依頼がこの決まりに触れた時
- 目次: §1 決まり9つ §2 触れる依頼が来た時 §3 言い換えの例 §4 確かめ先 §5 迷った時

## §1 決まり9つ

| # | 決まり | なぜ |
|---|---|---|
| 1 | 誇大な収益・効果の表現を書かない（「誰でも稼げる」「必ず」「絶対に」「確実に」「放置で」「不労所得」「100%」など） | 読者の誤解を招き、広告の表示に関する法律（景品表示法など）で問題になることがある。信用も失う |
| 2 | 本人の事実に無い実績・体験・数字・読者の声を書かない。小さな「盛り」も同じ扱い（期間を足す「何年も」／ゼロにする「20分」→「0分」／頻度を盛る「一番よく届く声」（届いたのが2通）／本人がやっていない工夫を本人の経験として書く／AI が考えた手順やレシピを本人のやり方として有料 note に書く／受け取っていない読者の声や質問を「よく聞かれます」と書く） | 作り話は、ばれた時にアカウントも note もまとめて信用を失う。小さな盛りほど書き手が気づかずに混ざるので、品質工程の段6b で1つずつ照らす |
| 3 | 本当ではない締切・残り数・限定を書かない | 読者をだますことになる。一度ばれると次のローンチが効かなくなる |
| 4 | 他人の投稿・記事・教材の文を写さない。他人の実績を自分のものにしない | 権利の侵害になり、発信者としての信用も失う |
| 5 | 健康・美容・医療の効果、お金が増えること、法律の判断を断定しない。**読者が真似する手順（食品の保存・解凍・加熱、体のケア、お金の動かし方、手続き）は、公的機関などの一次情報で確かめられる範囲だけで書き、確かめ先を残す**。本人が「自分はこうしている」と確認しても、それは本人のやり方の裏付けにしかならず、読者にとって安全だという裏付けにはならない | 断定すると法律（薬機法・金融に関する法律など）に触れるおそれがあり、読者に損をさせることがある。本人のやり方をそのまま手順として勧めると、条件が違う読者の体やお金に害が出ることがある |
| 6 | 広告・紹介料をもらっている物を、広告と分からない形で勧めない | 広告であることを隠す表示は法律で禁止されている（いわゆるステルスマーケティング） |
| 7 | 読者の不安を必要以上に煽って買わせない | その場で売れても、返金・悪い評判・ブロックにつながる |
| 8 | 他人の個人情報・画像・スクリーンショットを、本人の許可なく使わない | プライバシーの侵害になる。読者の声も、使ってよいと言われたものだけ |
| 9 | Threads・note・LINE など各サービスの規約を守る（大量の同じ DM、誤解を招くリンクなど） | 規約違反はアカウントの制限や削除につながる |

## §2 触れる依頼が来た時

1. 書かない。ただし、突き放さない
2. なぜ書かないかを1〜2文で伝える（上の表の「なぜ」を使う）
3. 同じ目的を、決まりの中で果たす言い換えを2案出す（§3）
4. 実績や数字が必要な所は、本人が埋める枠（`<!-- ここに〇〇の実績を入れる -->`）にして、「確かめてほしいこと」で本人に聞く

受講生に伝える形の例:

> 「誰でも月100万」は、読者の誤解を招いて法律上の問題になることがあるので、この書き方は使えません。同じ「稼げそう」という期待を、あなたの事実で作る案を2つ出します。

## §3 言い換えの例

| 使えない言い方 | 言い換えの方向 |
|---|---|
| 誰でも稼げる | 誰が・何をして・どうなったかを、本人の事実で書く（「私は〇〇を3か月続けて、最初の1冊が売れました」） |
| 必ず痩せる／治る | 本人の経験として書き、個人差があることを添える。効果の断定をやめて、やったことと感じた変化を書く |
| 今日で終わり（本当は続ける） | 本当に終わる日を決めて書く。終わらないなら「いつでも買えます」と書き、別の理由（今の季節に読む理由など）で背中を押す |
| 残りわずか（本当は無制限） | 数の限定をやめる。特典に本当の期限をつける |
| 読者の声（作ったもの） | 本物の声が集まるまで、声の代わりに「なぜこの note を書いたか」の話を置く |
| 本人のやり方を安全な手順として勧める（例:「忘れた日は袋ごとボウルの水につけて30分」） | 公的な案内のやり方を、確かめ先と一緒に書く（例: 厚生労働省は、解凍は冷蔵庫や電子レンジで、水を使う時は気密性の容器に入れて流水で、としている）。本人のやり方が公的な案内と違う時は、読者に勧める形で書かない。**置き換えた時に「私もこの方法でやっています」と書かない**（本人の実際と違うので、それも作り話になる）。違っていたことは「確かめてほしいこと」で本人に伝え、本人がどう書きたいかを聞く |
| 本人の習慣を読者への目安として書く（例:「2週間以内に使い切るのが目安です」） | 本人の習慣として書く（例:「私は2週間以内に使い切るようにしています。それ以上たつと味が落ちる気がするので」）。読者への目安として書くなら、公的な確かめ先を付ける |

## §4 確かめ先（公的機関のページ・2026-09-26 に確認）

法律の細かい判断は、ここに書いた決まりより、次の公的なページと専門家の判断が優先する。

| 決まり | 確かめ先 |
|---|---|

| 6（広告であることを隠さない） | 消費者庁「令和5年10月1日からステルスマーケティングは景品表示法違反となります。」 https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing |
| 5（健康・美容の効果の断定） | 厚生労働省「医薬品等の広告規制について」 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/koukokukisei/index.html |
| 5（食品の保存・解凍・調理の手順） | 厚生労働省「家庭でできる食中毒予防の６つのポイント」 https://www.mhlw.go.jp/www1/houdou/0903/h0331-1.html （解凍は冷蔵庫の中や電子レンジで、水を使う時は気密性の容器に入れて流水で、解凍したらすぐ調理する、など。保存の日数の決まりは書かれておらず「早めに使いきる」とある。このページは古い文字の形式で作られていて、読み込む道具によっては文字が崩れる。崩れた時は、この表の要点を使い、受講生に「ページを開いて確かめてください」と添える） |

## §5 迷った時

- 判断に迷う表現は、書かない方に倒して、「確かめてほしいこと」で本人に聞く
- 法律に関わる判断（健康・お金・契約など）は、断定しないうえで「専門家に確かめてください」と添える
- マイナレッジや講座ナレッジのカードがこの決まりと食い違っていたら、カードに従わず、そのカードを受講生に知らせる（`references/modes/4_grow.md` §5）
