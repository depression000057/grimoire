# 市場の言葉で書く

- 役割: 投稿・note・告知・プロフィール・名前を、受講生が集めた「伸びた投稿」の言葉のまま書くための決まりと手順。それっぽい言葉を作らず、言い換えずに書く
- いつ読むか: 書く全モードの品質工程の段1（市場の言葉の表を読む）と段6d（書いた句を数える）（`references/quality/pipeline.md`）／他人の伸びた投稿が貼られた時／アカウント名・肩書き・コンセプトの一言・柱の名前を決める時
- 目次: §1 それっぽく書かない §2 元にする言葉は、出す物で変わる §3 受講生にとっての市場＝集めた伸びた投稿 §4 道具 §5 書く前: 市場の言葉の表を読む §6 書く時: その言葉のまま書く §7 書いた後: 句のまま数える §8 写さない決まりとの線引き §9 ほかの決まりとの関係 §10 よくある失敗

## §1 それっぽく書かない（2026-11-12 講師の指示）

講師の言葉: 「市場が答え。市場で伸びているっていうことは、文体とか言葉遣いとかニュアンスも含めて伸びてる」「それっぽく書くっていうのをなくせば、文章は自然になる」。

AI は、元の言葉を自分の言葉に訳し直して、それらしい言い回しを作りやすい。これが「それっぽく書く」こと。訳し直すたびに意味が少しずれ、日本人がふつうは言わない文になる。新しく作った名前やまとめの言葉は、読者が一度も見たことのない言葉なので、そこで読む手が止まる。

伸びた投稿の言葉は、読者がもう知っていて、実際に反応した言葉。それをそのまま使えば、文は自然になり、読者にも一度で通じる。だから次の4つをしない。

1. 元の言葉を言い換えない
2. 説明の言葉に開いたり、きれいな言葉に直したりしない
3. 新しい名前・まとめの言葉・肩書きを作らない
4. 似すぎを避けるために、言い回しの方を変えない（変えるのは中身。§8）

足してよいのは、本人の中身（題材・本人の事実・本人の声）だけ。手本の文の形と言葉はそのままにして、中身だけを入れ替える。

## §2 元にする言葉は、出す物で変わる

| 出す物 | 元にする言葉（ここに無い言葉は作らない・言い換えない） |
|---|---|
| 投稿・プロフィール・固定投稿・note（題・見出し・本文）・告知・LINE の配信・アカウント名・肩書き・コンセプトの一言・柱や型の名前・企画表のセル | 受講生が集めた伸びた投稿の言葉（§3） |
| コメントや DM への返信の下書き | 相手の文面にある言葉と、本人（受講生）のふだんの言い方（設定の「声」・お手本） |
| グリモワールから受講生への説明・報告・質問 | 受講生が使った言葉と、画面・ファイルに出ている名前 |
| マイナレッジのカード | 講師・本人の原文（引用で残し、言い換えた要約で置き換えない） |

判定は1問: **その言葉は元の言葉にあるか、日本人がふつうに口で言うか**。どちらでもない言葉（自分で作った名前・まとめの言葉・訳した言い回し）は、元の言葉に戻す。

## §3 受講生にとっての市場＝集めた伸びた投稿

市場の言葉の元は、受講生が自分のジャンルで集めた伸びた投稿の原文。講座の第2回勉強会で集めた「コメントが多い投稿」と同じ物を使う。

- **置き場**: `ティルナノーグ_マイナレッジ/50_市場の投稿/`。1回ぶんの貼り付けが1ファイルになる。鑑定モードの `ティルナノーグ_マイナレッジ/鑑定/集めた投稿.md` も、同じ市場の投稿として道具が数える
- **保存は道具で行う**: 貼られた他人の投稿は `market-add`（§4）で、原文のまま保存する。手でフォルダを作らない（`mkdir` は受講生の画面に確認が出るため）。カードにはしない（他人の文を本人のナレッジとして覚えないため）
- **外に出さない**: 原文は手元のマイナレッジにだけ置く。投稿・note・人に見せる資料に、原文やアカウント名を写さない
- **集め方**: 受講生に頼む時は、`references/kantei/research.md` の「利用者への案内」と同じ形で頼む（自分のジャンルの言葉で検索して、いつもより数字が多く、コメントが多い投稿を選び、本文と数字を貼ってもらう）。誰の投稿かが分かる形で貼ってもらうと、何人が使っている言い回しかも数えられる
- **フォルダがまだ無くても道具は動く**（0本として扱う）。ただし、マイナレッジに `カード` のフォルダが無い時は、`market-add` が「先に init」と出して止まる。その時は先に `tn_kb.py init` を動かす（`references/modes/0_setup.md` §2）
- **別のパソコンへ移す時**: マイナレッジを `tn_kb.py export`・`import` のまとめファイルで移すと、`50_市場の投稿/` と `市場の言葉.md` は付いてこない。付けて移したい時は、`ティルナノーグ_マイナレッジ/` のフォルダごとコピーしてもらう（`references/environments.md` §4）

**貼られた投稿を `market-add` に渡す前に整える**（受講生には直させない。グリモワールが整えた文を `--text-file -` で渡す）:

| 整えること | なぜ |
|---|---|
| 投稿と投稿の間を、`---` だけの行か、空行2つ以上で区切る（`【番号】` で始まる行・`# ` で始まる見出しの行も区切りになる。空行1つでは区切られない） | 区切りが無いと、何本もの投稿が1本として数えられ、本数も1行目の一覧も狂うため |
| 書き手の名前が分かる投稿は、名前の行を、行全体が `@名前` の形にそろえる（名前は日本語の表示名でもよい。`@名前・2日` の形も可。`書き手: 名前`・`投稿者: 名前` の行でもよい） | Threads から写すと名前に @ が付かないことがあり、そのままだと名前の行がその投稿の1行目として数えられてしまうため。名前が分からない投稿はそのままでよい（人数は「不明」と出る） |
| いいね・コメントの数だけの行や、数字だけの行は、消さなくてよい | 道具が数えずに外すため |

同じ中身をもう一度渡すと、道具は「保存しませんでした」と出して2つ目を保存しない。`50_市場の投稿/` と `鑑定/集めた投稿.md` の両方にある投稿は、1本として数える。

**集めた投稿が10本未満の時**: 書く手を止めない。そのまま書き、提出メモに次の1行を出す。

```
市場の言葉の確かめ: 集めた投稿が N 本なので未（10本集めると、言葉を数えて確かめられます）
```

あわせて、集め方の案内（`research.md` の案内）を1回だけ添える。同じ会話で2回は出さない（受講生の手を止めないため）。

## §4 道具

道具は作業フォルダ（最初の場所）で、次の形のまま1回に1つずつ動かす（`cd` で移らない・コマンドをつながない）。数えたい句が何個あっても、`--phrase` を並べて1回で数える。

| やること | 道具 |
|---|---|
| 貼られた他人の投稿を保存する | `python3 .grimoire/scripts/tn_kb.py market-add ティルナノーグ_マイナレッジ --text-file - [--note 一言] <<'EOF'`（次の行から、§3 で整えた投稿、最後の行に `EOF`）。ファイルで渡された時は `--file <ファイル>`（`--text-file <ファイル>` でもよい）、フックが長い文を保存した時は `--prompt-json <フックが伝えた .json>`。保存した本数が出る |
| 市場の言葉の表を作る | `python3 .grimoire/scripts/tn_kb.py market-words ティルナノーグ_マイナレッジ [--top 40]`。`ティルナノーグ_マイナレッジ/市場の言葉.md` に3つの表を書く:「よく出る言い回し」（言い回し・本数・書き手・例。3本以上の投稿に出る物。同じ文から出る並びは、その文の原文のまま1行にまとまる。12字以上で書き手が2人以下の、1人の文の写しに近い行は載らない）／「1行目の一覧（原文のまま）」／「文末の形」。10本未満の時は表を作らず、その旨が出る |
| 句を数える | `python3 .grimoire/scripts/tn_kb.py market-count ティルナノーグ_マイナレッジ --phrase 句 [--phrase 句 …]`。句を文字のまま探し、句ごとに何本の投稿に出るか・何人ぶんか・例を1つと、集めた投稿の総数が出る。0本の句には、その中で集めた投稿にある一番長い並びが添えられる（§7 の3）。書き手が分からない投稿だけなら「人数は不明」、分かる投稿と分からない投稿が混じる時は「N人以上」と出る。10本未満の時は「本数は目安です（10本から確かめられます）」と出る |
| 提出するファイルの1行目を当てる | 機械チェックに `--market ティルナノーグ_マイナレッジ` を足す（`python3 .grimoire/scripts/tn_check.py threads <ファイル> --settings ティルナノーグ_マイナレッジ/00_わたしの設定.md --market ティルナノーグ_マイナレッジ`。note は `threads` を `note` に）。各投稿の1行目（note は題と見出し）で、集めた投稿に1本も出ない句があると、目視候補 `MARKET`（「この句は集めた投稿（N本）に0本です」と、一番長い並び）が出る。集めた投稿に出ても書き手が1〜2人だけの12字以上の句には `MARKET_COPY` が出る。扱いは §7 の3・5・6 |

Python が動かない時は、`50_市場の投稿/` のファイルを読む道具・探す道具で開き、句を文字のまま探して数える。その時は提出メモに「手で数えた本数です」と添える。

## §5 書く前: 市場の言葉の表を読む（品質工程の段1）

1. 書く前に毎回、`python3 .grimoire/scripts/tn_kb.py market-words ティルナノーグ_マイナレッジ` を1回動かして表を作り直し、そのあと `ティルナノーグ_マイナレッジ/市場の言葉.md` を読む道具で読む（作り直しても、集めた投稿は変わらない。数秒で終わる）。表が古いかどうかを、フォルダの中身を並べて見分けようとしない（`ls`・`find`・`cd` などのコマンドは、受講生の画面に確認が出るため）。道具が「表はまだ作れません（10本から）」と出したら、§3 の「10本未満の時」に進む
2. 表から、今回のテーマに合う言い回し・1行目の形・文末の形を拾い、どれを使うかを `ティルナノーグ_制作物/_作業中/` のメモに書く。「よく出る言い回し」の表から拾う時は、書き手の欄が3人以上の行（書き手が分からない行は3本以上の行）から拾う（1〜2人しか使っていない言い回しは、その人の言い方に近いため。§8）
3. 伸びた投稿1本を手本にする時は、**今回のテーマと「読者の気持ちの動き方」が合い、かつその書き手の中でふだんより大きく伸びた投稿（目安は中央値の3倍以上、またはフォロワーが少ないのに反応が多い投稿）**を1本選ぶ。家族の笑い話の手本に真面目な警告の話を当てるように、気持ちの動き方が違う手本は選ばない。選んだ手本は、要約や骨組みに直さず**原文のまま切らずに** `_作業中/手本.md` に保存し、`tn_check.py threads` に当てて字数を確かめる。書く稿は、その字数までに収める（仕上げ後も1.1倍以内。`pipeline.md` §3「長さ」）

## §6 書く時: その言葉のまま書く

- 市場の言葉・決まり文句・1行目の形・語尾・語り口は、そのまま使う。変えるのは中身（題材・本人の事実）と、本人の声（一人称・語尾の癖・絵文字）だけ
- **手本1本をなぞる時**: `_作業中/手本.md` に置いた原文を見ながら、1行目の強い骨組み（数字・逆説・強い言葉）と行ごとの役目・テンポ・文字数感をそのまま1対1でなぞり、中身だけを本人の事実と答えに入れ替えて一息に書く。3人以上が使う決まり文句はそのまま残し、**その手本1人だけの言い回し（12字以上の一致）と、同じ文の並び（2文以上）を残さない**（§8）。書いた後は `tn_check.py … --tehon ティルナノーグ_制作物/_作業中/手本.md` で、12字以上の一致（`TEHON_COPY`）が0件・字数が手本の1.1倍以内（`TEHON_LENGTH` なし）か確かめる。鑑定モードでは採点の道具の近さ0.72未満も確かめる
- **直しのたびに手本の並びと字数へ戻る**: 書き直しや点検で文を直すうちに、説明を足して手本より長くなりやすい。直した後は毎回 `_作業中/手本.md` の字数と行の並びに戻って照らし、膨らんだ説明を削る
- **対象は本文だけではない**: アカウント名・肩書き・コンセプトの一言・柱や型の名前・プロフィール・note の題と見出し・企画表のセルも同じ。まとめの言葉や名前を作りたくなったら、それが市場の投稿に出てくるかを §7 のやり方で数える。出てこなければ使わない

形の例（講座の通し例「窓口のふく江さん」。元・信用金庫の窓口係の数秘のおばあちゃん）:

| 市場の句の形 | 中身を入れた形 |
|---|---|
| 〇〇な人へ。みんながやっている△△、実は逆効果です | 給料日が来た人へ。真っ先に全部おろして財布に入れるの、実は逆効果です |
| 〇〇が言ってた。△△だけがやってること。それが、 | 窓口にいた頃の先輩が言ってた。お金が残る人だけがやってること。それが、 |

左の形は、言い回しも語尾もそのまま残っている。替わったのは〇〇と△△に入れた中身（ふく江さんが窓口で見てきた場面）だけ。§7 で数える時は、1つ目の右の1行目なら、句の1つ「真っ先に全部おろして財布に入れるの」は0本でも、残りの句「実は逆効果です」が市場の言い回し（3人以上）なら済みで、提出メモには「形「実は逆効果です」M本＋中身「真っ先に全部おろして財布に入れるの」（題材）」と書く（M は道具が出した本数）。

## §7 書いた後: 句のまま数える（品質工程の段6d）

1. 名前・コンセプトの一言・各投稿の1行目・note の題と見出しを抜き出し、句に分ける。**句＝「、」「。」「！」「？」と改行で切った、4字以上のひとかたまり**（機械チェックと同じ切り方）
2. **部品の語ではなく、書いた句のまま** `market-count` で数える
   - なぜ: 部品の語（「金運」「習慣」）がそれぞれ市場に何本もあっても、つないだ句（「金運が育つ習慣」）が0本なら、それは作った言葉。読者はその句を一度も見ていない
3. 0本の句には、道具が「この中で集めた投稿にある一番長い並び: 「…」N本・M人」を添える（`market-count` も、機械チェックの `MARKET` も同じ）。次で決める
   - **済み**: その一番長い並びが市場の言い回し（3人以上。人数が分からなければ3本以上）で、句の残りが題材か本人の言葉の時。提出メモには「形「…」M本＋中身「…」（題材）」と書く
   - **直す**: 一番長い並びが無い時・1〜2本しか無い時・句の残りがこちらで作った言い回しの時。`市場の言葉.md` の「よく出る言い回し」の表から、近い言い回しの形（「祖母から教わった〇〇」「〇〇な人は△△してください」「〇月が苦しかった方へ」など、表に実際にある物）を探し、〇〇に中身を入れる。〇〇は題材なので本数を問わない
4. 0本でも残してよい物: 本人の言葉（設定・お手本・本人が口で言った言い方）と、題材そのものの名前（商品名・占術の名前など）。残した時は理由を1行書く
5. **写しに近い句**: 集めた投稿に出る句でも、書き手が1〜2人だけ（分からなければ1〜2本だけ）の長い句、特に1行目まるごとは、1人の文の写しに近い。3人以上が使う言い回しの形に替える（§8）。機械チェックは12字以上の句で、これを目視候補 `MARKET_COPY`（「この句は集めた投稿に N本・M人だけです。1人の文の写しに近いので…」）として出す
6. 機械チェックが出す目視候補 `MARKET` と `MARKET_COPY` は、1件ずつ記録する（`VOICE_…`・`VERIFY_FACT`・`FUZZY` と同じ扱い）。`MARKET` は「市場にある言い方の形に直した」か「形「…」M本＋中身「…」（題材）で済み」か「本人の言葉・題材なので残した（理由1行）」。`MARKET_COPY` は「3人以上の言い回しの形に替えた」か「本人の言葉なので残した（理由1行）」
7. 提出メモに、数えた句と本数を書く

```
市場の言葉の確かめ（集めた投稿 N 本）:
- 1行目「給料日が来た人へ。真っ先に全部おろして財布に入れるの、実は逆効果です」: 形「実は逆効果です」M本＋中身「真っ先に全部おろして財布に入れるの」（題材）
- 肩書き「お財布の見張り番」… 0 本・一番長い並びも1本だけ → 本人の言葉ではないので外し、「元・信用金庫の窓口係」（本人の経歴）にした
```

## §8 写さない決まりとの線引き（絶対ルール §1 の4番）

| 使ってよい | 写さない |
|---|---|
| 言葉・決まり文句・1行目の形・語尾・語り口（3人以上が使っている言い回し） | 1人の投稿の文の並びを、続けてそのまま写すこと／その人だけの出来事／その人の数字／オチ |

- 写さない4つは、講座の第2回勉強会の「持ってこないものは4つ」と同じ
- 似すぎを避けるために、市場の言葉を言い換えない。似すぎを避けたい時は、中身（題材・本人の事実）の方を替える
- 何人が使っているかは `market-count` の人数で見る。「人数は不明」と出た時は、3本以上の投稿に出るかで見る（「N人以上」と出た時は、N が3以上なら3人以上として扱う）
- 1人しか使っていない言い回しを、その人の文の並びのまま続けて使わない。集めた投稿に出る句でも、書き手が1〜2人だけ（分からなければ1〜2本だけ）の長い句、特に1行目まるごとは、写しに近い。3人以上が使う言い回しの形に替える（機械チェックの目視候補 `MARKET_COPY`。扱いは §7 の5・6）
- 手本と同じ文の並びかどうかの見分け方: 手本と同じ順の文が2文以上続いていたら、並びを写している（§6）
- 鑑定モードの採点の道具が「近さ0.72以上」と出した時は、文の並びが近すぎる合図。決まり文句は残し、並びと中身を替える（`references/kantei/post-scoring.md`）
- 講座の第2回の資料と、その回のカードには「真似していいのは形（構造）だけ」「言葉はそのまま使いません」とある。2026-11-12 の講師の指示で、この表の線引きに変わった。食い違った時はこの表に従う（絶対ルール §1 の4番に書いてあり、どの層のカードからも上書きできない）

## §9 ほかの決まりとの関係

- **絶対ルールに当たる言い方**: 市場で伸びていても、絶対ルール §1 と `references/kantei/safety.md` に当たる言い方（結果の保証・脅し・未来の断定など）は、「真似しない言い方」として数えるだけで、使わない
- **ふわっと禁止**（`absolute-rules.md` §6）: そのジャンルの伸びた投稿に実際にある語（占いの「運気」「浄化」、健康の「腸活」など）は、そのジャンルでは使ってよい。ふわっと禁止は、届く物・読者の得を言う行に当てる（得を「整う」「流れが変わる」でぼかさない）
- **自然な日本語が先**: 市場の言葉どうしでも、つないだ時に日本語として崩れる組み合わせにしない。判定の順番は `breakdown-checklist.md` §1 のまま
- **破綻の点検の「言い換えで救わない」**（`breakdown-checklist.md` §4）: 壊れた文を、言葉の差し替えだけで済ませないという決まり。市場の言葉を守ることとぶつからない。直す時は、市場の言葉と本人の言葉を残したまま、文の組み立て（主語・目的語・つなぎ）を直す
- **書き直し担当**（`rewrite-pass.md`）: 市場の言葉は「変えない言葉」と同じ扱いで前提メモに入れる。消すのは AI の決まり文句（「安心してください」「いかがでしょうか」など）で、市場の決まり文句（`市場の言葉.md` の表にある物）は消さない

## §10 よくある失敗

| 失敗 | なぜ起きるか | 防ぎ方 |
|---|---|---|
| 肩書き・柱の名前・型の名前を作る（「〇〇の見張り番」「〇〇の見立て」） | まとめの言葉を作ると、整理できた気になる | §7 で句のまま数える。0本なら、市場の句の形に中身を入れる |
| 似すぎを避けて、決まり文句まで言い換える | 写さない決まりを広く取りすぎる | §8 の表で線を引く。替えるのは中身 |
| 部品の語だけを数えて「市場にある」とする | 1語ずつなら、たいてい市場にある | 書いた句のまま数える |
| 集めた投稿を「言い換えて」メモする | 原文を手元に置くと、写してしまう気がする | 原文のまま `market-add` で手元に置く。外に出す稿で、文の並びを続けて写さない |
| 返信を、相手が使っていない言葉で書く | AI の言い方に直してしまう | §2 のとおり、相手の文面にある言葉で返す |
| 受講生への報告で、画面に無い名前を使う | 手順書の中の呼び方で話してしまう | 受講生が使った言葉と、画面・ファイルに出ている名前で話す |
